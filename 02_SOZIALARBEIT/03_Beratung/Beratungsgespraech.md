# Beratungsgespräch — Methoden und Grundsätze

[← Beratung](./README.md) | [← Sozialarbeit](../README.md)

> Beratung in der Sozialarbeit ist mehr als Informationsweitergabe.
> Gute Beratung stärkt Selbstwirksamkeit, respektiert Autonomie und
> verbindet Fachwissen mit Beziehungsarbeit.

---

## Grundhaltungen in der Sozialarbeitsberatung

```
Basierend auf dem person-zentrierten Ansatz (Carl Rogers):

1. Empathie (Einfühlendes Verstehen)
   → Verstehen wie Klient die Situation erlebt
   → Nicht: "Ich verstehe wie Sie sich fühlen"
   → Sondern: aktiv zuhören, spiegeln, nachfragen

2. Kongruenz (Echtheit)
   → Sozialarbeiter ist authentisch
   → Keine Rolle spielen
   → Auch Grenzen klar benennen ("Das kann ich leider nicht entscheiden")

3. Positive Wertschätzung (Unbedingte Akzeptanz)
   → Person wird angenommen wie sie ist
   → Keine Bewertung von Lebensstil, Entscheidungen
   → ACHTUNG: Akzeptanz ≠ alles gut finden

4. Ressourcenorientierung
   → Nicht nur Defizite benennen
   → "Was haben Sie bisher gut hinbekommen?"
   → Stärken sichtbar machen
```

## Phasen des Beratungsgesprächs

### Phase 1: Kontaktaufnahme und Beziehungsaufbau

```
Ziele:
  → Vertrauen schaffen
  → Anliegen klären
  → Rahmen des Gesprächs erläutern

Praktisch:
  → Willkommen heißen, Anbieten von Wasser/Sitzen
  → Sich vorstellen + Rolle erklären
  → Zeit + Datenschutz erläutern:
    "Dieses Gespräch ist vertraulich. Informationen gebe ich nur mit Ihrer
     Zustimmung weiter."

Türöffner-Fragen:
  → "Was führt Sie heute hierher?"
  → "Was ist Ihr wichtigstes Anliegen?"
  → "Was hat sich zuletzt verändert?"
```

### Phase 2: Anliegen erheben und verstehen

```
Techniken:
  → Aktives Zuhören: Nicken, Mhmm, "Ich verstehe..."
  → Paraphrasieren: "Sie sagen also, dass..."
  → Offene Fragen: W-Fragen (Was, Wie, Wann, Wer)
  → Geschlossene Fragen: sparsam (nur für Fakten)

Anamnese:
  → Lebenssituation: Wohnen, Arbeit, Familie, Gesundheit
  → Problemgeschichte: Seit wann? Was war der Auslöser?
  → Bisherige Versuche: Was wurde schon probiert?
  → Ressourcen: Was funktioniert gut? Wer unterstützt?

Problemklärung:
  → Manchmal: vorgelegtes Problem ≠ eigentliches Problem
  → "Gibt es noch etwas, was Sie beschäftigt?"
  → Zeit lassen — manchmal kommt das Wichtigste erst am Ende
```

### Phase 3: Ziele entwickeln

```
SMART-Ziele:
  Spezifisch: konkret und klar
  Messbar: wann ist Ziel erreicht?
  Akzeptiert: vom Klienten gewollt (nicht aufgezwungen!)
  Realistisch: erreichbar
  Terminiert: bis wann?

Beispiel:
  NICHT: "Ich will meine Schulden loswerden"
  SONDERN: "In 3 Monaten habe ich einen Termin bei der Schuldnerberatung
    und einen Überblick über alle Schulden."

Partizipation:
  → Ziele müssen VOM KLIENTEN kommen (nicht aufgedrängt!)
  → Berater = Begleiter, nicht Entscheider
  → "Was wäre für Sie ein kleiner Schritt in die richtige Richtung?"
```

### Phase 4: Informieren und Handlungsoptionen entwickeln

```
Information geben:
  → Nur was relevant ist — kein Informationsoverload!
  → "Darf ich Ihnen erklären, was das bedeutet?"
  → Fachsprache vermeiden oder erklären
  → Informationsmaterial mitgeben (schriftlich)

Handlungsoptionen:
  → Mindestens 2–3 Optionen vorstellen
  → Vor- und Nachteile abwägen
  → Entscheidung liegt beim Klienten!

Konkrete nächste Schritte:
  → "Was können Sie bis zum nächsten Gespräch konkret tun?"
  → "Was brauchen Sie dafür von mir?"
  → Schriftlich festhalten (für Klient + eigene Dokumentation)
```

### Phase 5: Abschluss und Follow-up

```
Zusammenfassen:
  → "Was haben wir heute besprochen?"
  → Klienten zusammenfassen lassen (Verständnis prüfen)

Nächste Schritte:
  → Wer tut was bis wann?
  → Folge-Termin vereinbaren
  → "Wie kann ich Sie am besten erreichen?"

Feedback einholen:
  → "Hat das Gespräch geholfen?"
  → "Was fehlt noch?"
```

## Motivational Interviewing (MI)

```
MI = Motivierende Gesprächsführung
  → Besonders geeignet wenn: Ambivalenz vorhanden, Widerstand spürbar
  → Nicht kämpfen, nicht überreden — "Drehen Sie die Argumentation um"

OARS-Grundtechniken:
  O — Open Questions: Offene Fragen stellen
  A — Affirming: Stärken bestätigen und loben
  R — Reflecting: Reflektieren was gesagt wurde
  S — Summarizing: Zusammenfassen

Umgang mit Widerstand:
  → NICHT konfrontieren ("Aber das müssen Sie doch einsehen...")
  → STATTDESSEN: Widerstand rollen lassen
  → "Es klingt als ob Sie noch nicht sicher sind. Das ist verständlich."
  → "Was spricht für eine Änderung? Was dagegen?"

Change talk hervorrufen:
  → "Warum möchten Sie das ändern?"
  → "Was würde sich verbessern wenn..."
  → "Stellen Sie sich vor, es klappt — wie sieht Ihr Leben in 5 Jahren aus?"
```

## Case Management

```
Case Management = koordinierte Unterstützung bei komplexen Fällen

Phasen (nach DGCC):
  1. Assessment: Bedarfserhebung (umfassend!)
  2. Hilfeplanung: Ziele + Maßnahmen definieren
  3. Implementierung: Leistungen einleiten, Netzwerk koordinieren
  4. Monitoring: regelmäßig prüfen ob Ziele erreicht werden
  5. Evaluation: Wirksamkeit beurteilen
  6. Abschluss: Betreuung beenden wenn Ziele erreicht

Wann Case Management:
  → Mehrere Problembereiche gleichzeitig
  → Mehrere Behörden/Träger involviert
  → Klient kann nicht selbst koordinieren
  → Lange Begleitungszeit nötig

Werkzeuge:
  → Ecomap (Visualisierung des sozialen Netzes)
  → Genogramm (Familienstruktur)
  → Netzwerkkonferenz (alle Beteiligten zusammenbringen)
  → Hilfeplangespräch (formell + dokumentiert)
```

## Krisenintervention

```
Wann Krisenintervention:
  → Akute Suizidalität
  → Häusliche Gewalt / Gefährdungssituation
  → Psychotische Episode
  → Schwere Eskalation

Grundprinzipien:
  1. Sicherheit herstellen (Dritte schützen, Person schützen)
  2. Deeskalieren: ruhige Stimme, langsam sprechen
  3. Kontakt halten: nicht alleine lassen
  4. Verstärker weg: Alkohol, andere eskalierenden Personen

Wenn Suizidalität:
  → Direkt ansprechen: "Haben Sie Gedanken daran, sich etwas anzutun?"
  → MITOS: Direkt fragen erhöht NICHT das Risiko — im Gegenteil!
  → Sofortmaßnahmen: Krisentelefon, Psychiatrie, Notarzt (110/112)
  → Telefonseelsorge: 0800 111 0 111 oder 0800 111 0 222 (kostenlos, 24h)

Professionelles Handeln danach:
  → Supervison nach Kriseneinsatz
  → Dokumentation
  → Weitervermittlung
```

## Dokumentation in der Sozialarbeit

```
Zweck der Dokumentation:
  → Kontinuität der Hilfe (auch bei Personalwechsel)
  → Nachweis erbrachter Leistungen
  → Rechtliche Absicherung
  → Qualitätssicherung

Was dokumentieren:
  → Datum, Dauer, Teilnehmer
  → Anlass / Thema
  → Wichtige Aussagen des Klienten (in Anführungszeichen!)
  → Vereinbarte Maßnahmen
  → Nächste Schritte

Datenschutz (DSGVO + SGB X):
  → Nur nötige Daten erheben
  → Zugriff beschränken
  → Klient hat Auskunftsrecht (§ 83 SGB X)
  → Aufbewahrungsfristen (je nach Träger: 5–10 Jahre)

Sprache:
  → Sachlich, neutral, faktenbezogen
  → Keine Wertungen ("der Klient ist auffällig")
  → Stattdessen: konkrete Beschreibungen
  → Person-First-Language: "Herr M. hat eine Depression"
    (nicht: "der Depressive")
```

## Grenzen der Beratung und Weitervermittlung

```
Wo endet Sozialarbeitsberatung?
  → Medizinische Diagnose: Arzt!
  → Psychotherapeutische Behandlung: Psychologe/Psychiater
  → Rechtsberatung mit Vertretung: Rechtsanwalt
  → Schuldnerberatung (tiefgreifend): Fachberatungsstelle

Kooperationsnetzwerk aufbauen:
  → Überweisungsmöglichkeiten kennen
  → Wartezeiten kennen (Therapieplätze: oft Monate!)
  → Überbrückungsangebote nutzen (PSZ, Krisentelefone)

Warm Hand-Over:
  → Nicht nur "Gehen Sie zum Arzt" sagen
  → Begleitung zum ersten Termin anbieten
  → Rückmeldung erbitten
  → Nachfragen wie es lief
```
