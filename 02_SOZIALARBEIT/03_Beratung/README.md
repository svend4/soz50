## Arten der Beratung

| Typ | Inhalt |
|-----|--------|
| **Sozialrechtliche Beratung** | Rechte, Ansprüche, Bescheide, Widerspruch |
| **Psychosoziale Beratung** | Persönliche Probleme, Krisenbewältigung |
| **Schuldnerberatung** | Schulden, Insolvenz, Pfändung |
| **Migrationsberatung** | Aufenthalt, Integration, Behördenkontakte |
| **Suchtberatung** | Abhängigkeitserkrankungen |
| **Familienberatung** | Erziehung, Konflikte, Trennung |

---

## Grundprinzipien der Beratung

- **Vertraulichkeit** — Schweigepflicht (§ 203 StGB)
- **Freiwilligkeit** — keine Beratung gegen den Willen
- **Parteilichkeit** — Interessen des Klienten vertreten
- **Akzeptanz** — nicht wertend, nicht moralisierend
- **Ressourcenorientierung** — Stärken aktivieren
- **Selbstbestimmung** — Klient entscheidet selbst

## Erstgespräch — Checkliste

```
Vorbereitung:
  [ ] Raum vorbereiten (Datenschutz, Ruhe)
  [ ] Dolmetscher organisiert?
  [ ] Verfügbare Zeit klären

Im Gespräch:
  [ ] Vorstellung + Rolle erklären
  [ ] Schweigepflicht und Grenzen erläutern
  [ ] Anlass / Situation erfragen (aktiv zuhören)
  [ ] Dringende Bedarfe identifizieren (Geld? Wohnen? Gesundheit?)
  [ ] Ressourcen erfragen
  [ ] Nächste Schritte vereinbaren

Nach dem Gespräch:
  [ ] Dokumentation (Datum, Inhalt, Vereinbarungen)
  [ ] Aufgaben/Fristen notieren
```

---

## Dokumentation

Каждый Beratungskontakt документируется:

```markdown
Datum: TT.MM.YYYY
Klient: [anonymes Kürzel]
Thema: ...
Inhalt: ...
Vereinbarungen: ...
Nächster Termin: ...
```

## Grenzen der Beratung — Schweigepflichtsdurchbrechung

Schweigepflicht kann gebrochen werden bei:
- **Kindeswohlgefährdung** (§ 8a SGB VIII) — Pflicht zur Meldung
- **Akute Selbst- oder Fremdgefährdung** — abwägen, ggf. Notruf
- **Einwilligung des Klienten**
