# Dokumentation in der Sozialarbeit — Документирование

[← Sozialarbeit](../README.md) | [← Главная](../../README.md)

---

## Зачем документировать?

- **Rechtssicherheit** — доказательство выполненной работы
- **Kontinuität** — коллеги могут продолжить работу
- **Qualitätssicherung** — рефлексия, улучшение работы
- **Rechenschaftspflicht** — перед ведомством, финансирующим
- **Datenschutz** — правильное хранение и удаление

---

## Arten der Dokumentation

| Тип | Назначение |
|-----|-----------|
| Beratungsprotokoll | Фиксация отдельного разговора |
| Fallakte (Fallführung) | Полная история случая |
| Hilfeplan | Strukturierter Plan (§ 36 SGB VIII) |
| Verlaufsdokumentation | Хронология событий |
| Abschlussbericht | Итог работы при завершении |
| Sachbericht | Отчёт для финансирующего ведомства |

## Datenschutz — DSGVO

```
Grundsätze:
  - Zweckbindung (данные только для заявленной цели)
  - Datensparsamkeit (только необходимые данные)
  - Vertraulichkeit (защита от посторонних)
  - Löschpflicht (удалить когда цель достигнута)

Aufbewahrungsfristen:
  - Sozialarbeit allgemein: 10 Jahre nach Fallabschluss
  - Jugendhilfe: nach Vollendung 18. Lebensjahres + 10 Jahre
  - Medizinische Daten: 10 Jahre (§ 630f BGB)
```

## Kindeswohlgefährdung — § 8a SGB VIII

При признаках угрозы благополучию ребёнка:

```
1. Risikoeinschätzung im Team
2. Fachkraft mit Erfahrung hinzuziehen (§ 8a Abs. 1)
3. Eltern einbeziehen (wenn möglich ohne Gefährdung)
4. Bei Nichtabwendbarkeit: Jugendamt informieren
5. Dokumentation: Datum, Beobachtungen, Maßnahmen
```
