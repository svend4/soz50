# Kindeswohlgefährdung — § 8a Dokumentation & Meldebogen

[← Dokumentation](./README.md) | [← Sozialarbeit](../README.md)

---

## § 8a SGB VIII — Schutzauftrag (Kurzübersicht)

```
§ 8a Abs. 1 SGB VIII:
  Werden dem Jugendamt gewichtige Anhaltspunkte für die Gefährdung
  des Wohls eines Kindes oder Jugendlichen bekannt, so hat es das
  Gefährdungsrisiko im Zusammenwirken mehrerer Fachkräfte einzuschätzen.

§ 8a Abs. 2 SGB VIII (für freie Träger):
  Träger der freien Jugendhilfe werden durch Vereinbarung verpflichtet,
  bei Bekanntwerden gewichtiger Anhaltspunkte das Jugendamt einzubeziehen.

Pflicht gilt für ALLE pädagogischen Fachkräfte:
  → Kita, Schule, Beratungsstelle, ASD, stationäre Einrichtung, etc.
```

## Gewichtige Anhaltspunkte — Checkliste

### Körperliche Gefährdung

```
[ ] Unerklärliche Verletzungen, Blutergüsse, Striemen
[ ] Verletzungen in verschiedenen Heilungsstadien
[ ] Verletzungen an Stellen, die nicht durch Unfälle erklärbar
[ ] Deutliche Unterernährung / Mangelernährung
[ ] Anhaltende Vernachlässigung der Körperpflege / Hygiene
[ ] Keine altersgemäße medizinische Versorgung
[ ] Kind äußert körperliche Schmerzen / zeigt Schutzreflexe
```

### Seelische / emotionale Gefährdung

```
[ ] Kind äußert Angst vor Personen aus dem Haushalt
[ ] Ausgeprägte Verhaltensauffälligkeiten (Aggression, Regression)
[ ] Starke Ablehnung des Nachhausewegs
[ ] Symptome einer posttraumatischen Belastung
[ ] Deutliche Entwicklungsrückstände ohne organische Ursache
[ ] Kind zeigt sexualisiertes Verhalten (altersungemäß)
[ ] Häufiges unentschuldigtes Fehlen / Schulverweigerung
```

### Vernachlässigung

```
[ ] Unzureichende Ernährung (Hunger, schlechte Zähne)
[ ] Unzureichende Kleidung (zu kalt, verschmutzt, zu klein)
[ ] Häufige Unfall-/Verletzungssituationen (mangelnde Aufsicht)
[ ] Keine Schul-/Kitabesuche
[ ] Eltern / Erziehungsberechtigte reagieren nicht auf Bedürfnisse
[ ] Keine Wohnsicherheit / häufige Umzüge
```

### Sexueller Missbrauch

```
[ ] Altersungemäßes Sexualwissen
[ ] Sexualisiertes Verhalten gegenüber Gleichaltrigen / Erwachsenen
[ ] Körperliche Anzeichen im Genital-/Analbereich
[ ] Plötzliche Verhaltensänderung ohne erklärbaren Anlass
[ ] Kind macht direkte oder indirekte Andeutungen
[ ] Rückzug, Schlafstörungen, Einnässen ohne organische Ursache
```

## Risikoeinschätzung — Bogen (4-stufig)

### Schritt 1: Anhaltspunkte dokumentieren

```
Datum der Beobachtung/Information: ___________
Quelle (eigene Beobachtung / Mitteilung / wer): ___________

Konkrete Beobachtung / Mitteilung:
[Genaue Beschreibung — keine Interpretation, nur Fakten!]
_______________________________________________
_______________________________________________

Datum: ___________ Dokumentiert von: ___________
```

### Schritt 2: Gefährdungsstufe einschätzen

```
Stufe 1: KEINE Gefährdung / kein Handlungsbedarf
  → Normale Alltagssituation, keine Anhaltspunkte
  → Dokumentation empfohlen

Stufe 2: MÖGLICHE Gefährdung / Beobachtungsbedarf
  → Gewichtige Anhaltspunkte vorhanden
  → Kollegiale Beratung / Teamberatung einleiten
  → Elterngespräch initiieren (wenn ohne Gefährdung möglich)
  → Beobachtung intensivieren, Dokumentation fortführen

Stufe 3: WAHRSCHEINLICHE Gefährdung / Handlungsbedarf
  → Mehrere Anhaltspunkte
  → Hinzuziehung erfahrener Fachkraft (intern)
  → Ggf. externe Fachberatung (ASD, freier Träger)
  → Jugendamt informieren wenn Gefährdung nicht abzuwenden

Stufe 4: AKUTE Gefährdung / sofortiges Handeln
  → Kind in unmittelbarer Gefahr
  → Sofort Jugendamt (ASD) einschalten
  → Bei akuter Lebensgefahr: Polizei (110)
  → Inobhutnahme § 42 SGB VIII
```

### Schritt 3: Team-/Fachkraft-Beratung dokumentieren

```
Datum: _______   Uhrzeit: _______
Beteiligte Fachkräfte: _______________________
Einschätzung des Teams: _____________________
Einstufung: Stufe [ 1 ] [ 2 ] [ 3 ] [ 4 ]
Beschlossene Maßnahmen: ____________________
Nächstes Überprüfungsdatum: ________________
```

## Elterngespräch — Vorgehen

```
WANN Eltern einbeziehen?
  → IMMER — außer wenn dadurch Gefährdung erhöht wird
    (z.B. Misshandlung durch Eltern → erst Jugendamt!)

Wie vorgehen:
  1. Ruhige, wertschätzende Atmosphäre schaffen
  2. Konkrete Beobachtungen schildern (keine Schuldzuweisungen!)
  3. Eltern um Erklärung bitten
  4. Hilfe anbieten (HzE, Beratung)
  5. Verhalten der Eltern im Gespräch beobachten

Warnsignale im Elterngespräch:
  → Massives Abstreiten / Bagatellisieren
  → Aggressives Verhalten
  → Unglaubwürdige Erklärungen
  → Eltern versuchen Kind zum Widerruf zu bringen
  → Terminabsagen, Nichterreichbarkeit

Wenn Elterngespräch zu Gefährdung führen würde:
  → DIREKT Jugendamt informieren (§ 8a Abs. 2)
```

## Meldung an das Jugendamt — Ablauf

```
Telefonische Meldung (sofort):
  → ASD des zuständigen Jugendamts anrufen
  → Bereitschaftsdienst außerhalb der Öffnungszeiten
  → Konkrete Angaben: Name, Adresse des Kindes, Sachverhalt

Schriftliche Meldung (nachfolgend):
  → Ausführliche Sachverhaltsdarstellung
  → Alle dokumentierten Beobachtungen
  → Einschätzungsbogen beifügen
  → Datum + Unterschrift

Eigene Dokumentation:
  → Alle Schritte, Gespräche, Maßnahmen festhalten
  → "Wer hat wann was getan / entschieden?"
  → Aufbewahrung nach Datenschutzregeln (10 Jahre)
```

## Nach der Meldung — was passiert?

```
Jugendamt ist verpflichtet:
  → Gefährdungsrisiko einzuschätzen (§ 8a Abs. 1 SGB VIII)
  → Innerhalb 24h bei akuter Gefahr
  → In nicht-akuten Fällen: binnen weniger Tage

Meldende Einrichtung:
  → Hat Anspruch auf Rückmeldung (soweit möglich/datenschutzkonform)
  → Bleibt an der Seite des Kindes
  → Kooperiert mit JA im weiteren Verfahren

Inobhutnahme (§ 42 SGB VIII):
  → JA kann Kind sofort in Sicherheit bringen
  → Eltern werden informiert
  → Familiengericht entscheidet über weiteren Verbleib
```

## Selbstschutz / Teamschutz

```
Belastende Fälle:
  → Regelmäßige Supervision
  → Fachberatung nutzen
  → Meldung ist SCHUTZ (nicht Verrat) des Kindes

Rechtliche Absicherung:
  → § 8a-Meldung schützt vor Unterlassungsvorwurf
  → Pflicht zur Meldung bei gewichtigen Anhaltspunkten!
  → Zivil- und strafrechtliche Risiken bei Nichtmeldung

Datenschutz:
  → § 65 SGB VIII: Schweigepflicht vs. Kinderschutz
  → Bei § 8a-Meldung überwiegt Kinderschutz
  → Datenweitergabe an JA ist rechtmäßig (§ 69 Abs. 1 Nr. 1 SGB X)
```
