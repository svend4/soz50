# Dokumentation in der Sozialen Arbeit

[← Dokumentation](./README.md) | [← Sozialarbeit](../README.md)

> Dokumentation ist professionelle Pflicht und rechtliches Schutzinstrument.
> Was dokumentiert ist, hat stattgefunden — was nicht dokumentiert ist, hat nicht stattgefunden.
> Gute Dokumentation schützt Klient UND Fachkraft.

---

## Warum dokumentieren? — Professionelle Begründung

```
1. KONTINUITÄT:
   → Mitarbeiterwechsel: neuer Kollege kann Fallgeschichte verstehen
   → Urlaub, Krankheit: Vertretung ist informiert
   → Langzeitbetreuung: Entwicklung nachvollziehbar

2. RECHENSCHAFTSPFLICHT:
   → Gegenüber Träger, Finanzierern, Behörden
   → "Was haben wir mit dem Geld gemacht?"
   → Nachweis von Maßnahmen, Leistungen

3. RECHTSSICHERHEIT:
   → Bei Klagen, Beschwerden, Vorwürfen
   → Gerichtsverwertbar wenn korrekt
   → Schutz der Fachkraft bei Streitigkeiten

4. QUALITÄTSSICHERUNG:
   → Reflexion der eigenen Arbeit
   → Fallsupervision: Grundlage für Beratung
   → Evaluation von Hilfen

5. KLIENTENRECHTE:
   → Transparenz über eigene Situation
   → Recht auf Akteneinsicht (§ 25 SGB X)
```

## Datenschutz in der Sozialen Arbeit

```
DSGVO + nationales Recht:

Grundsätze (Art. 5 DSGVO):
  → Zweckbindung: Daten nur für festgelegten Zweck!
  → Datensparsamkeit: nur notwendige Daten erheben
  → Richtigkeit: Daten aktuell halten
  → Speicherbegrenzung: nicht länger als nötig aufbewahren
  → Integrität: Datensicherheit gewährleisten

SGB X § 67ff. — Sozialgeheimnis:
  → Sozialdaten dürfen nur zweckgebunden verarbeitet werden
  → Weitergabe nur mit Einwilligung ODER gesetzlicher Grundlage
  → Auch intern: Weitergabe nur an Befugte!

SGB VIII § 65 — besonders strenger Datenschutz:
  → Informationen im Beratungskontext (§ 28 SGB VIII):
    → Nur mit Einwilligung weitergeben!
    → Ausnahme: § 8a (Kindeswohlgefährdung)

§ 203 StGB — Verletzung der Schweigepflicht:
  → Gilt für: Sozialarbeiter, Sozialpädagogen, Ärzte, Rechtsanwälte
  → Strafbar: unbefugte Offenbarung von Geheimnissen
  → Ausnahmen: mit Einwilligung oder rechtfertigender Pflicht
    (z.B. § 8a KWG, Notwehr, Selbstgefährdung)
```

## Einwilligung und Schweigepflichtentbindung

```
Einwilligung (Art. 7 DSGVO + § 67b SGB X):
  → Muss: freiwillig, informiert, eindeutig sein
  → Schriftlich empfohlen (nicht zwingend, aber Nachweis)
  → Widerrufbar jederzeit (mit Wirkung für die Zukunft)

Schweigepflichtentbindung:
  → Für Kooperation mit anderen Stellen (JC, Schule, Arzt)
  → "Kooperationsvereinbarung / Datenweitergabe" unterschreiben lassen
  → Immer begrenzt: für welche Stelle, welche Informationen, welcher Zeitraum?

ACHTUNG — Druckverbot!
  → Einwilligung darf nicht Voraussetzung für Hilfe sein
  → "Wenn Sie nicht unterschreiben, helfen wir Ihnen nicht" = unzulässig!
  → Ausnahme: wenn Hilfe strukturell Kooperation erfordert (§ 36 SGB VIII Hilfeplan)
```

## Recht auf Akteneinsicht (§ 25 SGB X)

```
§ 25 SGB X:
  → Beteiligte haben Recht auf Akteneinsicht
  → Behörde kann verweigern wenn: Geheimhaltungsinteresse Dritter
  → Recht gilt bei Sozialleistungsträgern (JC, Sozialamt, BA)

In der freien Jugendhilfe / Sozialarbeit:
  → DSGVO: Betroffenenrecht auf Auskunft (Art. 15 DSGVO)
  → Recht auf Kopie der eigenen Daten
  → Frist: 1 Monat (Art. 12 Abs. 3 DSGVO)

Praktisch:
  → Klient möchte Fallakte sehen → Recht besteht!
  → Notizen dürfen enthalten sein (Bewertungen müssen sachlich sein!)
  → Dritte dürfen nicht benannt werden (Datenschutz der Quelle)
  → Löschen nicht mehr nötiger Daten: auch Recht des Klienten
```

## Was dokumentieren? — Inhalte und Form

```
Grundunterschied:
  BEOBACHTUNG: "Klient kam 15 Minuten zu spät. Er riecht nach Alkohol."
  INTERPRETATION: "Klient ist alkoholkrank und unzuverlässig."

  → Immer: Beobachtungen zuerst, dann ggf. Einschätzung trennen!
  → Einschätzungen mit Begründung: "Aufgrund der folgenden Beobachtungen..."

Pflichtbestandteile einer Falldokumentation:
  → Stammdaten (Name, Geb.-Datum, Kontaktdaten — geschützt!)
  → Anlass: Warum kommt die Person?
  → Sachlage / Biographie: Lebensgeschichte, aktuelle Situation
  → Eigene Ressourcen: Stärken, soziales Netz
  → Problemanalyse (gemeinsam mit Klient entwickeln!)
  → Ziele (SMART: spezifisch, messbar, attraktiv, realistisch, terminiert)
  → Maßnahmen: Was wird gemacht, von wem, bis wann?
  → Verlauf: Was hat stattgefunden?
  → Evaluation: Was hat gewirkt, was nicht?
  → Abschluss / Weiterleitung

Gesprächsprotokolle:
  → Datum, Dauer, Ort, Teilnehmer
  → Themen und Ergebnisse — nicht alles wörtlich!
  → Wichtige Aussagen in Anführungszeichen (direkte Zitate)
  → Vereinbarungen deutlich hervorheben
```

## Besondere Dokumente

```
Hilfeplan (§ 36 SGB VIII):
  → Pflichtdokument bei HzE
  → Inhalt: Diagnose, Ziele, Maßnahmen, Zuständigkeiten, Termine
  → Klient unterschreibt (Partizipation!)
  → Überprüfung mindestens 1× jährlich

Gesamtplan (§ 121 SGB IX):
  → Pflichtdokument bei EGH
  → ICF-basiert (Teilhabeziele)
  → Alle beteiligten Träger

Fachliche Stellungnahme / Bericht:
  → An Behörden, Gericht, Träger
  → Strenge Sachlichkeit!
  → Was ist Tatsache, was ist Meinung? Trennen!
  → Bei Gericht: nur was direkt beobachtet wurde!

Kindeswohlgefährdungs-Dokumentation (§ 8a SGB VIII):
  → Verdacht: sofort dokumentieren
  → Datum, konkrete Beobachtungen
  → Risikoeinschätzung (mit Begründung)
  → Kollegiale Beratung / Fachberatung: dokumentieren!
  → Meldung ans Jugendamt: Datum, Inhalt, an wen
```

## Aufbewahrungsfristen

```
Aufbewahrungspflichten:
  → Sozialleistungsträger (JC, Sozialamt): i.d.R. 10 Jahre nach Fallabschluss
  → Jugendhilfe: z.T. bis Volljährigkeit + 10 Jahre
  → Gesundheit: 10 Jahre (§ 630f BGB für Ärzte)

Löschpflicht nach DSGVO:
  → Nach Ablauf der Aufbewahrungsfrist: Löschen!
  → Aktives Löschen (auch digitale Dateien, Backups)

Faustregel in der Praxis:
  → Leitfaden des Trägers / Verbands beachten
  → Im Zweifel: Datenschutzbeauftragten fragen
```

## Digitale Dokumentation — Sicherheit

```
Datensicherheit (Art. 32 DSGVO + § 78a SGB X):
  → Verschlüsselung (PC, Laptop, Smartphone)
  → Passwortschutz auf allen Geräten
  → Keine Klientendaten auf privaten Geräten!
  → Cloud: nur DSGVO-konforme Anbieter (EU-Server, Auftragsverarbeitung)

E-Mail:
  → Unverschlüsselte E-Mails: KEIN datenschutzkonformer Kanal!
  → Personenbezogene Daten per E-Mail → nur mit Einwilligung und Hinweis auf Risiken
  → Besser: verschlüsselte E-Mail (PGP) oder gesichertes Portal

Mobiler Datenschutz:
  → Notizen auf Papier: nie mit Klarnamen bei Hausbesuchen
  → WhatsApp für Klientengespräche: grundsätzlich NEIN
    (Metadaten, US-Server, keine Kontrolle)
  → Alternative: Signal (E2E-Verschlüsselt)
```

## Supervision und Dokumentation

```
Supervision nutzt Dokumentation:
  → Falldarstellung in Supervision: Akte ist Grundlage
  → Was habe ich dokumentiert? Was habe ich weggelassen?
  → Unbewusste Bewertungen in Dokumentation sichtbar machen

Dokumentation als Selbstreflexion:
  → "Wie habe ich den Klienten wahrgenommen?"
  → "Was hat mich in dieser Sitzung beschäftigt?"
  → Reflexionsnotizen können intern bleiben (nicht zur Fallakte)

ACHTUNG:
  → Reflexionsnotizen → nur intern, nicht für Behörden
  → Personenbezogen → trotzdem Datenschutz!
```
