# Institutionen und Träger der Sozialen Arbeit

[← Institutionen](./README.md) | [← Sozialarbeit](../README.md)

> Soziale Arbeit findet statt in einem komplexen Geflecht von staatlichen
> und freien Trägern. Das Subsidiaritätsprinzip regelt: Staat tritt zurück
> wo freie Träger tätig sind (§ 5 SGB VIII, § 17 SGB XII).

---

## Das Prinzip der Subsidiarität

```
Subsidiarität = kleinere Einheit hat Vorrang vor größerer

In der Sozialen Arbeit:
  1. Selbsthilfe (Familie, Netzwerk)
  2. Freie Träger (Wohlfahrtsverbände, Vereine)
  3. Kommunale öffentliche Träger (JA, Sozialamt)
  4. Staatliche Träger (BA, BAMF)

Praktisch:
  → Jugendhilfe: JA fördert freie Träger (§ 4 Abs. 2 SGB VIII)
  → Freie Träger haben Vorrang bei HzE wenn geeignet
  → Staat tritt erst ein wenn andere Hilfe versagt
```

### Bundesebene

| Institution | Aufgabe | Rechtsgrundlage |
|-------------|---------|-----------------|
| Bundesagentur für Arbeit (BA) | ALG I, Berufsberatung, Vermittlung | SGB III |
| Jobcenter (JC) | Bürgergeld, Eingliederung | SGB II |
| BAMF | Asylverfahren, Integrationskurse | AsylG, AufenthG |
| Deutsche Rentenversicherung (DRV) | Rente, Reha | SGB VI |
| GKV-Spitzenverband | Krankenversicherungspolitik | SGB V |

| Institution | Aufgabe | Zuständigkeit |
|-------------|---------|---------------|
| **Jugendamt (JA)** | Jugendhilfe, Kinderschutz, UhV | Kommunal (§§ 69–72 SGB VIII) |
| **Sozialamt** | SGB XII, AsylbLG, Wohnhilfen | Kommunal (§§ 97–100 SGB XII) |
| **Ausländerbehörde (ABH)** | Aufenthaltstitel, Einbürgerung | Kommunal (AufenthG) |
| **Pflegekasse** | Pflegeleistungen (SGB XI) | Teil der GKV |

## Die Sechs Wohlfahrtsverbände (BAGFW)

```
BAGFW = Bundesarbeitsgemeinschaft der freien Wohlfahrtspflege

Gründungsprinzip: weltanschauliche und konfessionelle Pluralität

1. DIAKONIE (evangelisch):
   → Verband der evangelischen Kirche
   → Angebote: Caritas-ähnlich (Beratung, Pflege, Jugendhilfe)
   → Groß: ca. 600.000 Mitarbeiter

2. CARITAS (katholisch):
   → Verband der katholischen Kirche
   → Breites Angebot: alle Bereiche
   → Größter Wohlfahrtsverband Deutschlands

3. AWO (Arbeiterwohlfahrt):
   → Sozialdemokratische Tradition
   → Unabhängig von Kirchen
   → Besonders: Jugendarbeit, Seniorenpflege

4. DRK (Deutsches Rotes Kreuz):
   → Humanitäre Tradition
   → Katastrophenschutz + Soziale Dienste
   → Blutspende, Rettungsdienst, Beratung

5. PARITÄTISCHER (DPWV):
   → Plural, laic, weltanschaulich ungebunden
   → "Dachverband" für viele kleine Vereine
   → Besonders: spezialisierte Einrichtungen

6. ZWST (Zentralwohlfahrtsstelle der Juden):
   → Verband der jüdischen Gemeinden
   → Kleiner, aber gleichberechtigt
```

## Spezielle Beratungsstellen und Einrichtungen

### Migration und Asyl

```
MBE — Migrationsberatung für erwachsene Zuwanderer:
  → Zuständig: Erwachsene mit Aufenthaltserlaubnis (Neuzuwanderer)
  → Finanziert: BMMI (Bundesministerium für Migration)
  → Träger: Wohlfahrtsverbände (Caritas, Diakonie, AWO, DRK, DPWV)
  → Leistung: Erstberatung, Sprachkursbegleitung, Verweisung

JMD — Jugendmigrationsdienst:
  → Zuständig: junge Menschen 12–27 Jahre mit Migrationsgeschichte
  → Träger: Wohlfahrtsverbände
  → Leistung: Schule, Ausbildung, Arbeitsmarkt

Flüchtlingsberatung (nicht MBE):
  → Für Asylsuchende und Personen mit ungesichertem Status
  → Träger: AWO, Caritas, Diakonie, Flüchtlingsräte, Pro Asyl-Netzwerk
  → Oft: Asylverfahrensberatung, rechtliche Begleitung
```

### Sucht und Gesundheit

```
Sucht- und Drogenberatungsstellen:
  → Alle Wohlfahrtsverbände betreiben Suchtberatung
  → Fachverband: DHS (Deutsche Hauptstelle für Suchtfragen)
  → Niedrigschwellig: kein Termin nötig, anonym möglich

Psychosoziale Beratungsstellen (PSB):
  → Verbunden mit psychiatrischen Versorgungszentren
  → Für Menschen mit psychischen Erkrankungen
  → Anbindung an Gemeindepsychiatrie (SpDi: Sozialpsychiatrische Dienste)
```

### Wohnungslosenhilfe

```
Wohnungslosenhilfe (§ 67 SGB XII):
  → Träger: Caritas, Diakonie, Bahnhofsmission, regionale Verbände
  → Unterkünfte, Kleiderkammer, Suppenküche
  → BAG W (Bundesarbeitsgemeinschaft Wohnungslosenhilfe): Dachverband
  → Housing First: neuere Ansätze (kommunale + freie Träger)
```

### Schuldnerberatung

```
Schuldnerberatung / Insolvenzberatung:
  → Rechtsgrundlage: § 305 InsO — Verbraucherinsolvenz braucht anerkannte Stelle
  → Träger: Caritas, AWO, VdK, Verbraucherzentrale, Kommunen
  → Kostenlos für Betroffene
  → Leistung: Schuldenanalyse, Verhandlung, Insolvenzantrag
  → WICHTIG: Schuldnerberatung ≠ Rechtsberatung
```

### Familienhilfe und Jugendhilfe

```
SPFH-Träger (Sozialpädagogische Familienhilfe):
  → Freie Träger im Auftrag des Jugendamts
  → § 31 SGB VIII
  → Caritas, Diakonie, AWO und viele kleinere Träger

Erziehungsberatungsstellen (§ 28 SGB VIII):
  → Kostenlos, ohne Anmeldung beim JA
  → Freie Träger (Caritas, Diakonie, AWO)
  → Themen: Erziehungsprobleme, Scheidung, Kindesentwicklung

Frauenhäuser (§ 36a WoSchG):
  → Schutz für von Gewalt betroffene Frauen (+ Kinder)
  → Träger: AWO, Caritas, Diakonie, autonome Frauenhäuser
  → Bundesweit ca. 350 Häuser
```

## Selbsthilfe und zivilgesellschaftliche Organisationen

```
Selbsthilfe (§ 20h SGB V — GKV-Förderung):
  → Sucht: AA, NA, Kreuzbund, Al-Anon
  → Psychische Erkrankungen: NAKOS (Selbsthilfe-Dachverband)
  → Behinderung: VdK, SoVD
  → Chronische Erkrankungen: Patientenverbände

Advocacy / Interessenvertretung:
  → Pro Asyl: Flüchtlingsschutz-Lobby
  → Paritätischer Wohlfahrtsverband: sozialpolitische Positionen
  → AWO: sozialdemokratisch geprägte Sozialpolitik
  → BAGFW: gemeinsame Positionen aller Wohlfahrtsverbände
```

## Wer zahlt wen? — Finanzierungslogik

```
Öffentliche Förderung:
  → Institutionelle Förderung: Träger bekommt Grundfinanzierung
  → Leistungsvereinbarung: konkrete Leistung gegen Preis (§ 78a SGB VIII)
  → Zuwendung: zweckgebundene Förderung (Projektstellen)

SGB-Finanzierung:
  → JA kauft Leistungen ein (§ 78a SGB VIII):
    → Leistungs-, Entgelt- und Qualitätsentwicklungsvereinbarung
  → Sozialamt (§§ 75ff. SGB XII): ähnliche Vereinbarungen
  → EGH-Träger: Verträge mit Einrichtungen

Ehrenamtliche Strukturen:
  → Viele Beratungsstellen: Mix aus Haupt- und Ehrenamt
  → Kleiderkammer, Tafeln: meist ehrenamtlich
```

## Vernetzung und Kooperation

```
Sozialraumteams / AK Soziale Arbeit:
  → Regionaler Austausch verschiedener Träger
  → Fallübergreifende Abstimmung (datenschutzkonform!)
  → Gemeinsame Ressourcennutzung

Case Management über Träger hinweg:
  → Federführung: meist JA oder Sozialamt
  → Koordiniert: BA, Pflegekasse, freie Träger
  → Klient: steht im Mittelpunkt (§ 10a SGB I Teilhabeplan)

Hilfeplanung (§ 36 SGB VIII, § 119 SGB IX):
  → Alle beteiligten Träger sitzen zusammen
  → Ziele: gemeinsam abgestimmt
  → Umsetzung: wer macht was bis wann?
```

## Schnell-Navigation: Wer ist für was zuständig?

```
Kein Geld / Arbeit → Jobcenter (SGB II) oder Sozialamt (SGB XII)
Kind in Not → Jugendamt (SGB VIII)
Pflegebedarf → Pflegekasse (SGB XI) + Sozialamt (§ 65 SGB XII)
Aufenthaltsstatus → Ausländerbehörde + Beratungsstelle
Behinderung → EGH-Träger (SGB IX) oder JA (§ 35a)
Überschuldung → Schuldnerberatung (freie Träger)
Sucht → Suchtberatung (freie Träger)
Häusliche Gewalt → Frauenhaus + JA (§ 8a SGB VIII wenn Kinder)
Obdachlosigkeit → Wohnungsamt + § 67 SGB XII-Träger
Flüchtling ohne Status → Asylberatung / MBE wenn Status anerkannt
```
