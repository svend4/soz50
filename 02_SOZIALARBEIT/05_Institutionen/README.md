## Wer ist zuständig? — Schnellübersicht

```
Frage → Zuständig

Ich habe keinen Job / kein Geld → Jobcenter (SGB II) oder Sozialamt (SGB XII)
Mein Kind braucht Hilfe → Jugendamt (SGB VIII)
Ich bin alt / krank und brauche Pflege → Pflegekasse (SGB XI) + Sozialamt (SGB XII)
Mein Aufenthaltsstatus ist unklar → Ausländerbehörde + Rechtsanwalt
Ich habe Schulden → Schuldnerberatung
Ich habe keinen Wohnraum → Wohnungsamt + Wohnhilfe
```
