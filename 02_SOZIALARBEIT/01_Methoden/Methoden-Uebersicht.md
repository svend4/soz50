# Methoden der Sozialen Arbeit — Überblick

[← Methoden](./README.md) | [← Sozialarbeit](../README.md)

> Methoden sind keine Schubladen. Sie sind Werkzeuge, die je nach Situation,
> Klient und Kontext kombiniert werden.
> Grundhaltung ist wichtiger als Technik.

---

## Klassische Grundmethoden

```
Drei klassische Methoden (seit Jane Addams / Mary Richmond):

1. EINZELFALLHILFE (Case Work / Einzelfallarbeit)
   → Arbeit mit dem einzelnen Menschen und seinem Umfeld
   → Diagnose → Planung → Intervention → Evaluation
   → Methode: Gesprächsführung, Hilfeplanung, Vermittlung

2. GRUPPENARBEIT (Group Work)
   → Arbeit mit Gruppen als Träger sozialer Lernprozesse
   → Therapeutische Gruppen, Selbsthilfegruppen, Bildungsgruppen
   → Methode: Gruppendynamik nutzen, Moderation

3. GEMEINWESENARBEIT (Community Work)
   → Arbeit mit dem Gemeinwesen, Stadtteil, Bevölkerungsgruppen
   → Strukturell ansetzen: Ressourcen aktivieren, Netzwerke aufbauen
   → Methode: Stadtteilbegehung, Befragung, Gemeinwesenkonferenzen
```

## Moderne Ansätze im Detail

### Ressourcenorientierung

```
Grundgedanke:
  → Jeder Mensch hat Stärken, Fähigkeiten, soziale Netzwerke
  → Sozialarbeit: nicht Defizite verwalten, sondern Stärken mobilisieren

Instrumente:
  → Ressourcenkarte: Visualisierung persönlicher Stärken
  → Öko-Karte (Ecomap): soziales Netz + Ressourcen aufzeigen
  → Fragen: "Was hat Ihnen bisher geholfen?"

Hintergrund:
  → Gegen defizitorientierte Problemsicht
  → Empowerment-Perspektive (Herriger)
  → Salutogenese (Antonovsky): Was erhält Gesundheit?
```

### Systemische Perspektive

```
Grundgedanke:
  → Problem nicht im Individuum, sondern in der Interaktion von Systemen
  → Familie, Schule, Arbeit, Behörden als Systeme, die wirken

In der Praxis:
  → Genogramm: Familiensysteme über Generationen visualisieren
  → Zirkuläre Fragen: "Was glauben Sie, wie Ihre Mutter das sieht?"
  → Lösungsfokussiert: "Angenommen das Problem wäre gelöst — wie würde das aussehen?"

Wichtig:
  → Nicht pathologisieren
  → Ressourcen des Systems aktivieren
  → Neutralität (Allparteilichkeit) als Grundhaltung
```

### Lebensweltorientierung (Hans Thiersch)

```
Kerngedanke:
  → Sozialarbeit muss von der Lebenswelt der Betroffenen ausgehen
  → Nicht von bürokratischen Kategorien oder professionellen Deutungen

Dimensionen der Lebenswelt:
  1. Raum: Wo lebt die Person? (Sozialraum, Nachbarschaft)
  2. Zeit: Welche Zeiterfahrungen hat die Person? (Dringlichkeit, Zukunft)
  3. Beziehungen: Wer gehört zum Lebensbereich?

Konsequenzen für Praxis:
  → Niederschwellig, aufsuchend
  → Sprache der Klienten aufnehmen (keine Fachterminologie)
  → Ort des Gesprächs: wo fühlt sich die Person sicher?
```

### Empowerment (Norbert Herriger)

```
Ziel: Autonomie und Selbstbestimmung stärken

Grundannahmen:
  → Menschen sind Experten ihrer eigenen Lebenssituation
  → Abhängigkeit von professionellen Helfern ist zu reduzieren
  → Eigene Stärken entdecken und nutzen

Empowerment-Prozess:
  1. Bewusstmachung der eigenen Stärken
  2. Analyse der Situation (was ist Fremd-, was ist Eigenverschulden?)
  3. Handlungsschritte entwickeln
  4. Umsetzung + Reflexion

Gefahr:
  → Empowerment nicht als Appell zur Eigenverantwortung missbrauchen
  → ("Selber schuld, wenn du nichts unternimmst")
  → Strukturelle Barrieren müssen benannt werden
```

## Case Management — Fallmanagement

```
Definition:
  → Koordination aller Hilfen für eine Person über Systemgrenzen
  → Besonders wenn viele Träger + Einrichtungen beteiligt sind

Phasen des Case Management:
  1. Intake / Screening: Wer kommt, was braucht er?
  2. Assessment: Umfassende Bedarfserfassung
  3. Zielplanung: Was soll erreicht werden?
  4. Service Planning: Welche Hilfen werden koordiniert?
  5. Implementation: Durchführung + Begleitung
  6. Monitoring: Läuft alles wie geplant?
  7. Evaluation: Wurden Ziele erreicht?
  8. Disengagement: Fallabschluss

Wo Case Management angewendet:
  → Eingliederungshilfe (Gesamtplan § 119 SGB IX)
  → Jugendhilfe (Hilfeplan § 36 SGB VIII)
  → Psychiatrie / psychiatrische Sozialarbeit
  → Pflege (Case Management in Pflegestützpunkten)
```

## Motivational Interviewing (MI)

```
Entwickelt von: William Miller / Stephen Rollnick

Ziel: Eigene Motivation des Klienten aktivieren — nicht Überreden!

Vier Grundprinzipien (RULE):
  R — Resist the righting reflex (Widerstehe dem Korrekturimpuls!)
  U — Understand client's motivation
  L — Listen to client
  E — Empower client

OARS-Techniken:
  O — Open Questions (offene Fragen)
  A — Affirmations (Bestätigungen, Anerkennung)
  R — Reflections (Spiegelungen)
  S — Summaries (Zusammenfassungen)

Umgang mit Ambivalenz:
  → Ambivalenz ist NORMAL — kein Zeichen von Unwillen!
  → "Ich weiß nicht ob ich das schaffe" → "Was glauben Sie, was für Sie sprechen würde?"
  → Decisional balance: "Was spricht dafür, was dagegen?"

Besonders geeignet:
  → Suchtberatung
  → Compliance bei Behandlung
  → Motivierung zu Verhaltensänderung (Arbeit, Schule)
```

## Trauma-informierte Praxis

```
Grundsatz: "Was ist mit Ihnen passiert?" statt "Was stimmt mit Ihnen nicht?"

Zehn Grundsätze trauma-informierter Sozialarbeit:
  1. Sicherheit herstellen (physisch + psychisch)
  2. Vertrauen aufbauen (Transparenz!)
  3. Peer-Support ermöglichen
  4. Kooperation + gegenseitige Hilfe
  5. Empowerment (Stärken betonen)
  6. Kulturelle Sensibilität

Trauma-Reaktionen erkennen:
  → Flashbacks, Dissoziation: nicht als "unkooperativ" deuten
  → Freeze-Reaktion: nicht als "Desinteresse"
  → Misstrauen: oft begründet durch vergangene Erfahrungen

Praktisch:
  → Stabilisierung vor Bearbeitung!
  → Überweisung an Traumatherapeuten wenn nötig
  → Keine Traumaexposition ohne Therapie erzwingen
  → § 35a SGB VIII: PTBS = seelische Behinderung → Hilfeanspruch!
```

## Krisenkompetenz

```
Krisenintervention — Erstmaßnahmen:
  1. Ruhe bewahren + Sicherheit signalisieren
  2. Aktives Zuhören (nicht bewerten!)
  3. Krisenauslöser verstehen
  4. Ressourcen aktivieren (Netzwerk, frühere Bewältigung)
  5. Konkrete nächste Schritte vereinbaren

Typen von Krisen:
  → Lebensereigniskrisen: Trennung, Todesfall, Jobverlust
  → Entwicklungskrisen: Pubertät, Rente, Übergänge
  → Traumatische Krisen: plötzliche Gewalt, Unfall

Suizidgefahr:
  → Direkt ansprechen: "Haben Sie Gedanken, sich etwas anzutun?"
  → Suizidgedanken ansprechen erhöht NICHT das Risiko!
  → Bei akuter Gefahr: 112 / psychiatrischer Notfalldienst
  → Telefonseelsorge: 0800 111 0 111 (kostenlos, 24h)
```

## Dokumentation als Methode

```
Warum dokumentieren?
  → Kontinuität bei Mitarbeiterwechsel
  → Nachvollziehbarkeit von Entscheidungen
  → Rechtssicherheit (Datenschutz, Schweigepflicht)
  → Selbstreflexion + Qualitätssicherung

Grundsatz: Was nicht dokumentiert ist, hat nicht stattgefunden!
  (Für Rechenschaftspflicht, Leistungsnachweis)

Dokumentationsregeln:
  → Sachlich, beschreibend (keine Wertungen ohne Begründung)
  → Unterschied: Beobachtung vs. Interpretation
    ("Klient war aggressiv" vs. "Klient hob die Stimme und verließ den Raum")
  → Datum + Uhrzeit immer!
  → Klient hat Recht auf Akteneinsicht (§ 25 SGB X)
```
