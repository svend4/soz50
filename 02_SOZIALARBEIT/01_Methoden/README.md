## Классические методы

| Метод | Описание |
|-------|---------|
| **Einzelfallhilfe** (Case Work) | Работа с отдельным клиентом — анализ, план, сопровождение |
| **Gruppenarbeit** (Group Work) | Работа в группе — терапевтические, образовательные группы |
| **Gemeinwesenarbeit** | Работа с сообществом — район, группы населения |

---

## Современные подходы

| Подход | Суть |
|--------|-----|
| **Systemische Beratung** | Клиент в контексте систем (семья, работа, окружение) |
| **Ressourcenorientierung** | Фокус на сильных сторонах клиента, не на дефицитах |
| **Lebensweltorientierung** (Thiersch) | Исходить из реального жизненного мира клиента |
| **Empowerment** | Усиление собственных возможностей клиента |
| **Motivational Interviewing** | Мотивационное интервью — работа с ambivalenz |
| **Trauma-informierte Arbeit** | Учёт травматического опыта в работе |

---

## Prozess der Einzelfallhilfe

```
1. Erstgespräch / Kontaktaufnahme
    ↓
2. Anamnese / Situationserfassung
    (Lebenslagenanalyse, Genogramm, Ressourcencheck)
    ↓
3. Diagnose / Problemdefinition
    (gemeinsam mit Klient!)
    ↓
4. Hilfeplanung
    (Ziele, Maßnahmen, Zeitplan)
    ↓
5. Intervention / Durchführung
    ↓
6. Evaluation
    (Hat die Hilfe gewirkt? Ziele erreicht?)
    ↓
7. Abschluss / Weiterleitung
```
