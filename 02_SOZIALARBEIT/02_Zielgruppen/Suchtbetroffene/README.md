## Sucht als Krankheit

```
Sucht (ICD-10: F10–F19) ist eine anerkannte Erkrankung:
  → Krankenkasse zahlt: Entgiftung + Entwöhnung (stationär)
  → Rentenversicherung zahlt: med. Reha (Langzeittherapie)
  → Suchtberatung: kostenlos (§ 28 SGB VIII / freie Träger)
```

---

## Häufige Suchtformen in der Sozialarbeit

| Sucht | Besonderheiten |
|-------|---------------|
| Alkohol | Sozial akzeptiert → Spätdiagnose; körperl. Abhängigkeit gefährlich |
| Cannabis | Legalisierung 2024 → neue Beratungsbedarfe |
| Opioide / Heroin | Substitutionsbehandlung (Methadon) verfügbar |
| Stimulanzien (Amphetamin, Kokain) | Kein Substitut — Abstinenztherapie |
| Medikamente | Oft unerkannt (Benzodiazepine, Schmerzmittel) |
| Glücksspiel | Verhaltenssucht — GKV-Leistungen begrenzt |

## Behandlungsstufen (Stufenmodell)

```
Stufe 1: Kontaktaufnahme / Beratung
  → Suchtberatungsstelle (ambulant, kostenlos)
  → Selbsthilfegruppen (AA, NA, Blaues Kreuz)

Stufe 2: Entgiftung (körperlich)
  → Stationär Krankenhaus (GKV zahlt, ca. 1–3 Wochen)
  → Körperliche Entgiftung (Entzug)

Stufe 3: Entwöhnung (psychisch)
  → Ambulante Entwöhnung (Suchtberatung + Gruppe, ca. 1 Jahr)
  → Stationäre Langzeittherapie (Rentenversicherung / GKV, 3–24 Monate)

Stufe 4: Nachsorge / Reintegration
  → Ambulante Nachsorge
  → Betreutes Wohnen
  → Wiedereingliederung Arbeit
```

---

## Substitutionsbehandlung (Opioide)

```
§ 13 Abs. 3 BtMG + BtMVV:
  → Methadon, Buprenorphin (Subutex) — durch zugelassene Ärzte
  → Ziel: Stabilisierung, Schadensbegrenzung (Harm Reduction)
  → Kein Beikonsum: Urinkontrollen
  → Heroingestützte Behandlung (Diamorphin) — in spez. Zentren

GKV zahlt Substitution wenn:
  → Langjährige Opiatabhängigkeit
  → Andere Therapien nicht erfolgreich
  → Zugelassener Arzt verschreibt
```

## Soziale Folgeprobleme und Hilfen

| Folgeproblem | Hilfe |
|-------------|-------|
| Bürgergeld-Entzug bei Sucht | Sucht allein kein Ausschlussgrund! |
| Schulden / Überschuldung | Schuldnerberatung parallel zu Suchtberatung |
| Wohnungslosigkeit | Betreutes Wohnen (§ 67 SGB XII) |
| Führerschein entzogen | MPU-Vorbereitung nach Therapie |
| Straffälligkeit | JVA-Sozialdienst, Bewährungshilfe |
| Familie / Kinder | § 8a beachten! Kinder schützen + Familie stärken |

## Arbeiten mit Suchtbetroffenen — Grundsätze

```
✓ Niedrigschwellig: kein Druck zur Abstinenz als Bedingung für Kontakt
✓ Harm Reduction: Schadensminimierung (Spritztausch, Safer Use)
✓ Motivational Interviewing: Ambivalenz explorieren, nicht konfrontieren
✓ Autonomie respektieren: Sucht ist Bewältigungsstrategie
✓ Geduld: Rückfälle sind Teil des Prozesses, kein Versagen
✓ Netzwerk: Arzt, Suchtberatung, Jobcenter, Wohnhilfe zusammendenken
```
