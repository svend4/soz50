# Zielgruppe Suchtbetroffene — Hilfen im Überblick

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Suchterkrankungen sind **anerkannte Krankheiten** (ICD-10 F10–F19).
> Krankenkasse und Rentenversicherung haben Pflichten zur Behandlung.
> Sozialarbeit mit Suchtbetroffenen erfordert akzeptierende Grundhaltung.

---

## Sucht als Krankheit — Rechtliche Grundlage

```
ICD-10 Klassifikation:
  F10: Alkohol
  F11: Opiate / Heroin
  F12: Cannabinoide
  F13: Sedativa / Benzodiazepine
  F14: Kokain
  F15: andere Stimulanzien (Amphetamine, Crystal)
  F19: mehrere Substanzen

Rechtsstatus:
  → Sucht = Krankheit → Behandlung durch GKV (§ 27 SGB V)!
  → Krankenkasse zahlt: Entgiftung, qualifizierter Entzug, Langzeittherapie
  → Rentenversicherung zahlt: Entwöhnungstherapie (§§ 9ff. SGB VI)
  → Beides zusammen nutzen!

Verschuldensfrage:
  → GKV darf Behandlung nicht wegen "Selbstverschulden" ablehnen
  → § 52 SGB V: nur wenn Person wissentlich Schaden herbeiführt (selten!)
  → Praxis: GKV muss behandeln
```

## Hilfesystem: Stufenmodell

```
1. PRÄVENTION und AUFKLÄRUNG
   → Schulen, Jugendarbeit, Medienkampagnen
   → Nichts hier für akute Beratung

2. FRÜHERKENNUNG / BERATUNG (ambulant)
   → Sucht- und Drogenberatungsstellen (kostenlos, anonym!)
   → Niedrigschwellig: kein Termin, keine Aufnahme nötig
   → Aufgaben: Beratung, Krisenintervention, Vermittlung in Hilfen

3. AMBULANTE BEHANDLUNG
   → Psychiatrische Ambulanz (PIA)
   → Niedergelassener Suchtmediziner
   → Ambulante Entwöhnung (Einzeltherapie)

4. STATIONÄRE ENTGIFTUNG
   → Krankenhaus (internistisch oder psychiatrisch)
   → Dauer: 1–4 Wochen
   → Ziel: körperlicher Entzug, medizinisch begleitet
   → Finanzierung: GKV

5. QUALIFIZIERTER ENTZUG
   → Psychiatrische Klinik
   → Entzug + psychosoziale Stabilisierung
   → Dauer: 3–6 Wochen
   → Finanzierung: GKV

6. ENTWÖHNUNG / LANGZEITTHERAPIE
   → Fachklinik (stationär: 3–24 Monate) oder ambulant
   → Finanzierung: Rentenversicherung! (§ 9 SGB VI)
   → Antragstellung: über Beratungsstelle oder Klinik
   → Wartezeit: 3–6 Monate nach Entzug

7. NACHSORGE + ADAPTIONEN
   → Übergangseinrichtung (Adabtion): zwischen Langzeittherapie und normalem Leben
   → Ambulante Nachsorge
   → Selbsthilfegruppen (AA, NA, KREUZBUND etc.)

8. HARM REDUCTION (parallel zu allem)
   → Drogenkonsumräume
   → Substituionsbehandlung (Methadon, Buprenorphin)
   → Naloxon-Abgabe
   → Tauschprogramme (Spritzen)
```

## Substitutionsbehandlung

```
§ 13 Abs. 3 BtMG iVm Betäubungsmittel-Verschreibungsverordnung (BtMVV):

Was:
  → Opiatabhängige erhalten Ersatzsubstanz (Methadon, Buprenorphin/Suboxone)
  → Entzug von Heroin ohne sofortige Abstinenzforderung
  → Stabilisierung, dann schrittweise Reduktion möglich

Ziele:
  → Reduktion des Beschaffungsstresses (keine Kriminalität nötig)
  → Schutz vor HIV/Hepatitis
  → Soziale Stabilisierung (Arbeit, Wohnen möglich)
  → Verminderung von Todesfällen durch Überdosierung

Zugang:
  → Substitutionstherapeut (Arzt mit Zertifikat)
  → Suchtberatung vermittelt
  → Wartelisten in manchen Städten!

GKV:
  → Substitution von GKV bezahlt
  → Kein Eigenanteil für Basissubstitution

Sozialrechtlich:
  → Substitution ≠ Drogenkonsum im SGB-II-Sinne
  → Person auf Substitution kann erwerbsfähig sein!
  → JC darf Substitution nicht als Hinderungsgrund für Arbeit sehen
```

## Entwöhnungstherapie über Rentenversicherung

```
"Reha vor Rente" — § 9 SGB VI:
  → DRV finanziert Entwöhnungstherapie wenn Erwerbsfähigkeit gefährdet

Voraussetzungen:
  1. Mindestens 15 Jahre Versicherungszeit ODER
  2. 6 Monate Pflichtbeitragszeiten in letzten 2 Jahren ODER
  3. Erwerbsminderung droht

Antrag:
  → Über Suchtberatungsstelle (!) — die kennen den Weg
  → DRV-Antrag auf Leistungen zur Teilhabe (§ 9 SGB VI)
  → Meist: Suchtberatung stellt Antrag mit Klientem zusammen

Ablauf:
  1. Entgiftung (KK) → danach Antrag DRV
  2. DRV prüft + genehmigt Klinik
  3. Aufnahme in Fachklinik
  4. Dauer: 12–26 Wochen (stationär) oder kürzer (ambulant)

Wenn keine Rentenversicherungszeiten:
  → Sozialhilfeträger (§ 53 SGB XII) als Fallback
  → Oder: gesundheitliche Rehabilitation (GKV § 40 SGB V)
```

## Sozialrechtliche Situation bei Suchterkrankung

```
SGB II (Bürgergeld):
  → Sucht ≠ automatisch nicht erwerbsfähig
  → JC-Vermittlung muss Sucht berücksichtigen
  → Eingliederungsmaßnahmen: Suchtberatung als Maßnahme möglich

  ABER: Regelmäßige Pflichtverletzungen wegen Sucht:
  → Sanktionen möglich (aber: Verschuldensausschluss bei Suchterkrankung prüfen!)
  → Wenn Sucht → Handlungsunfähigkeit → kein Verschulden!

SGB XII:
  → Wenn Sucht zu dauerhafter Erwerbsminderung führt:
    → § 41 SGB XII (Grundsicherung)
    → § 67 SGB XII (besondere soziale Schwierigkeiten)

EM-Rente:
  → Schwere Alkohol-/Drogenabhängigkeit + Folgeerkrankungen
    → EM-Rente prüfen! (DRV-Antrag)
  → Leberzirrhose, Kardiomyopathie, kognitive Einschränkungen

GKV-Kürzung bei "Selbstverschulden" (§ 52 SGB V):
  → Nur in sehr engen Grenzen erlaubt
  → Akutbehandlung: niemals kürzen!
  → Wiederholungsbehandlung: Kostenbeteiligung möglich
```

## Grundsätze akzeptierender Sozialarbeit

```
Akzeptierende Sozialarbeit (Harm Reduction):
  → Abstinenz ist NICHT Voraussetzung für Hilfe
  → Treffen des Menschen dort wo er ist
  → Keine Moralurteile
  → Sicherheit geht vor Abstinenz

Motivational Interviewing bei Sucht:
  → Ambivalenz normalisieren: "Das kenne ich von anderen Menschen auch"
  → Keine Konfrontation: nicht "Sie müssen aufhören"
  → Stattdessen: "Was würde sich ändern wenn Sie weniger trinken würden?"
  → Selbstwirksamkeit stärken

Rückfall:
  → Rückfall ist KEIN Versagen — gehört zum Krankheitsverlauf!
  → Rückfall aufgreifen: "Was ist passiert? Was können wir ändern?"
  → Keine Bestrafung, keine Ausschlüsse nach Rückfall

Grenzen der Beratung:
  → Bei Alkohol am Steuer: Meldepflicht? (Abwägung)
  → Akute Fremdgefährdung: Notruf 110/112
  → Kind in Gefahr durch Sucht der Eltern: § 8a SGB VIII!
```

  → Sucht & Drogen Hotline: 01806 313 031 (20 Ct./Verbindung)

Selbsthilfe:
  → Anonyme Alkoholiker (AA): www.anonyme-alkoholiker.de
  → Narcotics Anonymous (NA): www.na.org.de
  → Kreuzbund: www.kreuzbund.de
  → Al-Anon (Angehörige): www.al-anon.de

  → Entgiftungsstationen: nächstes Krankenhaus
  → Krisendienst: lokale Nummern (nicht bundeseinheitlich)
  → Drogenkonsumräume: in Großstädten

  → Bundesweite Drogenhotline: 0800 31 50 30 (kostenlos)
  → Eltern + Kinder: NACOA: www.nacoa.de
