# Zielgruppe Wohnungslose — Hilfen in der Praxis

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Wohnungslosigkeit hat viele Gesichter — von der verdeckten Wohnungslosigkeit
> bis zur chronischen Obdachlosigkeit. Sozialarbeit muss niedrigschwellig,
> akzeptierend und auf Eigenressourcen ausgerichtet sein.

---

## Phasen und Formen der Wohnungslosigkeit

```
Kontinuum der Wohnungslosigkeit (ETHOS-Klassifikation):

1. Obdachlos (auf der Straße):
   → Kein Dach über dem Kopf
   → Öffentlicher Raum, Notunterkünfte
   → Sofortiger Handlungsbedarf

2. In Notunterkünften:
   → Nachtasyle, Wärmestuben
   → Keine Dauerlösung

3. In Übergangswohnheimen:
   → Kurz- bis mittelfristig
   → Mit sozialpädagogischer Begleitung

4. Bei Bekannten/Verwandten ("Sofasurfer"):
   → Verdeckte Wohnungslosigkeit!
   → Oft übersehen — kein fester Rückhalt

5. Drohende Wohnungslosigkeit:
   → Kündigung erhalten
   → Räumungsklage läuft
   → Präventiver Handlungsbedarf
```

## Erstberatung: Sofortmaßnahmen

```
Checkliste beim ersten Kontakt:

Sofort sicherstellen:
  □ Unterkunft heute Nacht? (wenn nicht: Ordnungsamt / Notunterkunft)
  □ Krankheiten / Verletzungen? (Sanitäter, Krankenschein)
  □ Letzte Mahlzeit wann? (Tafel, Ausgabestellen)
  □ Dokumente vorhanden? (Ausweis, Meldebescheinigung)

Rechtlich klären:
  □ Bürgergeld / SGB XII beantragt? (SGB II braucht keine feste Adresse!)
  □ Postadresse? (Anlaufstelle kann als Adresse dienen)
  □ Krankenversicherung?
  □ Schulden? Haftstrafen? (können Wiedereingliederung erschweren)

Langfristig:
  □ Wohnungssuche möglich? Wenn nein, warum?
  □ Sucht / psychische Erkrankung?
  □ Soziales Netz (Familie, Freunde)?
```

## Sozialrechtliche Grundlagen

```
§ 67 SGB XII — Hilfen zur Überwindung besonderer sozialer Schwierigkeiten:
  → Rechtsanspruch auf Beratung + Begleitung
  → Hilfe bei Wohnungssuche, Schuldenregulierung, Behördengängen
  → Finanziert durch Sozialamt, oft an freie Träger delegiert

Ordnungsrechtliche Unterbringung:
  → Gemeinde MUSS Notunterkunft stellen (Polizeirecht)
  → Sofort, keine Bedürftigkeitsprüfung!
  → Kosten: erstmal Gemeinde (Rückforderung möglich)

SGB II bei Wohnungslosigkeit:
  → Antrag OHNE feste Adresse möglich!
  → "Gewöhnlicher Aufenthalt" reicht (§ 30 SGB I)
  → Postadresse: Beratungsstelle, Anlaufstelle, Behörde
  → KdU wird für Notunterkunft übernommen (§ 22 SGB II)

Krankenversicherung:
  → GKV-Mitglieder: Versicherung bleibt aktiv (Beitragsschulden: nachholen)
  → Nicht versichert: § 264 SGB V → Krankenhilfe durch Sozialamt
  → Kein Anspruch auf KV: § 25 SGB V → Behandlung für Obdachlose
```

## Wohnungssuche — Konkrete Unterstützung

```
Hürden bei Wohnungssuche:
  ✗ Keine Bonität (SCHUFA-Einträge, Mietschulden)
  ✗ Kein Bürgschaft-Einkommensnachweis
  ✗ Kein Arbeitgeberzeugnis
  ✗ Fehlende Referenzen vorangehender Vermieter
  ✗ Stigmatisierung ("Obdachloser als Mieter")
  ✗ Knapper Wohnungsmarkt in Ballungsräumen

Unterstützung durch Sozialarbeit:
  → Jobcenter-Bescheinigung über KdU-Übernahme (§ 22 Abs. 4 SGB II)
  → Garantieerklärung des JC / Sozialamts
  → Mietkaution: Darlehen über JC (§ 22 Abs. 6 SGB II)
  → Zielgruppenspezifische Wohnprojekte ("Housing First", Inklusionswohnen)
  → Sozialer Wohnungsbau: Dringlichkeitseinstufung beim Wohnungsamt

Housing First (Housing-First-Prinzip):
  → Zuerst stabile Wohnung, DANN Arbeit an anderen Problemen
  → Evidenzbasiert: bessere Ergebnisse als "erst abstinent, dann Wohnung"
  → In Deutschland: wachsend, aber noch nicht flächendeckend
```

## Sucht und Wohnungslosigkeit

```
Komorbidität: 60–70% der chronisch Wohnungslosen haben Suchtprobleme

Akzeptierende Sozialarbeit:
  → Keine Abstinenzforderung als Voraussetzung für Hilfe!
  → Harm Reduction: Risikominimierung, nicht Abstinenz
  → "Wet shelter" / akzeptierende Unterkünfte (Alkohol toleriert)

Sucht + SGB II:
  → Sucht ≠ automatisch nicht erwerbsfähig
  → JC kann Suchtberatung nicht erzwingen
  → Sanktionen wegen Pflichtverletzung trotzdem möglich

Niedrigschwellige Suchtberatung:
  → Drogenhilfe-Einrichtungen (konsumraumnah)
  → Substitutionsbehandlung: bei JC als Absicherung kommunizieren
  → Überleitung: Sucht → Therapie → Nachsorge → Wohnen

Sucht + EM-Rente:
  → Alkoholabhängigkeit kann Erwerbsminderung begründen
  → Bei langjähriger Sucht + Folgeerkrankungen: DRV-Antrag prüfen!
```

## Psychische Erkrankungen und Wohnungslosigkeit

```
Psychische Erkrankungen bei Wohnungslosen: bis 80%
  → Depression, Schizophrenie, Persönlichkeitsstörungen, PTBS

Versorgung:
  → SPZ (Sozialpsychiatrische Zentren): aufsuchend + niedrigschwellig
  → Psychiatrische Institutsambulanzen (PIA): spezialisiert
  → Kriseninterventionsteams (manche Städte)
  → GKV-Erstattung möglich wenn eingeschrieben

Betreutes Wohnen:
  → § 67 SGB XII + EGH SGB IX: für Menschen mit psych. Erkrankung + Wohnungslosigkeit
  → Ambulant betreutes Wohnen + Fachleistungsstunden
  → Ziel: schrittweise Selbstständigkeit

Forensische Psychiatrie:
  → Haftentlassene mit psych. Erkrankung: hohe Wohnungslosigkeitsrate
  → Übergangsmanagement aus Haft: § 67 SGB XII frühzeitig aktivieren
```

## Besondere Gruppen

```
FRAUEN:
  → Verdeckte Wohnungslosigkeit überproportional häufig
  → Frauenspezifische Unterkünfte (Schutz vor Gewalt!)
  → Oft: Häusliche Gewalt → Frauenhaus → dann Wohnungslosigkeit
  → Besonderer Bedarf: Gynäkologie, Verhütung, Begleitung

JUGENDLICHE (§ 41 SGB VIII: Hilfen für junge Volljährige):
  → 18–21 Jahre (bis 27 in begründeten Fällen)
  → JA muss weiterhelfen wenn Jugendhilfe-Bedarf fortbesteht
  → Übergang: Jugendhilfe → Erwachsenenbereich vermeiden!

EU-BÜRGER ohne SGB-II-Anspruch:
  → Ordnungsrechtliche Unterbringung immer!
  → § 23 Abs. 3 SGB XII: Ermessensleistung
  → Rückkehhilfe: freiwillige Heimreise kann organisiert werden

HAFTENTLASSENE:
  → § 67 SGB XII sofort nach Entlassung aktivieren
  → JC-Antrag am Entlassungstag stellen!
  → Führungsaufsicht: manchmal Wohnauflage (Adresse vorweisen)
```

## Streetwork und aufsuchende Sozialarbeit

```
Methodik:
  → Regelmäßige Präsenz an bekannten Aufenthaltsorten
  → Keine Erwartung von Gegenleistung
  → Vertrauen aufbauen = Grundlage für alles

Streetwork-Grundsätze:
  1. Parteilichkeit: Interessen der Zielgruppe vertreten
  2. Akzeptanz: ohne Vorbedingungen
  3. Niedrigschwelligkeit: minimale Zugangshürden
  4. Freiwilligkeit: kein Zwang
  5. Vertraulichkeit: Informationen schützen

Konkrete Angebote:
  → Erstversorgung (Kleidung, Essen, Hygiene)
  → Dokumentenbeschaffung (Ausweis ist Voraussetzung für fast alles!)
  → Begleitung zu Ämtern
  → Vermittlung in Beratungs-/Notunterkünfte
  → Krisenintervention
```
