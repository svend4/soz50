## Sofort-Check: Wie akut ist die Situation?

```
Frage 1: Hat die Person HEUTE eine Unterkunft?
    │
    ├─ JA (Wohnung, Notunterkunft, bei Freunden)
    │       → Reguläre Beratung möglich (s. Checkliste unten)
    │
    └─ NEIN (Straße, Bahnhof, Auto, keine Übernachtung)
            → AKUT — sofortige Vermittlung (s. Akutkontakte)
            → Notunterkunft anrufen → JETZT

Frage 2: Droht der Wohnungsverlust in nächster Zeit?
    ├─ Kündigung erhalten → Fristen klären! (s. unten)
    ├─ Mietrückstände → § 22 Abs. 8 SGB II-Antrag (s. unten)
    └─ Räumungsurteil → sofortiger Handlungsbedarf!
```

## Maßnahmen je nach Situation

### Fall A: Kündigung erhalten (noch nicht vollstreckt)

```
Schritt 1: Widerspruch prüfen (bei unwirksamer Kündigung)
  → § 543 BGB: fristlose Kündigung nur bei 2 Monatsmieten Rückstand!
  → § 569 BGB: Heilung möglich durch Zahlung innerhalb 2 Monate!
    Bei SGB II: Jobcenter informieren → § 22 Abs. 8 Antrag!

Schritt 2: § 22 Abs. 8 SGB II-Antrag (Mietschuldenübernahme)
  → Antrag beim Jobcenter SOFORT (nicht nach Räumungsklage!)
  → JC kann Schulden übernehmen WENN Wohnung erhalten werden kann
  → ACHTUNG: JC hat Ermessen — ablehnen möglich → Widerspruch!

Schritt 3: Schuldnerberatung
  → Gesamtschuldensituation prüfen
  → Ggf. Insolvenzverfahren

Schritt 4: Kommunale Wohnhilfe kontaktieren
  → Viele Kommunen haben Wohnhilfestellen (Sozialamt)
  → Können Vermieter kontaktieren, vermitteln
```

### Fall B: Räumungsklage / Räumungsurteil

```
Schritt 1: Prozesskostenhilfe beantragen
  → Bei Räumungsklage: Anwalt + PKH
  → Räumungsfrist beim Gericht beantragen (§ 721 ZPO)
    → Gericht kann bis zu 1 Jahr gewähren bei besonderer Härte!

Schritt 2: § 22 Abs. 8 SGB II — auch bei Räumungsurteil möglich!
  → Solange keine Räumung vollstreckt: JC kann noch einspringen
  → Argument: "Wohnung kann noch erhalten werden"

Schritt 3: Ordnungsamt informieren
  → Kommunen haben Pflicht zur Notunterbringung
  → Bei drohender Obdachlosigkeit: Ordnungsamt muss handeln
```

### Fall C: Bereits wohnungslos (obdachlos)

```
Schritt 1: Sofortunterbringung
  → Ordnungsamt: Pflicht zur Obdachlosenunterbringung!
  → Polizei bei akuter Gefahr (Kälte, Gesundheit)

Schritt 2: Krankenversicherung klären
  → Bürgergeld-Antrag stellt KV sicher
  → Bei Bürgergeld: KV über Jobcenter
  → Bei SGB XII: KV über Sozialamt
  → EU-Bürger ohne Status: BWKG (Bedürftig ohne KV) — Notversorgung

Schritt 3: Meldeanschrift sichern
  → Ohne Wohnung: Meldeadresse beim Sozialamt möglich (§ 23 BMG)
  → Oder: Briefadresse bei Beratungsstelle / Notunterkunft

Schritt 4: Hilfen nach § 67 SGB XII
  → Hilfen zur Überwindung besonderer sozialer Schwierigkeiten
  → Antrag beim Sozialamt
  → Leistungen: begleitetes Wohnen, Heimplatz, Beratung, Unterkunft

Schritt 5: Langfristige Wohnungssuche
  → Soziale Träger: Caritas, Diakonie, AWO
  → Kommunale Wohnungsbaugesellschaft (ggf. Sozialwohnungen)
  → Wohnungslosenhilfe des Wohlfahrtsverbands
```

## Besondere Personengruppen

### Geflüchtete / Menschen mit Duldung

```
→ AsylbLG statt SGB II/XII
→ Unterbringungspflicht der Ausländerbehörde / des Landes
→ Sammelunterkunft als "Unterkunft" (keine Wahl!)
→ Bei Obdachlosigkeit trotz Duldung: Sozialamt informieren
→ Wohnungssuche extrem schwer ohne Aufenthaltstitel
```

### EU-Bürger ohne Aufenthaltsrecht

```
→ Kein SGB II (BSG-Rechtsprechung)
→ § 23 Abs. 3 S. 2 SGB XII: Überbrückungsleistungen möglich
  (Essen, Unterkunft bis zur Ausreise)
→ Rückreisebeihilfe prüfen
→ In der Praxis: Caritas / Diakonie, Notfallhilfe
```

### Personen mit psychischer Erkrankung / Sucht

```
→ Niedrigschwellig! Kein Druck
→ Betreutes Wohnen prüfen (§ 67 SGB XII)
→ Psychiatrische Unterstützung parallel
→ Sozialpsychiatrischer Dienst einbeziehen
→ Betreuungsrecht prüfen (§ 1814 BGB) wenn nötig
```

## § 22 Abs. 8 SGB II — Mietschuldenübernahme (Muster)

```
An: Jobcenter [Stadt]
Von: [Name, Adresse, Kundennummer]
Betr.: Antrag auf Übernahme von Mietschulden gem. § 22 Abs. 8 SGB II

Ich beantrage hiermit dringend die Übernahme meiner aufgelaufenen
Mietschulden in Höhe von ________ €.

Begründung:
Die Wohnung kann nur erhalten werden, wenn die rückständigen
Mietzahlungen beglichen werden. Ohne Übernahme droht meine
Obdachlosigkeit, da der Vermieter die Kündigung bereits ausgesprochen
hat / Räumungsklage eingereicht hat.

Die Übernahme ist im Sinne des § 22 Abs. 8 S. 1 SGB II geboten,
da sie zur Sicherung der Unterkunft unerlässlich ist.

Ich bitte um sofortige Bearbeitung.
Datum, Unterschrift
```
