# Zielgruppe Senioren — Hilfen im Überblick

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Mit zunehmendem Alter wächst der Bedarf an Unterstützung — gleichzeitig
> sinkt oft die Fähigkeit, Ansprüche selbst geltend zu machen.
> Seniorenberatung muss niedrigschwellig, aufsuchend und barrierefrei sein.

---

## Häufige Bedarfslagen älterer Menschen

```
FINANZIELL:
  → Altersarmut (Rente unter Bedarf)
  → Grundsicherung im Alter (SGB XII) nicht beantragt!
  → Zuzahlungen für Medikamente, Heilmittel
  → Heimkosten (Eigentanteil Pflege)

GESUNDHEIT / PFLEGE:
  → Pflegebedürftigkeit (Pflegegrad)
  → Chronische Erkrankungen
  → Medikamenten-Management
  → Häusliche vs. stationäre Pflege

WOHNEN:
  → Barrierefreiheit in der Wohnung
  → Anpassung vs. Umzug ins Heim
  → Wohnberatung: Hilfsmittel, Umbau

SOZIAL:
  → Vereinsamung / Isolation
  → Trauer (Verlust von Partner, Freunden)
  → Kognitiver Abbau, Demenz

RECHTLICH:
  → Vollmachten, Patientenverfügung
  → Erbschaft, Schenkung
  → Betreuerbestellung (§§ 1814 ff. BGB)
```

## Grundsicherung im Alter (§§ 41–46b SGB XII)

```
Anspruch:
  → Personen ab 65 Jahren (oder: bei dauerhafter voller EM)
  → Bedürftigkeit: Einkommen + Vermögen deckt Bedarf nicht

Bedarf:
  → Regelsatz 2026: 563 € (Stufe 1, Alleinstehend)
  → KdU (Miete + Heizung)
  → Mehrbedarf (z.B. Merkzeichen G → 17%)

Einkommen + Vermögen:
  → Rente wird angerechnet (abzgl. Freibeträge)
  → Grundrente: bis 216 €/Monat anrechnungsfrei! (§ 82 Abs. 4 SGB XII)
  → Schonvermögen: 5.000 € (10.000 € bei Ehepaaren)
  → Eigenheim: nicht einzusetzen (§ 90 Abs. 2 Nr. 8 SGB XII)

KEIN Rückgriff auf Kinder (§ 94 Abs. 1a SGB XII):
  → Wenn Kinder < 100.000 € Jahreseinkommen: kein Unterhalt!
  → Das ist in 95% aller Fälle so!
  → Dieser Irrglaube hält viele Senioren vom Antrag ab!

Antragstellung:
  → Sozialamt (nicht Jobcenter!)
  → Oft: Sozialarbeiter/in kommt mit zum Amt (Begleitservice wichtig)

→ [SGB XII Einkommensanrechnung im Detail](../../../01_SOZIALRECHT/03_SGB_XII_Sozialhilfe/SGB-XII-Einkommensanrechnung.md)
```

## Pflege — SGB XI

```
Wenn Pflegebedürftigkeit besteht:

Antrag auf Pflegegrad:
  → Bei der Pflegekasse (Krankenkasse) beantragen
  → MD (Medizinischer Dienst) kommt zur Begutachtung
  → NBA-System: 6 Module (Mobilität, Kognition, Selbstversorgung...)
  → PG 1–5: je nach Schwere

Leistungen (ab PG 2):
  → Pflegegeld (wenn privat gepflegt):
    PG 2: 347 €, PG 3: 599 €, PG 4: 800 €, PG 5: 990 €/Monat
  → Pflegesachleistung (ambulanter Dienst):
    PG 2: 796 €, PG 3: 1.497 €, PG 4: 1.859 €, PG 5: 2.299 €

Wenn Pflegegeld nicht reicht:
  → Hilfe zur Pflege SGB XII (§§ 61–66 SGB XII)
  → Wenn Heimkosten Einkommen übersteigen → Sozialamt übernimmt Rest
  → Eigentum wird erst nach Tod des Heimbe wohners berücksichtigt
    (§ 102 SGB XII — Kostenersatz, aber: 3.214 € Freibetrag)

→ [Pflegegrad Berechnung im Detail](../../../01_SOZIALRECHT/05_SGB_XI_Pflege/Pflegegrad-Berechnung.md)
```

## Wohnen im Alter

```
Optionen:
  1. Eigene Wohnung (mit ambulanter Unterstützung)
     → Haushaltshilfe, Pflegedienst
     → Wohnraumanpassung (Haltegriffe, Treppenlift)
     → Finanzierung: KfW-Kredit, Pflegekasse (§ 40 Abs. 4 SGB XI: 4.000 €)

  2. Betreutes Wohnen / Service-Wohnen
     → Eigener Mietvertrag + Betreuungspauschale
     → Unabhängiger von Pflegebedarf
     → Kosten: je nach Anbieter

  3. Senioren-WG
     → Ambulant betreut, gemeinschaftlich
     → Kosten: KdU/SGB XII oder Eigenfinanzierung

  4. Heim (vollstationäre Pflege)
     → Bei schwerem Pflegebedarf
     → Eigenanteil: bundesweit 1.500–3.500 €/Monat
     → Bei Überschreitung: Hilfe zur Pflege SGB XII!
     → WICHTIG: Sozialamt rechtzeitig einschalten (bevor Ersparnisse aufgebraucht)

Wohnberatung:
  → Kommunale Wohnberatungsstellen
  → KfW-Programm: "Altersgerecht Umbauen" (Kredit oder Zuschuss)
  → BAGSO: Bundesarbeitsgemeinschaft der Seniorenorganisationen
```

## Rechtliche Vorsorge

```
Vorsorgevollmacht:
  → Regelung WER Entscheidungen trifft wenn Person nicht mehr kann
  → Empfehlenswert: schriftlich, idealerweise notariell beglaubigt
  → Ohne Vollmacht → Betreuungsgericht bestellt Betreuer

Patientenverfügung:
  → Regelung für medizinische Maßnahmen (z.B. Reanimation, künstliche Ernährung)
  → Bindend für Ärzte wenn Person nicht einwilligungsfähig

Betreuung (§§ 1814 ff. BGB):
  → Wenn keine Vollmacht: Familiengericht bestellt Betreuer
  → Betreuer: ehrenamtlich (Familie) oder beruflich (Betreuungsverein)
  → Betreuer darf NUR für zugewiesene Aufgabenkreise handeln!
  → Kontobetreuer ≠ Heilbehandlungsbetreuer (oft getrennt!)

Beratung:
  → Notare: für rechtssichere Dokumente
  → Betreuungsvereine: für laufende Betreuungsfragen
  → Rechtsberatung: VdK, Sozialverband, Mieterverein
```

## Häufige Irrtümer in der Seniorenberatung

```
IRRTUM 1: "Ich muss Kinder um Erlaubnis fragen"
  → FALSCH: Bei Grundsicherung im Alter KEIN Rückgriff auf Kinder
    (wenn deren Jahreseinkommen < 100.000 €)
  → Eigener Anspruch — Kinder haben kein Mitspracherecht!

IRRTUM 2: "Meine Wohnung wird gepfändet"
  → FALSCH: Selbstgenutztes Eigenheim = Schonvermögen (§ 90 Abs. 2 Nr. 8 SGB XII)
  → Solange Senior darin wohnt: kein Einsatz erforderlich

IRRTUM 3: "Für Sozialhilfe muss ich mein Erspartes aufbrauchen"
  → TEILWEISE FALSCH: Schonvermögen 5.000 € (10.000 € Ehepaar) bleibt
  → Gesundheitlich notwendige Rücklagen: oft anerkennbar
  → Riester-Rente: geschützt (§ 90 Abs. 2 Nr. 2 SGB XII)

IRRTUM 4: "Heimkosten zahle ich selbst oder gar nicht"
  → FALSCH: Wenn Einkommen und Vermögen nicht reichen → SGB XII!
  → Hilfe zur Pflege (§ 61 SGB XII) übernimmt Differenz
  → Antrag beim Sozialamt stellen!

IRRTUM 5: "Pflegegrad wird automatisch erhöht"
  → FALSCH: Antrag auf Neubewilligung stellen bei Verschlechterung!
  → Pflegegrad wird nicht automatisch angepasst
  → Neubegutachtung beantragen!
```

## Beratungssetting Senioren

```
Besonderheiten:
  → Barrierefreiheit: Sprechzeiten + Räume zugänglich
  → Hausbesuche: wenn Mobilität eingeschränkt
  → Zeitaufwand: mehr Zeit pro Beratung einplanen
  → Gehör/Sehbeeinträchtigungen: laut/deutlich sprechen, große Schrift

Angehörige einbeziehen:
  → Mit Einverständnis: Angehörige können wichtige Informationen liefern
  → ABER: Datenschutz! Nur wenn Senior einwilligt
  → Pflegende Angehörige selbst beraten (Überlastung, eigene Bedarfe)

Netzwerk:
  → Seniorenbüros / Beratungszentren (kommunal)
  → VdK, SOVD, Sozialverband
  → Alzheimer Gesellschaft (bei Demenz)
  → Wohlfahrtsverbände: Beratung + praktische Hilfen
  → Hospiz-/Palliativberatung (bei lebensbeendenden Erkrankungen)
```
