## Typische Problemlagen

| Problemlage | Relevante Hilfe |
|-------------|----------------|
| Altersarmut (Rente zu gering) | Grundsicherung § 41 SGB XII |
| Pflegebedürftigkeit | SGB XI, SGB XII § 61ff |
| Einsamkeit / soziale Isolation | Besuchsdienste, Tagesangebote |
| Wohnungsanpassung | KfW-Förderung, EGH |
| Demenz | Pflegegrad, Betreuung, § 1814 BGB |
| Sucht (Alkohol) | Suchtberatung + geriatrische Versorgung |
| Häusliche Gewalt | Beratung, ggf. Heimunterbringung |
| Schulden / Überschuldung | Schuldnerberatung, Insolvenz |
| Fehlende Krankenversicherung | § 264 SGB V, KVdR |

## Grundsicherung im Alter (§ 41 SGB XII)

→ Ausführlich: [Grundsicherung](../../../01_SOZIALRECHT/03_SGB_XII_Sozialhilfe/Grundsicherung/)

```
Ab Regelaltersgrenze (67 Jahre):
  → Antrag beim Sozialamt
  → Eigeneinkommen (Rente) wird angerechnet
  → Vermögen bis 5.000 € (Einzel) / 10.000 € (Paar) geschützt
  → Kinder haften NICHT mehr (Reform 2020 — ab 100.000 € Jahreseinkommen)
```

**Wichtig: Viele Anspruchsberechtigte stellen keinen Antrag!**
Schamgefühl, fehlendes Wissen → proaktiv informieren.

## Pflegegrade — Antrag und Begutachtung

```
Schritt 1: Antrag bei Pflegekasse (formlos, telefonisch)
           → Antrag → Begutachtungsfrist: 5 Wochen (sonst Entschädigung!)

Schritt 2: Begutachtung durch MDK (Medizinischer Dienst)
           → Hausbesuch (mit Angehörigen anwesend sein!)
           → 6 Lebensbereiche werden bewertet (NBI)

Schritt 3: Bescheid
           → Bei zu niedrigem Grad: Widerspruch + Gegengutachten

Tipps für Begutachtung:
  → Pflegetagebuch führen (min. 2 Wochen vor Termin)
  → Alle Einschränkungen beschreiben — auch gute Tage
  → Angehörige / Pflegeperson anwesend
  → Wohnung zeigen (Hilfsmittel sichtbar)
```

## Betreuung (§ 1814 BGB — seit 2023)

```
Wann:
  → Volljähriger kann seine Angelegenheiten nicht mehr regeln
  → (Demenz, psychische Erkrankung, geistige Behinderung)

Wer bestellt:
  → Betreuungsgericht (Amtsgericht)
  → Antrag: Betroffener selbst, Angehörige, Behörden, Betreuungsstelle

Wer wird Betreuer:
  1. Angehörige (bevorzugt)
  2. Ehrenamtliche Betreuer
  3. Berufsbetreuer (vergütet)

Aufgabenbereiche (nur so viele wie nötig!):
  → Gesundheitssorge
  → Vermögenssorge
  → Aufenthaltsbestimmung
  → Behördenangelegenheiten

Vorsorgevollmacht empfehlen! (verhindert Betreuung)
```

## Vorsorgedokumente — важно рекомендовать клиентам

| Dokument | Inhalt |
|----------|--------|
| **Vorsorgevollmacht** | Bevollmächtigt Vertrauensperson für alle Bereiche |
| **Patientenverfügung** | Medizinische Wünsche für Notfallsituationen |
| **Betreuungsverfügung** | Wer soll Betreuer werden (wenn Betreuung nötig wird) |

> Notariell beglaubigt = höchste Rechtssicherheit.
> Beim Notar: ca. 50–150 €. Ohne Notar auch gültig (eigenhändig + Datum + Unterschrift).

## Erste Beratung — Checkliste Senior

```
[ ] Rentenanspruch bekannt? (Deutsche Rentenversicherung — Rentenauskunft)
[ ] Grundsicherungsanspruch geprüft? (oft nicht beantragt!)
[ ] Pflegegrad vorhanden / beantragt?
[ ] Wohnverhältnis: allein? Barrierefrei?
[ ] Angehörige? Unterstützungsnetz?
[ ] Vorsorgedokumente vorhanden?
[ ] Gesundheit: Chronische Erkrankungen? Medikamente? Arzttermine?
[ ] Einsamkeit / Kontakte? (soziale Isolation prüfen)
[ ] Kognitive Einschränkungen? (Demenz-Anzeichen?)
[ ] Finanzen: Schulden? Kontozugang klar?
```
