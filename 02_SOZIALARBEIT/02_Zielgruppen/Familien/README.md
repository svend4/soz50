## Typische Problemlagen

| Problemlage | Häufigkeit | Relevante Hilfen |
|-------------|-----------|-----------------|
| Finanzielle Not / Bürgergeld | sehr häufig | SGB II, § 22, Mehrbedarf |
| Alleinerziehend | häufig | UVG, Mehrbedarf § 21, SPFH |
| Erziehungsprobleme | häufig | HzE § 27ff SGB VIII |
| Häusliche Gewalt | häufig | Frauenhaus, § 1 GewSchG |
| Wohnungsprobleme | häufig | § 22 SGB II, § 67 SGB XII |
| Schuldenprobleme | häufig | Schuldnerberatung |
| Sucht (Elternteil) | mittel | Suchtberatung + § 8a |
| Trennung / Scheidung | mittel | Beratungsstelle, FamG |
| Pflege Angehöriger | mittel | SGB XI, Pflegegeld |

## Leistungen für Familien — Übersicht

### Bürgergeld-Leistungen für Familien

```
Regelbedarf:
  Alleinstehender Elternteil: Stufe 1 (563 €)
  Partner: Stufe 2 (je 506 €)
  Kinder je nach Alter: Stufe 4–6 (357–471 €)

Mehrbedarf Alleinerziehende (§ 21 Abs. 3 SGB II):
  1 Kind unter 7 / max. 2 unter 16: 36% Regelbedarf
  1 Kind ab 7 / mehr Kinder: gestaffelt
  Maximum: 60% Regelbedarf

KdU: Miete + Heizung (§ 22 SGB II) — angemessen

Bildungs- und Teilhabepaket (§ 28 SGB II):
  Schulbedarf: 116 €/Schuljahr (2 Raten)
  Schulausflüge, Klassenfahrten
  Mittagessen in Schule/Kita
  Nachhilfe (Lernförderung)
  Vereinsmitgliedschaft / Freizeit: 15 €/Monat
```

### Familienleistungen außerhalb SGB II

| Leistung | Betrag | Zuständig |
|---------|--------|----------|
| Kindergeld | 250 €/Kind/Monat | Familienkasse BA |
| Kinderzuschlag (KiZ) | max. 292 €/Kind | Familienkasse BA |
| Elterngeld | 65% Nettolohn, mind. 300 € | Elterngeldstelle |
| Unterhaltsvorschuss (UVG) | 230–394 €/Monat | Jugendamt |
| Wohngeld | je nach Haushalt | Wohnungsamt |

## Kinderzuschlag (KiZ) — важный инструмент

```
KiZ ist sinnvoll wenn:
  → Familie würde NUR wegen Kinderkosten Bürgergeld benötigen
  → Eltern haben eigenes Einkommen (auch geringes)
  → Mit KiZ + Wohngeld: kein Bürgergeld mehr nötig!

Höhe: max. 292 €/Kind/Monat (2026)
Beantragung: Familienkasse (nicht Jobcenter!)
Online: familienkasse.de
```

## Häusliche Gewalt — was tun?

```
Akuter Fall:
  → Polizei: 110
  → Frauenhaus (anonym, sofortiger Schutz)
  → Platzverweis für Täter (§ 1 GewSchG)

Danach:
  → Beratungsstelle (z.B. Caritas, Diakonie, Wildwasser)
  → Gewaltschutzanordnung beim Familiengericht (§ 1 GewSchG)
  → Neue Wohnung + KdU-Erstattung (auch ohne Kündigung alte Wohnung!)
  → SGB II-Antrag beim neuen Jobcenter (Schutzadresse möglich)
```

## Erste Beratung — Checkliste Familie

```
[ ] Welche Kinder? (Alter, Schule, Kita)
[ ] Einkommen? (Arbeit, Rente, Unterhalt, Kindergeld)
[ ] Wohnsituation? (Miete, Schulden, Kündigung?)
[ ] Rechtliche Situation? (Trennung, Sorgerecht, Unterhalt)
[ ] Gesundheit? (Krankheiten, Behinderung, Schwangerschaft)
[ ] Aufenthaltsstatus? (bei nicht-deutschen Familien)
[ ] Dringende Bedarfe? (Strom/Gas abgestellt? Schulden?)
[ ] Kindeswohlgefährdung? (§ 8a prüfen!)
```
