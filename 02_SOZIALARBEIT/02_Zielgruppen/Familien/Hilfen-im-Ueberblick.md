# Zielgruppe Familien — Hilfen im Überblick

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Familien sind die komplexeste Zielgruppe: Mehrere Sozialgesetzbücher
> berühren sie gleichzeitig. Kinder haben eigene Rechte — unabhängig von Eltern.

---

## Bedarfslagen typischer Familien in der Beratung

```
Häufig kombinierte Bedarfe:

Finanziell:
  → Bürgergeld (SGB II) — meist Hauptleistung
  → Kindergeld + KiZ (Kinderzuschlag)
  → Unterhaltsvorschuss (wenn ein Elternteil fehlt)
  → BuT (Bildung und Teilhabe) für Kinder

Erziehung / Entwicklung:
  → HzE (SGB VIII) — wenn Erziehung überfordert
  → SPFH — aufsuchende Familienunterstützung
  → Kita-Platz / Tagespflege

Wohnen:
  → Angemessene Wohnung (KdU)
  → Schutzwohnung bei häuslicher Gewalt

Gesundheit:
  → GKV für Kinder (kostenfrei in der Familienversicherung)
  → Hebamme + Frühe Hilfen (bei Neugeborenen)
  → Kinderärztliche Versorgung
```

## Finanzielle Leistungen für Familien

### Kindergeld

```
Anspruch: Alle Eltern für Kinder bis 18 Jahre
  (Verlängerung bis 25 wenn: Ausbildung/Studium, Arbeitssuchend bis 21)

2026: 255 €/Monat pro Kind (alle Kinder gleich)

Beantragung: Familienkasse der Bundesagentur für Arbeit
  → Online: familienkasse.de
  → Tipp: Antrag rückwirkend max. 6 Monate möglich!

Anrechnung SGB II:
  → Kindergeld wird auf Kinderbedarf in BG angerechnet (§ 11 Abs. 1 S. 4 SGB II)
  → Logik: Kind bekommt Regelsatz − Kindergeld vom JC = Rest
```

### Kinderzuschlag (KiZ)

```
§ 6a BKGG: Bis 292 €/Monat pro Kind (2026)

Voraussetzungen:
  → Eltern verdienen mind. 900 € (Paare) oder 600 € (Alleinerziehende)
  → Gesamt-Einkommen reicht nicht für Familie → KiZ + Wohngeld schließt Lücke
  → KiZ verhindert SGB-II-Antrag → kein Bürgergeld nötig!

Beantragung: Familienkasse
  → Antrag online: arbeitsagentur.de
  → Prüfrechner online verfügbar

Kombination:
  → KiZ + Wohngeld kann SGB II komplett ersetzen!
  → BuT bleibt trotz KiZ (§ 6b BKGG)
```

### Unterhaltsvorschuss

```
UhVG: Staatliche Vorleistung wenn Elternteil Unterhalt nicht zahlt

Voraussetzungen:
  → Alleinerziehend mit Kind bis 18 Jahren
  → Unterhaltspflichtiger zahlt nicht (< Mindestunterhalt)

Beträge 2026:
  → bis 5 Jahre:  227 €/Monat
  → 6–11 Jahre:  266 €/Monat (Schätzung, jährlich angepasst)
  → 12–17 Jahre: 303 €/Monat

Beantragung: Jugendamt (Unterhaltsvorschussstelle)

Wichtig:
  → UhV wird nicht auf SGB-II-Anspruch angerechnet wenn unter Regelsatz des Kindes
  → Aber: Jobcenter rechnet UhV als Einkommen des Kindes an — klären!
  → Jugendamt holt Unterhalt beim Vater/Mutter zurück (Regressverfahren)
```

### Elterngeld

```
BEEG: Einkommensersatz bei Babypause

Basiselterngeld: 65–67% des Nettoeinkommens (Durchschnitt 12 Monate vor Geburt)
  → Mindest: 300 €/Monat
  → Höchst: 1.800 €/Monat
  → Bezugsdauer: 12 Monate (14 Monate wenn beide Elternteile teilnehmen)

ElterngeldPlus: halbe Monate, doppelte Dauer
Partnerschaftsbonus: je 4 weitere Monate wenn beide Teilzeit 25–32h

SGB-II-Bezieher:
  → Elterngeld bis 300 € anrechnungsfrei (§ 10 Abs. 5 BEEG)
  → Darüber: wird als Einkommen angerechnet
  → Tipp: Für SGB-II-Haushalte kaum Mehrgewinn durch höheres Elterngeld!

Beantragung: Elterngeldstelle des Landes (meist beim Versorgungsamt)
```

## Frühe Hilfen

```
Nationales Zentrum Frühe Hilfen (NZFH):
  Unterstützung für Familien mit Kindern 0–3 Jahre

Leistungen:
  → Familienhebammen (auch nach 8. Woche nach Geburt)
  → Familiengesundheitspflegerinnen
  → Ehrenamtliche Besuchsdienste
  → Eltern-Kind-Kurse, Mütterzentren

Anknüpfung:
  → Finanziert über Bundesstiftung "Frühe Hilfen" + Länder + Kommunen
  → Kein Antrag auf Sozialleistung — niedrigschwellig!
  → Kontakt: Jugendamt, Geburtsklinik, Kinderarzt
```

## Erzieherische Hilfen (SGB VIII)

```
Wenn Erziehung in der Familie überfordert ist:

Beratung (§ 28 SGB VIII):
  → Erziehungsberatungsstellen: kostenlos, anonym möglich
  → Kein Antrag beim JA nötig!

SPFH (§ 31 SGB VIII):
  → Aufsuchende Familienhilfe (5–20 Std/Woche in der Familie)
  → Rechtsanspruch! — kein Ermessen des JA ob Hilfe gewährt wird
  → Kostenlos für Eltern

Tagesgruppe (§ 32 SGB VIII):
  → Kind tagsüber in betreuter Gruppe + abends zuhause
  → Ersetzt manchmal Heimunterbringung

Vollzeitpflege (§ 33 SGB VIII):
  → Kind lebt in Pflegefamilie
  → Kontakt zu Eltern bleibt (Besuchsrecht)

→ [HzE Anspruch im Detail](../../../01_SOZIALRECHT/04_SGB_VIII_Jugendhilfe/Hilfen_zur_Erziehung/HzE-Anspruch.md)
```

## Häusliche Gewalt — Schutzmaßnahmen

```
Sofortmaßnahmen bei häuslicher Gewalt:

1. Polizei (Platzverweisung gegen Täter — § 34a PolG)
   → Täter muss Wohnung verlassen (10–14 Tage)
   → Verlängerung durch Familiengericht (Kontaktverbot, § 1 GewSchG)

2. Frauenhaus / Schutzunterkunft:
   → Kostenlos für Frau und Kinder
   → Finanzierung: SGB II (KdU für Frauenhaus) oder Sozialhilfe
   → Adresse geheim

3. Finanzsicherung im Frauenhaus:
   → SGB-II-Antrag am neuen Ort! (JA des alten Orts wird zuständig bis Umzug offiziell)
   → Kinder mit im neuen JA-Bereich miterfassen

4. Rechtliche Schritte:
   → Strafanzeige (Körperverletzung, § 223 StGB; Bedrohung, § 241 StGB)
   → Gewaltschutzantrag beim Familiengericht (§ 1 GewSchG)
   → Beratung: Weißer Ring, Frauenhaus, Opferschutzverbände
```

## Kinder mit besonderen Bedarfen

```
Chronisch kranke Kinder:
  → GKV übernimmt Behandlung (Familienversicherung bis 25 kostenlos)
  → Krankenhilfe SGB XII wenn keine GKV (z.B. AsylbLG)
  → Hilfs-/Pflegemittel: GKV oder § 33 SGB V

Kinder mit Behinderung (körperlich/geistig):
  → EGH nach SGB IX (Eingliederungshilfe durch Sozialamt)
  → Frühförderung (§§ 79–82 SGB IX + Landesrecht)
  → Assistenz in Schule / Kita

Kinder mit seelischer Behinderung:
  → § 35a SGB VIII (Eingliederungshilfe vom Jugendamt!)
  → Schulbegleitung, Heilpädagogik
  → Kinder- und Jugendpsychiatrie

UMA (Unbegleitete minderjährige Ausländer):
  → § 42a SGB VIII: Sofortige Inobhutnahme durch JA
  → Leistungen nach SGB VIII (kein AsylbLG!)
  → Vormund bestellen lassen
```

## Praxis: Erstberatung Familien — Checkliste

```
1. Familiensituation klären:
   □ Zusammenlebend? Getrennt? Alleinerziehend?
   □ Kinder: Wie viele, wie alt?
   □ Aufenthaltsstatus Eltern + Kinder?

2. Finanzielle Situation:
   □ Einkommen? Bürgergeld? KiZ? UhV?
   □ Kindergeld beantragt?
   □ BuT beantragt? (Schulbedarf, Mittagessen!)

3. Erziehungssituation:
   □ Gibt es Überforderung?
   □ Schule, Kita, Entwicklung der Kinder ok?
   □ HzE bereits beantragt / laufend?

4. Wohnsituation:
   □ Angemessene Wohnung?
   □ Umzug nötig? (KdU-Kostensenkung?)
   □ Häusliche Gewalt? → sofort ansprechen!

5. Gesundheit:
   □ GKV für alle Familienmitglieder?
   □ Chronische Erkrankungen?
   □ Frühe Hilfen (bei 0–3 Jährigen)?
```
