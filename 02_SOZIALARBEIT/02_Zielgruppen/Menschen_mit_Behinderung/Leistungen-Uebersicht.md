# Zielgruppe Menschen mit Behinderung — Leistungsübersicht

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Menschen mit Behinderung haben Anspruch auf **Teilhabe** — nicht nur Pflege.
> Seit BTHG 2020 ist das Leitbild: **Personenzentrierung + Selbstbestimmung**.
> Wichtig: Mehrere Träger können gleichzeitig zuständig sein!

---

## Wer gilt als Mensch mit Behinderung?

```
§ 2 SGB IX:
  "Menschen mit Behinderungen sind Menschen, die körperliche, seelische,
   geistige oder Sinnesbeeinträchtigungen haben, die sie in Wechselwirkung
   mit einstellungs- und umweltbedingten Barrieren an der gleichberechtigten
   Teilhabe an der Gesellschaft mit hoher Wahrscheinlichkeit länger als
   sechs Monate hindern können."

→ ICF-basiert: Beeinträchtigung + Barrieren = Behinderung
→ KEIN GdB erforderlich für EGH-Leistungen!
→ GdB relevant für: Schwerbehindertenausweis + spezielle Leistungen
```

## Feststellung des Grades der Behinderung (GdB)

```
Zuständig: Versorgungsamt (in manchen Ländern: Landesamt für Soziales)

Antrag:
  → Formlos oder Formular beim Versorgungsamt
  → Mit ärztlichen Befundberichten, Krankenhausentlassungsbriefen

GdB-Skala: 20, 30, 40, 50, 60, 70, 80, 90, 100
  → Ab GdB 50: "Schwerbehindert" (§ 2 Abs. 2 SGB IX)
  → Schwerbehindertenausweis (gelb, ab GdB 50)

Merkzeichen:
  G:  Gehbehinderung (erhebliche Mobilitätseinschränkung)
  aG: Außergewöhnliche Gehbehinderung (Rollstuhl etc.)
  H:  Hilflosigkeit (Anspruch auf Pflegegeld steuerrechtlich)
  B:  Begleitperson erforderlich
  Bl: Blind
  Gl: Gehörlos
  RF: Rundfunkbeitragsbefreiung
  1.  Klasse: Berechtigung 1. Klasse im Zug mit 2.-Klasse-Ticket
```

## Eingliederungshilfe (EGH) — SGB IX Teil 2

```
Seit BTHG 2020: EGH vollständig in SGB IX (früher SGB XII)

Zuständiger Träger: EGH-Träger (meist Bezirk/LWV/LVR, je nach Bundesland)
  → NICHT das Sozialamt!
  → NICHT das Jobcenter!

Wer hat Anspruch (§§ 99, 53 SGB IX):
  → Körperliche, geistige, seelische oder Sinnesbeeinträchtigung
  → Teilhabe an der Gesellschaft ist wesentlich eingeschränkt
  → KEIN GdB-Mindestgrenze! (aber GdB 50+ erleichtert Nachweis)

Leistungen (§§ 78–116 SGB IX):
  1. Leistungen zur Medizinischen Rehabilitation
  2. Leistungen zur Teilhabe am Arbeitsleben
  3. Leistungen zur Bildung
  4. Leistungen zur sozialen Teilhabe:
     → Assistenz (§ 78 SGB IX) — wichtigste Leistung!
     → Heilpädagogische Leistungen
     → Förderung sozialer Beziehungen
     → Teilhabe an Gemeinschaftsveranstaltungen
  5. Leistungen zur Teilhabe an Bildung
```

### Assistenz — die zentrale EGH-Leistung

```
§ 78 SGB IX — Assistenz:
  → Unterstützung bei allen Aktivitäten des täglichen Lebens
  → Arbeit, Freizeit, Kommunikation, soziale Kontakte
  → KEIN Haushalt! (das ist Pflege → SGB XI)
  → Arbeitgebermodell möglich: Betroffener ist Arbeitgeber der Assistenz

Persönliches Budget (§ 29 SGB IX):
  → Alternative zu Sachleistung!
  → Betroffener erhält Geldbetrag und kauft Leistungen selbst ein
  → Stärkt Selbstbestimmung enorm
  → SUBJEKTIVES RECHT — kann nicht einfach verweigert werden!
  → Antrag: beim EGH-Träger stellen
```

## Gesamtplan und Bedarfsermittlung

```
§§ 117–122 SGB IX:

Gesamtplanverfahren:
  1. Antrag beim EGH-Träger
  2. Bedarfsermittlung: ICF-basiertes Instrument (je nach Bundesland verschieden)
     → ITP (Individueller Teilhabeplan)
     → BENI, BEI_BW, METZLER etc. — je nach Bundesland
  3. Gesamtplangespräch mit Betroffenem (§ 117 SGB IX)
     → Betroffener hat Recht auf Unterstützung durch Person seiner Wahl!
  4. Gesamtplan = Bewilligung + Leistungsbeschreibung
  5. Überprüfung: mind. alle 2 Jahre

Frist:
  → EGH-Träger muss innerhalb 2 Monate nach Antrag entscheiden
  → Verzögerung → Untätigkeitsklage VG möglich!

Wunsch- und Wahlrecht (§ 8 SGB IX):
  → Träger und Einrichtung frei wählbar
  → Mehrkosten-Zumutbarkeit: 25% teurer = noch zumutbar (Faustformel)
```

## Wohnen mit Behinderung

```
EGH-Leistungen für Wohnen (§ 78 SGB IX):

Eigene Wohnung (ambulant betreutes Wohnen):
  → Assistenz in der eigenen Wohnung
  → Unterstützung bei Alltagsgestaltung
  → Wunsch- und Wahlrecht: wer betreut, wer assistiert

Wohngemeinschaft / besondere Wohnformen (§ 42a SGB XII):
  → Gemeinschaftlich mit anderen Betroffenen + Unterstützung
  → Kosten: Trennung EGH (Fachleistung) + Grundsicherung (Lebensunterhalt)
  → § 42a SGB XII: Unterkunftskosten in besonderen Wohnformen übernommen

Vollstationär (Heimunterbringung):
  → Nur wenn ambulante Alternativen nicht möglich
  → BTHG: ambulant vor stationär ist Leitprinzip!
  → Kosten: EGH (Betreuung) + SGB XII § 42a (Unterkunft) + Grundsicherung

Grundsicherung neben EGH:
  → Wer in besonderer Wohnform lebt: Grundsicherung nach § 42 SGB XII
  → EGH-Träger und SGB XII-Träger kooperieren (§ 46b SGB XII)
```

## Arbeit und Beschäftigung

```
Inklusiver Arbeitsmarkt (§§ 49–63 SGB IX):
  → Arbeitgeber ab 20 MA: mind. 5% Schwerbehinderte
  → Ausgleichsabgabe wenn Quote nicht erfüllt
  → Unterstützung: IFD (Integrationsfachdienste), JC, Agentur

Werkstatt für behinderte Menschen (WfbM, § 219 SGB IX):
  → Wenn allgemeiner Arbeitsmarkt nicht erreichbar
  → Mindestlohn gilt NICHT in WfbM
  → Entgelt: ca. 200 €/Monat (Arbeitsentgelt + Grundbetrag)
  → Grundsicherung: SGB XII (§ 41 SGB XII) neben WfbM-Entgelt

Übergang WfbM → allgemeiner Arbeitsmarkt:
  → Budget für Arbeit (§ 61 SGB IX): Lohnkostenzuschuss für Arbeitgeber
  → Unterstützte Beschäftigung (§ 55 SGB IX): Job Coach, Betriebsintegriert
```

## Kinder mit Behinderung

```
Zuständigkeit nach Behinderungsart:

Körperliche/geistige Behinderung:
  → EGH (SGB IX) durch EGH-Träger
  → Frühförderung (§§ 79–82 SGB IX)
  → Schulbegleitung

Seelische Behinderung:
  → § 35a SGB VIII (JUGENDAMT!)
  → Schulbegleitung, Heilpädagogik, Tagesgruppe

Mehrfachbehinderung:
  → Zuständigkeit klären (§ 14 SGB IX)
  → Einer der Träger muss federführend sein
  → Kein "Hin- und Herschieben" erlaubt!

Frühförderung (§§ 79–82 SGB IX):
  → Für Kinder unter 6 Jahren (frühe Kindheit)
  → Komplexleistung: medizinisch + pädagogisch + sozial
  → Träger: Frühförderstellen (interdisziplinär)
  → Abrechnung: KV + EGH teilen sich Kosten
```

## Schwerbehindertenrecht — praktische Vorteile

```
GdB 50+ (Schwerbehindertenausweis):

Arbeitsrecht:
  → Zusatzurlaub: 5 Tage/Jahr (§ 208 SGB IX)
  → Kündigungsschutz: Kündigung nur mit Zustimmung Integrationsamt (§ 168 SGB IX)
  → Nachteilsausgleiche bei Bewerbung

Steuerrecht:
  → Steuerfreibeträge je nach GdB (Behinderten-Pauschbetrag)
  → GdB 100 + H: 7.400 €/Jahr Freibetrag
  → Fahrtkosten abzugsfähig

Verkehr:
  → Merkzeichen G + aG: Freifahrt im ÖPNV nach Entrichtung Gebühr
  → Merkzeichen 1.: Bahnfahrt 1. Klasse mit 2.-Klasse-Ticket
  → Parkausweis (blau, EU-weit) bei aG

Rente:
  → Altersrente bei Schwerbehinderung: 2 Jahre früher möglich (§ 37 SGB VI)

SGB II:
  → Schwerbehinderung: kein Minijob-Ausschluss, keine Sonderregeln
  → EGH-Leistungen werden NICHT als Einkommen angerechnet! (§ 11a Abs. 3 SGB II)
```

## Praxis: Erstberatung Menschen mit Behinderung

```
1. Art der Behinderung klären:
   □ Körperlich? Geistig? Seelisch? Sinnes?
   □ Diagnosen vorhanden? Befundberichte?
   □ GdB festgestellt? Schwerbehindertenausweis?

2. Leistungsbedarf:
   □ Assistenz? Wohnen? Arbeit? Freizeit?
   □ Schulbegleitung für Kinder?
   □ EGH-Antrag gestellt?

3. Zuständigkeit:
   □ EGH-Träger bekannt (Bezirk/LWV/LVR)?
   □ Gesamtplan vorhanden?
   □ Wunsch- und Wahlrecht ausgeübt?

4. Grundsicherung:
   □ SGB XII-Grundsicherung beantragt?
   □ SGB II möglich (wenn erwerbsfähig)?
   □ EM-Rente möglich?

5. Persönliches Budget?
   □ Informiert über PB-Option?
   □ Wunsch vorhanden? → Antrag stellen!

Anlaufstellen:
  → Ergänzende Unabhängige Teilhabeberatung (EUTB) — kostenlos, bundesweit!
  → VdK, BVKM, Lebenshilfe, Pro Infirmis
  → Behindertenbeauftragte (kommunal, Land, Bund)
```
