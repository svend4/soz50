## Schwerbehindertenausweis — GdB

```
GdB = Grad der Behinderung (0–100, in Zehnerschritten)

Ab GdB 50: Schwerbehindertenausweis
  → Antrag: Versorgungsamt / LVR / LWL

Wichtige Merkzeichen:
  G  = erheblich gehbehindert (→ Nahverkehr kostenlos u.a.)
  aG = außergewöhnlich gehbehindert (→ Behindertenparkplatz)
  H  = hilflos (→ Pflegegeld, Steuervorteile)
  B  = Begleitung notwendig (→ kostenlose Begleitperson ÖPNV)
  RF = Rundfunkgebührenbefreiung
  Bl = blind
  Gl = gehörlos
```

## Leistungsübersicht

### Eingliederungshilfe (SGB IX §§ 99ff)

→ Ausführlich: [Eingliederungshilfe](../../../01_SOZIALRECHT/03_SGB_XII_Sozialhilfe/Eingliederungshilfe/)

```
Ambulante Assistenz (Alltagsassistenz)
Wohnen mit Unterstützung (betreutes Wohnen)
WfbM — Werkstatt für Menschen mit Behinderung
Schulbegleitung / Schulassistenz
Persönliches Budget
```

### Pflegeversicherung (SGB XI)

→ Ausführlich: [SGB XI Pflege](../../../01_SOZIALRECHT/05_SGB_XI_Pflege/)

```
Pflegegrade 1–5 nach Begutachtung (MDK)
Pflegegeld (häusliche Pflege durch Angehörige)
Pflegesachleistungen (ambulanter Pflegedienst)
Stationäre Pflege
```

### Krankenversicherung (SGB V)

```
Heilmittel: Physiotherapie, Ergotherapie, Logopädie
Hilfsmittel: Rollstuhl, Hörgerät, Prothesen
→ Genehmigungspflicht! Bei Ablehnung: Widerspruch!
```

### Arbeitsrecht / Schwerbehindertenrecht

```
Ab GdB 50 (anerkannt oder gleichgestellt ab GdB 30):
  → Zusatzurlaub: 5 Arbeitstage/Jahr
  → Besonderer Kündigungsschutz (§ 168 SGB IX)
    (Zustimmung Integrationsamt erforderlich)
  → Recht auf leidensgerechten Arbeitsplatz
  → Anspruch auf Teilzeitarbeit bei GdB ≥ 50 (§ 164 Abs. 5)
```

## Verfahren: Weg zu den Leistungen

```
1. GdB feststellen lassen (Versorgungsamt)
   → Antrag + ärztliche Unterlagen
   → Dauer: 3–6 Monate

2. Pflegegrad beantragen (Pflegekasse)
   → Antrag per Brief/Telefon
   → MDK-Begutachtung (Hausbesuch)
   → Bescheid ca. 4–6 Wochen

3. Eingliederungshilfe beantragen (EGH-Träger)
   → Antrag + Gesamtplanverfahren
   → Bedarf wird individuell ermittelt
   → Bescheid + Leistungsvereinbarung
```

## Typische Probleme und Lösungen

| Problem | Lösung |
|---------|--------|
| GdB zu niedrig angesetzt | Widerspruch + Facharztberichte nachreichen |
| Pflegegrad abgelehnt | Widerspruch + Wiederholungsbegutachtung |
| Hilfsmittel abgelehnt (KK) | Widerspruch + ärztl. Notwendigkeitsbescheinigung |
| Schulbegleitung abgelehnt | Widerspruch (Jugendamt / EGH-Träger) |
| Kündigung trotz Schwerbehinderung | Integrationsamt kontaktieren — fehlende Zustimmung |
