## Первичная консультация — ключевые вопросы

1. Какой статус пребывания? (Ausweis zeigen lassen)
2. Где живёт клиент? (Unterkunft / eigene Wohnung)
3. Какие выплаты получает?
4. Есть ли семья? Дети?
5. Есть ли медицинские проблемы?
6. Есть ли юридическая поддержка (Rechtsanwalt, Verein)?
