# Erstberatung — Checkliste für Geflüchtete

[← Geflüchtete](./README.md) | [← Zielgruppen](../README.md)

> Для социальных работников и консультантов. Структурирует первую встречу с новым клиентом — беженцем или мигрантом. Убедись, что ключевые вопросы задаются с уважением и через доверенного переводчика.

---

## Vor dem Gespräch / До встречи

- [ ] Организован переводчик (профессиональный, не родственник клиента)
- [ ] Выбрано нейтральное, спокойное помещение (не коридор, не открытое пространство)
- [ ] Есть время: первая беседа занимает минимум 60–90 минут
- [ ] Заготовлены бланки для записи (не вводи данные в компьютер с первого раза — мешает контакту)
- [ ] Чай / вода предложены

---

## 1. Персональные данные / Stammdaten

*(Записывай только необходимое для помощи — минимум данных)*

- [ ] Имя (как написано в документах)
- [ ] Дата рождения / приблизительный возраст
- [ ] Текущий адрес / место проживания (Unterkunft, Privatwohnung, obdachlos)
- [ ] Есть ли безопасный способ связи (телефон, Signal, WhatsApp)?

---

## 2. Aufenthaltsstatus / Статус пребывания

Это определяет всё: какие права, какие выплаты, какие риски.

- [ ] Какой документ есть на руках?

| Документ | Значение | Leistungen |
|---------|---------|-----------|
| Aufenthaltsgestattung | Asylverfahren läuft | AsylbLG §3 (6–18 Monate) → danach §2 |
| Duldung | Asyl abgelehnt, Abschiebung ausgesetzt | AsylbLG §3 oder §2 |
| Aufenthaltserlaubnis §25 Abs.1 | Anerkannter Flüchtling | SGB II / SGB XII |
| Aufenthaltserlaubnis §25 Abs.2 | Subsidiär geschützt | SGB II / SGB XII |
| Niederlassungserlaubnis | Verfestigt | SGB II / SGB XII |
| Fiktionsbescheinigung | Verlängerung beantragt | je nach Inhalt |
| Reiseausweis / Pass (Drittland) | Weitere Klärung nötig | — |

- [ ] Wie lange gilt das Dokument? (Ablaufdatum)
- [ ] Gibt es ein laufendes Verfahren? (Asyl, Klage, Härtefallkommission)
- [ ] Wer ist der Rechtsanwalt / wer begleitet das Verfahren?

---

## 3. Famille / Семейная ситуация

- [ ] Alleinstehend / с семьёй?
- [ ] Kinder im Haushalt — возраст, школа/Kita?
- [ ] Есть ли члены семьи за рубежом? (Nachzug geplant?)
- [ ] Беременность? (Mehrbedarf §21 SGB II, ärztliche Begleitung)

---

## 4. Leistungen / Текущие выплаты

- [ ] Erhält derzeit Leistungen? Welche? (AsylbLG / SGB II / SGB XII / keine)
- [ ] Letzter Bescheid vorhanden? (Копия взять)
- [ ] Gibt es Kürzungen / Sanktionen / laufende Streitigkeiten?
- [ ] Kontoverbindung vorhanden? (Для переводов)

---

## 5. Wohnen / Жильё

- [ ] Gemeinschaftsunterkunft oder Privatwohnung?
- [ ] Zuweisung durch Behörde oder freie Wahl?
- [ ] Probleme in der Unterkunft? (Übergriffe, Diskriminierung, hygienische Mängel)
- [ ] Wohnungssuche läuft? Hilfe benötigt?
- [ ] Mietschulden / Räumungsklage?

---

## 6. Gesundheit / Здоровье

*(Деликатная тема — только то, что необходимо для помощи)*

- [ ] Krankenversicherung vorhanden? (GKV или KVdR, oder nur Behandlungsschein AsylbLG)
- [ ] Laufende Behandlungen / Medikamente? (Rezepte vorhanden?)
- [ ] Psychische Belastungen / Traumata? → Verweis auf Fachdienst (psychiatrische Ambulanz, Trauma-Beratung)
- [ ] Behinderung / besondere Bedarfe?

---

## 7. Arbeit und Ausbildung / Работа и образование

- [ ] Bisherige Qualifikation / Beruf (im Herkunftsland)?
- [ ] Deutschkenntnisse? (A1/A2/B1/B2/C1)
- [ ] Sprachkurs läuft / abgeschlossen?
- [ ] Arbeitsgenehmigung vorhanden? (abhängig vom Aufenthaltsstatus)
- [ ] Interesse an Ausbildung / Arbeit?

---

## 8. Dringende Probleme / Срочные проблемы

*(Что требует решения немедленно — в течение этой встречи или до следующей)*

- [ ] Ausweisdokument läuft ab — wann? Verlängerung beantragt?
- [ ] Anhörung / Gerichtstermin demnächst — Datum? Begleitung organisiert?
- [ ] Drohende Abschiebung — laufendes Verfahren? Rechtsanwalt informiert?
- [ ] Kein Geld für Essen / Grundbedarf → Sofortige Hilfe (Tafel, Notunterstützung)
- [ ] Sicherheitsprobleme (Gewalt, Verfolgung durch andere Bewohner)?

## 10. Einwilligung und Datenschutz / Согласие на обработку данных

- [ ] Клиент проинформирован о том, какие данные фиксируются
- [ ] Клиент понимает, куда данные могут передаваться (внутри организации)
- [ ] При передаче данных третьим лицам (Behörden, Anwalt): письменное согласие получено

---

## Hinweise zur Gesprächsführung

**Dos:**
- Говори медленно, простыми предложениями
- Проверяй понимание: «Как вы поняли то, что я сказал(а)?»
- Дай время для ответа — не торопи
- Признавай тяжесть ситуации: «Это действительно сложно»
- Будь прозрачен: объясняй, что ты можешь и чего не можешь сделать

**Don'ts:**
- Не используй детей как переводчиков
- Не обещай того, что не в твоих силах
- Не записывай информацию об изнасилованиях, пытках в обычных файлах — только в защищённых
- Не задавай вопросы о деталях травматических событий без специальной подготовки
