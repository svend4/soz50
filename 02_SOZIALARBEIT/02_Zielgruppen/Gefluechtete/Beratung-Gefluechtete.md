# Zielgruppe Geflüchtete — Beratungspraxis

[← Zielgruppen](../README.md) | [← Sozialarbeit](../../README.md)

> Beratung geflüchteter Menschen erfordert Wissen über Aufenthaltsrecht,
> AsylbLG, Asylverfahren UND interkulturelle Kompetenz.
> Vertrauen aufbauen braucht Zeit — Trauma sensibel ansprechen.

---

## Wer gehört zur Zielgruppe?

```
Geflüchtete sind keine homogene Gruppe:

Rechtliche Kategorien:
  → Asylbewerber (Aufenthaltsgestattung)
  → Geduldete (Duldung § 60a AufenthG)
  → Anerkannte Flüchtlinge (AE § 25 Abs. 1)
  → Subsidiär Schutzberechtigte (AE § 25 Abs. 2)
  → Menschen mit Abschiebungsverbot (AE § 25 Abs. 3)
  → Kontingentflüchtlinge (AE § 23 Abs. 2)
  → UMA (Unbegleitete Minderjährige)

Herkunft und Fluchtgründe variieren enorm:
  → Politische Verfolgung
  → Krieg / bewaffnete Konflikte
  → Religiöse / ethnische Verfolgung
  → LGBTIQ+-Verfolgung
  → Naturkatastrophen / Klimavertreibung (noch kein Schutzstatus)
```

## Herausforderungen in der Beratung

### Sprachbarriere

```
Umgang mit Dolmetscher:
  → Professionellen Dolmetscher nutzen (nicht Kinder/Verwandte!)
  → Kinder als Dolmetscher = erheblicher Belastung für das Kind!
  → Geschlechtsspezifisch: Sensible Themen (Gewalt, Trauma)
    → Dolmetscher gleichen Geschlechts bevorzugen

Sprachmittler:
  → Ehrenamtliche Sprachmittler: kostengünstig, aber Qualität variiert
  → Professioneller Dolmetscher: bei rechtlichen Terminen IMMER!
  → Telefonische Dolmetscherdienste (z.B. Kommunaler Sozialverband)

Wenn kein Dolmetscher verfügbar:
  → Einfache Sprache, kurze Sätze
  → Grafiken, Bilder, Piktogramme
  → Zeitplanung großzügig (doppelte Zeit einplanen)
```

### Trauma und Belastungsreaktionen

```
Häufige Traumafolgen:
  → PTBS (Posttraumatische Belastungsstörung, F43.1)
  → Depression, Angststörungen
  → Schlafstörungen, Hypervigilanz
  → Dissoziative Störungen
  → Körperliche Symptome ohne organische Ursache

Trauma-sensitive Haltung:
  → NICHT nach Details der Flucht fragen wenn nicht nötig!
  → Kontrolle geben: "Sie müssen nicht antworten"
  → Sicherheit herstellen: ruhiger Raum, Wasser anbieten
  → Übersetzte Kurzinfo vorab: Was passiert heute im Gespräch?
  → Reaktionen normalisieren: "Das ist eine normale Reaktion auf Abnormales"

Wenn Krise sichtbar wird:
  → Ruhig bleiben, Kontakt halten
  → Grounding-Techniken: "Was sehen/hören/fühlen Sie gerade?"
  → Im Notfall: Kriseninterventionsteam / Psychiatrie

Weitervermittlung:
  → Psychosoziale Zentren für Migranten und Flüchtlinge (PSZ)
  → BZFO (Berlin), IPSO, BAfF-Mitgliedseinrichtungen
  → Psychiatrische Ambulanzen (§ 6 AsylbLG — Ermessen!)
```

## Sozialrechtliche Erstberatung

```
Orientierungsgespräch — was brauche ich zu wissen?

1. Aufenthaltsstatus (von Dokument ablesen):
   □ Aufenthaltsgestattung → AsylbLG § 3
   □ Duldung → AsylbLG § 3 (oder § 2 nach 18 M.)
   □ AE § 25 Abs. 1/2 → SGB II
   □ Sonstiges → prüfen

2. Wie lange in Deutschland? (für § 2 AsylbLG-Prüfung)
   □ Unter 18 Monate → § 3 AsylbLG
   □ Über 18 Monate + kein Ausschluss → § 2 AsylbLG (SGB XII-analog)
   → Sozialamt informieren!

3. Asylverfahren — Stand?
   □ Noch offen → BAMF-Anhörung vorbereiten?
   □ Abgelehnt → Klage? Frist?
   □ Anerkannt → SGB-II-Antrag sofort stellen?

4. Laufende Leistungen?
   □ Sozialamt bekannt? Ansprechpartner?
   □ Gesundheitsversorgung (Krankenschein oder Gesundheitskarte)?
   □ Kinder in Schule / Kita?

5. Dringende Bedarfe:
   □ Krankenversicherung / akute Erkrankung?
   □ Arbeit erlaubt?
   □ Deutschkurs möglich?
```

## Arbeitsmarktzugang für Geflüchtete

```
Wer darf arbeiten?

Aufenthaltsgestattung (nach 3 Monaten):
  → Beschäftigung erlaubt WENN Arbeitserlaubnispflicht (§ 61 AsylG)
  → Genehmigung der Ausländerbehörde nötig
  → BA prüft: Vorrangprüfung (ob Deutsche/EU-Bürger den Job nehmen könnten)
  → Ausnahme: Vorrangprüfung entfällt nach 15 Monaten Aufenthalt

Duldung:
  → Beschäftigungserlaubnis bei Ausländerbehörde beantragen
  → Vorrangprüfung entfällt nach 4 Jahren Aufenthalt
  → Ausbildungsduldung § 60c: Ausbildung auch ohne Beschäftigungserlaubnis!

Anerkannte Flüchtlinge (AE § 25 Abs. 1/2):
  → Unbeschränkte Arbeitserlaubnis!
  → Kein Antrag nötig

AsylbLG + Arbeit:
  → Einkommen aus Arbeit wird auf AsylbLG angerechnet
  → Freibetrag: 30% + 50 € (§ 7 AsylbLG)

Beratung zu Arbeit:
  → Agentur für Arbeit: Berufsberatung (auch für Asylbewerber!)
  → IQ-Netzwerk: Anerkennung ausländischer Berufsabschlüsse
  → Integrationskurs: BAMF-finanziert (Pflicht nach Anerkannt-Status)
```

## Bildung und Spracherwerb

```
Integrationskurse (§ 43 AufenthG):
  → Anspruch auf Integrationskurs bei AE § 25 Abs. 1/2
  → 700 Stunden Deutsch + 100 Stunden Orientierung
  → Finanziert vom BAMF (Teilnahmegebühr: 2,20 €/Stunde, erlassbar)

Berufssprachkurse (BSK):
  → Für Berufseinsteiger: Deutsch im beruflichen Kontext
  → Kostenlos (BAMF-finanziert)

Für Asylbewerber in Verfahren:
  → Integrationskurs: erst nach Anerkennung (formell)
  → ABER: Viele Bundesländer ermöglichen frühzeitige Teilnahme
  → Alpha-Kurs: für Analphabeten
  → Kommunale Sprachkurse: oft offener zugänglich

Kinder und Schule:
  → Schulpflicht gilt sofort für Kinder!
  → Übergangskurse/Vorbereitungsklassen in Schulen
  → Schulbegleitung bei Bedarf (§ 35a SGB VIII oder EGH)
```

## Familiennachzug

```
Flüchtlingsschutz (§ 25 Abs. 1) — Familiennachzug:
  → § 29 Abs. 2 AufenthG: erleichterter Nachzug
  → Keine Nachweise von Sprachkenntnissen, keine Einkommensgrenze
  → Antrag bei Deutschen Botschaft im Herkunftsland

Subsidiärer Schutz (§ 25 Abs. 2) — eingeschränkt:
  → Seit 2018: Kontingent von 1.000 Personen/Monat
  → Humanitarian-Visa: Beantragung bei Botschaft
  → Wartezeiten: oft 1–3 Jahre!

Duldung (§ 60a) — Familiennachzug:
  → Grundsätzlich kein Rechtsanspruch
  → Ausnahme: Familienzusammenführung aus humanitären Gründen (§ 22 AufenthG)
  → Sehr schwierig durchzusetzen

Tipp:
  → Bei Familientrennung: spezialisierte Beratung aufsuchen
  → Trennungsbedingte psychische Belastung: PSZ!
```

## Beratungsnetz: Anlaufstellen

```
Staatliche Beratung:
  → Migrationsberatung für Erwachsene Zuwanderer (MBE):
    AWO, Caritas, Diakonie, DRK — für anerkannte Flüchtlinge
  → Jugendmigrationsdienst (JMD): für unter 27-Jährige
  → BAMF-Onlinedienste: bamf.de

Fachberatungsstellen:
  → Lokale Flüchtlingsberatung (Caritas, AWO etc.)
  → PRO ASYL: bundesweite Rechtsberatung
  → Flüchtlingsräte (Landesebene): Rechtsberatung + Advocacy
  → Rückkehrberatung: wenn freiwillige Ausreise erwogen wird

Psychosoziale Unterstützung:
  → Psychosoziale Zentren (PSZ): traumasensible Beratung
  → BAfF (Bundesweite Arbeitsgemeinschaft psychosozialer Zentren)
  → Liste: baff-zentren.de

Selbstorganisationen:
  → Flüchtlingsräte + lokale Netzwerke
  → Wichtig: Geflüchtete haben eigene Stimme!
```

## Besondere Zielgruppen innerhalb Geflüchteter

```
UMA (Unbegleitete Minderjährige Ausländer):
  → SGB VIII — nicht AsylbLG!
  → Jugendamt → Inobhutnahme § 42a
  → Vormund bestellen lassen
  → Alterseinschätzung: wenn unklar → immer Minderjährigen-Schutz!

LGBTIQ+-Geflüchtete:
  → Verfolgung wegen sexueller Orientierung = anerkannte Verfolgung!
  → Besondere Sensibilität in Unterkunft (Gewalt durch Mitbewohner?)
  → Spezifische Beratungsstellen (LSVD, örtliche Beratungsstellen)

Frauen und Mädchen:
  → Genderbasierte Verfolgung: FGM, Zwangsheirat, häusliche Gewalt
  → Frauenspezifische Unterbringung (nicht immer vorhanden!)
  → Gewaltschutzkonzepte in Unterkünften prüfen

Ältere Geflüchtete:
  → Chronische Erkrankungen + AsylbLG § 4 = oft Versorgungslücken!
  → § 6 AsylbLG: Ermessen bei medizinischen Bedarfen
  → Nach § 2: GKV-Vollversorgung
```
