# Zielgruppen der Sozialen Arbeit — Übersicht

[← Sozialarbeit](../README.md)

> Soziale Arbeit arbeitet mit verschiedenen **Zielgruppen**, die jeweils
> spezifische Bedarfe, Lebenssituationen und rechtliche Ansprüche haben.
> Viele Klienten gehören gleichzeitig mehreren Zielgruppen an — intersektional denken!

---

## Zielgruppen im Überblick

| Zielgruppe | Typische Bedarfe | Wichtigste Rechtsgrundlagen |
|------------|-----------------|------------------------------|
| [Familien](./Familien/) | Elterngeld, KiZ, BuT, Erziehungsberatung | SGB VIII, BKKG, UhVG |
| [Kinder & Jugendliche](./Kinder_Jugendliche/) | Schutz, Förderung, HzE, Unterhalt | SGB VIII, KSchG, UhVG |
| [Geflüchtete](./Gefluechtete/) | Aufenthalt, Sozialleistungen, Integration | AsylG, AufenthG, AsylbLG, SGB II |
| [Menschen mit Behinderung](./Menschen_mit_Behinderung/) | Teilhabe, EGH, Assistenz, Arbeit | SGB IX, SGB II, SGB XII |
| [Senioren](./Senioren/) | Pflege, Grundsicherung, Betreuung | SGB XI, SGB XII, BGB |
| [Suchtbetroffene](./Suchtbetroffene/) | Entzug, Reha, Substitution, Sozialarbeit | SGB V, SGB IX, BTMGVwV |
| [Wohnungslose](./Wohnungslose/) | Unterkunft, § 67 SGB XII, Schulden | SGB XII, SGB II |

## Querschnittsthemen — Mehrfachzugehörigkeit

Viele Klienten sind **mehreren Zielgruppen gleichzeitig** zuzuordnen:

```
Beispiele:
  → Geflüchtete Familie mit Kindern
    = Geflüchtete + Familien + Kinder & Jugendliche

  → Suchtbetroffener wohnungsloser Mann (50 J.)
    = Suchtbetroffene + Wohnungslose + evtl. Behinderung

  → Ältere Frau mit Demenz, Migrationshintergrund
    = Senioren + Behinderung + evtl. Geflüchtete
```

## Gemeinsame Grundprinzipien in der Arbeit mit allen Zielgruppen

### Ressourcenorientierung
```
→ Nicht nur Defizite sehen — was kann die Person?
→ Stärken aktivieren (Empowerment-Ansatz)
→ Soziales Netzwerk einbeziehen
```

### Lebensweltorientierung (Thiersch)
```
→ Klienten dort abholen wo sie stehen
→ Alltag und Lebenssituation verstehen
→ Institutionelle Logik ≠ Lebenswelt des Klienten
```

### Partizipation
```
→ Klienten als Experten ihrer eigenen Situation
→ Gemeinsame Zielformulierung
→ Hilfeplanung MIT nicht FÜR die Person (§ 36 SGB VIII, BTHG)
```

### Niedrigschwelligkeit
```
→ Kein Termin nötig für erste Kontaktaufnahme (idealerweise)
→ Sprache anpassen (einfache Sprache, Dolmetscher)
→ Ort der Beratung flexibel (aufsuchend wenn nötig)
```

## Rechtliche Grundprinzipien für alle Zielgruppen

| Prinzip | Bedeutung für Praxis |
|---------|---------------------|
| **Wunsch- und Wahlrecht** (§ 9 SGB IX, § 5 SGB VIII) | Klient darf Einrichtung/Leistungsform mitbestimmen |
| **Bedarfsdeckungsprinzip** | Leistung nach tatsächlichem Bedarf, nicht Pauschale |
| **Nachrang** | Eigene Mittel zuerst — aber Schonvermögen schützen! |
| **Amtsermittlung** (§ 20 SGB X) | Behörde muss selbst ermitteln, nicht nur abwarten |
| **§ 17 SGB I Beratungspflicht** | Behörde muss auf Ansprüche hinweisen |

## Intersektionale Perspektive — Mehrfachdiskriminierung

```
Klienten können gleichzeitig betroffen sein von:
  → Armut / soziale Ausgrenzung
  → Rassismus / Migrationshintergrund
  → Behinderung / chronische Erkrankung
  → Alter (jung oder alt)
  → Geschlecht / queere Identität
  → Bildungsbenachteiligung

→ Soziale Arbeit muss diese Überschneidungen erkennen
→ AGG (Allgemeines Gleichbehandlungsgesetz) bei Diskriminierung!
→ Bei Diskriminierung durch Behörden: Petition, Ombudsmann, Verwaltungsgericht
```

## Methodische Hinweise

### Erstgespräch — Was fragen?

Unabhängig von Zielgruppe immer klären:

```
1. Akutsituation: Gibt es Gefährdungen (§ 8a SGB VIII)?
2. Aufenthaltsstatus (bei Geflüchteten): Welches Recht gilt?
3. Erwerbsfähigkeit: SGB II oder SGB XII?
4. Familienstand: Kinder? Unterhaltspflichten?
5. Wohnverhältnisse: Stabil? KdU geklärt?
6. Gesundheit: GKV vorhanden? Pflegegrad? Schwerbehinderung?
7. Schulden: Gerichtliche Verfahren? Lohnpfändung?
8. Was ist der konkrete Wunsch/Auftrag des Klienten?
```

### Vernetzung / Fallkonferenz

```
→ Kein Fall ist nur "einer Stelle" zuzuordnen
→ Jugendhilfe + Jobcenter oft gleichzeitig aktiv
→ Koordination wichtig — § 36a SGB VIII (Fallverantwortung)
→ Schweigepflicht beachten: Weitergabe nur mit Einwilligung!
   (Ausnahme: § 8a SGB VIII Kindeswohlgefährdung)
```
