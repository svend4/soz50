## Zielgruppenspezifische Problemlagen

| Altersgruppe | Typische Probleme | Hilfen |
|-------------|------------------|--------|
| **0–6 Jahre** | Vernachlässigung, Armut, frühe Bildung | § 8a SGB VIII, Kita, Frühe Hilfen |
| **6–14 Jahre** | Schulschwierigkeiten, Mobbing, familiäre Belastung | Erziehungsberatung § 28, SPFH, Lernförderung |
| **14–17 Jahre** | Schulabbruch, Delinquenz, Sucht, Identität | ISE § 35, Jugendarbeit, Jugendsozialarbeit § 13 |
| **18–27 Jahre** | Übergang Jugendhilfe→Erwachsene, Ausbildung | § 41 SGB VIII, SGB II, Berufsberatung |

## Frühe Hilfen

```
Bundesinitiative Frühe Hilfen:
  → Unterstützung ab Schwangerschaft bis 3 Jahre
  → Familienhebammen, Familienpaten, Beratungsstellen
  → Freiwillig, niedrigschwellig
  → Ziel: Risiken früh erkennen, Kindeswohlgefährdung verhindern

Familienhebamme:
  → Qualifizierte Hebamme mit sozialpädagogischer Zusatzqualifikation
  → Für Familien mit Belastungsfaktoren
  → Hausbesuche 0–12 Monate (manchmal bis 3 Jahre)
```

---

## Schulsozialarbeit (§ 13 SGB VIII)

```
Jugendsozialarbeit an Schulen:
  → Soziale Benachteiligung ausgleichen
  → Beratung, Konfliktmediation, Krisenintervention
  → Elternarbeit
  → Übergang Schule → Beruf begleiten

Rechtlicher Rahmen: § 13 SGB VIII (Jugendsozialarbeit)
Finanzierung: Jugendamt + Schulträger
```

## Jugendliche in Krise — sofortige Hilfen

```
Suizidgefahr / psychische Krise:
  → Telefonseelsorge: 0800 111 0 111 (kostenlos, 24h)
  → Kinder- und Jugendpsychiatrie (KJP) — stationäre Aufnahme
  → Notaufnahme Krankenhaus

Obdachlosigkeit / Weggelaufen:
  → Inobhutnahme § 42 SGB VIII (auf Wunsch des Jugendlichen)
  → Jugendnotdienst (kommunal)
  → "off road kids" und andere Streetwork-Projekte

Gewalt / Missbrauch:
  → Sofortschutz: Polizei (110) + Jugendamt
  → Kinderschutzzentrum
  → Weißer Ring, Wildwasser (sexueller Missbrauch)
```

## Bildungs- und Teilhabepaket (§ 28 SGB II / § 34 SGB XII)

```
Leistungen für Kinder bei SGB II / SGB XII / KiZ / Wohngeld:

  Schulbedarf:     116 €/Schuljahr (1.8. und 1.2. je 58 €)
  Schulausflüge:   tatsächliche Kosten
  Klassenfahrten:  tatsächliche Kosten
  Mittagessen:     Schule/Kita (mit Eigenanteil 1 €/Tag)
  Lernförderung:   Nachhilfe wenn schulisches Ziel gefährdet
  Freizeit / Sport: 15 €/Monat (Verein, Kurs, Freizeit)

Beantragung: Jobcenter oder kommunale Stelle (je nach Stadt)
WICHTIG: Vor Veranstaltung beantragen!
```

## Übergang ins Erwachsenenalter (Leaving Care)

```
Problem: Jugendhilfe endet oft abrupt mit 18/21 Jahren
  → Kein soziales Netz, kein Geld, keine Wohnung

Rechtliche Ansprüche:
  § 41 SGB VIII: Hilfe für junge Volljährige bis 21 (bis 27 möglich)
  → Antrag muss vor 18. Geburtstag gestellt werden!
  SGB II: Bürgergeld ab 18 (wenn erwerbsfähig)
  BAföG: Ausbildungsförderung
  Berufsausbildungsbeihilfe (BAB): für Auszubildende
```
