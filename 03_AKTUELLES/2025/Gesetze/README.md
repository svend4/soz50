## Bekannte Änderungen 2025

### SGB II / Bürgergeld

```
01.01.2025:
  → Neue Regelbedarfssätze (jährliche Anpassung)
  → Kooperationsplan weiterentwickelt
  → Vertrauenszeit: Erfahrungen aus 2023-Reform
```

### Cannabis-Legalisierung (April 2024 → Auswirkungen 2025)

```
CanG (Cannabisgesetz) seit 01.04.2024:
  → Eigenkonsum und Besitz bis 25g legal (ab 18)
  → Anbau bis 3 Pflanzen legal
  → Auswirkungen Sozialarbeit:
     - Suchtberatung: neue Klientengruppen
     - Führerscheinrecht: § 24a StVG noch unklar
     - Strafrecht: Altfälle → Amnestie geprüft
```

### Betreuungsrecht (seit 01.01.2023 — Auswirkungen 2025)

```
BGB §§ 1814ff (Reform 2023):
  → Selbstbestimmung im Vordergrund
  → Unterstützte Entscheidungsfindung vor Betreuung
  → Qualitätsanforderungen an Berufsbetreuer gestiegen
```
