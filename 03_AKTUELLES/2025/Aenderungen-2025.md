# Rechtsänderungen 2025 — Sozialrecht

[← Aktuelles 2025](./README.md) | [← Aktuelles](../README.md)

> Stand: Änderungen ab 01.01.2025 sowie unterjährige Änderungen 2025.
> Politischer Kontext: Ampel-Koalition (SPD-FDP-Grüne) zerbrach November 2024.
> Bundestagswahl: 23.02.2025 → CDU/CSU-geführte neue Regierung ab Frühjahr 2025.
> Manche Reformen wurden verschoben, einige kamen trotzdem in Kraft.

---

## Bürgergeld (SGB II) — Änderungen 2025

```
REGELSATZ 2025 — ERSTMALIGE ABSENKUNG:

Bürgergeld-Regelsatz 2025:
  Alleinstehende:        563 € (2024: 563 €) → konstant!
  → Keine Erhöhung wegen negativem Mischindex

Hintergrund:
  → Regelleistungsanpassung nach § 28 SGB XII i.V.m. § 20 SGB II
  → Mischindex = 70% Preisentwicklung + 30% Lohnentwicklung
  → Hohe Inflation 2022–2023 → Steigerungen. 2024–2025: Normalisierung
  → Ergebnis 2025: KEINE Erhöhung (rechnerisch neutral)

Politische Debatte:
  → CDU/CSU: Bürgergeld soll abgesenkt/ersetzt werden
  → "Neue Grundsicherung": Pläne im Koalitionsvertrag CDU+SPD 2025
  → Umsetzung 2026 erwartet (noch nicht in Kraft 2025)
```

```
MITWIRKUNGSPFLICHTEN VERSCHÄRFT (§§ 31–31b SGB II):

Änderung ab 01.01.2025:
  → Sanktionssystem angepasst (nach BVerfG-Urteil 2019 + neuer Regierung)
  → Verschärfung: Vollständige Leistungskürzung bei dauerhafter Verweigerung
    wieder möglich (ehem. "Totalentzug")
  → Stand 2025: Politisch umstritten, Gesetz in Diskussion

Wichtig für Beratung:
  → Mitwirkungspflichten bei Eingliederungsmaßnahmen: weiter beachten
  → BVerfG 1 BvL 7/16 (2019): 100%-Kürzung verfassungswidrig
  → Neue Gesetzgebung bis Sommer 2025 erwartet — prüfen!
```

```
KARENZZEIT (§ 22 Abs. 1 S. 2–4 SGB II):
  → Bürgergeld-Reform 2023: Karenzzeit 1 Jahr beibehalten
  → 2025: tatsächliche Kosten der Unterkunft werden weiterhin übernommen
    (unabhängig von Angemessenheit) — gilt im 1. Jahr nach Leistungsbeginn!
  → Nach Karenzzeit: Angemessenheitsgrenze greift wieder

SCHONVERMÖGEN (§ 12 SGB II):
  → 40.000 € für Leistungsberechtigten (2023 eingeführt, bleibt 2025)
  → + 15.000 € je weiterer Person in Bedarfsgemeinschaft
  → Kraftfahrzeug bis ca. 15.000 € Zeitwert: geschützt
```

## Mindestlohn 2025

```
Mindestlohn:
  → Ab 01.01.2025: 12,82 €/Stunde
  (Empfehlung Mindestlohnkommission, Umsetzung durch Bundesregierung)
  → 2024: 12,41 €
  → Nächste Anpassung: 01.01.2026

Bedeutung für SGB II/XII:
  → Minijob-Grenze: weiter 538 €/Monat (2024 eingeführt)
  → Berechnung: bei 12,82 €/h → max. ~42 h/Monat im Minijob möglich
  → Midi-Job: 538,01 € bis 2.000 €/Monat (gleitende Sozialversicherung)

Ausnahmen Mindestlohn:
  → Jugendliche unter 18 ohne abgeschlossene Berufsausbildung
  → Auszubildende (eigene Mindestausbildungsvergütung § 17 BBiG)
  → Pflichtpraktika bis 3 Monate
```

## Krankenversicherung (SGB V) 2025

```
BEITRAGSSÄTZE GKV 2025:

Allgemeiner Beitragssatz: 14,6% (unverändert)
Durchschnittlicher Zusatzbeitrag 2025:
  → 2,5% (2024: 1,7%)! Erhebliche Erhöhung!
  → Jede Kasse legt eigenen Zusatzbeitrag fest
  → Höchster Kassen-Zusatzbeitrag 2025: ca. 3,4%

Effektiver Beitragssatz (Mittelwert):
  → ca. 17,0–17,2% gesamt (Arbeitnehmer + AG je ca. 8,5%)

Beitragsbemessungsgrenze 2025:
  → 5.512,50 €/Monat (2024: 5.175 €)

Bedeutung für SGB-II-Empfänger:
  → JC zahlt GKV-Beitrag direkt (§ 251 SGB V, § 20 SGB II)
  → Betrag 2025: pauschal pro Person → aktuellen Wert beim JC erfragen

ZUSATZBEITRAG-WECHSELRECHT:
  → Bei Zusatzbeitragserhöhung: Sonderkündigungsrecht (§ 175 Abs. 4 SGB V)!
  → Wechsel möglich innerhalb 2 Monate nach Erhöhungsankündigung
  → Wichtiger Beratungshinweis: Kasse kann gewechselt werden!
```

```
GKV-LEISTUNGEN 2025 — ÄNDERUNGEN:

Krankengeld:
  → Berechnung: unverändert (70% des Regelentgelts, max. 90% Netto)
  → Bezugsdauer: 78 Wochen je Erkrankung

Zahnversorgung:
  → Festzuschüsse Zahnersatz: leichte Anpassung 2025
  → Bonusheft weiterhin Pflicht für erhöhten Zuschuss

Digitale Gesundheitsanwendungen (DiGA):
  → Weiter im Leistungskatalog (§ 33a SGB V)
  → Apps auf Rezept: zugelassene DiGA = Kassenleistung
```

## Rentenversicherung (SGB VI) 2025

```
RENTENANPASSUNG JULI 2025:
  → Erwartete Erhöhung: ca. +3,5% (West) / +3,5% (Ost)
  → Lohnanpassung: abhängig von Lohnentwicklung 2024

  (Anmerkung: Genaue Zahlen werden erst im Frühjahr 2025 bekanntgegeben
  — Stand August 2025 noch nicht veröffentlicht)

GRUNDRENTE (seit 2021, stabile Regelung 2025):
  → Grundrentenzuschlag für lange Versicherungszeiten (33+ Jahre)
  → Automatisch: kein Antrag nötig!
  → DRV prüft bei Rentengewährung automatisch

BEITRAGSBEMESSUNGSGRENZE (BBG) 2025:
  → West: 8.050 €/Monat (2024: 7.550 €)
  → Ost: 8.050 €/Monat (angeglichen seit 01.01.2025!)
  → WICHTIG: Ost/West-Unterschied bei BBG ENTFÄLLT 2025!

RENTENPUNKTE-WERT 2025:
  → Aktueller Rentenwert (ARW): voraussichtlich ~39,50 €/Punkt
  → (Anpassung nach Bekanntgabe im Frühjahr 2025)
```

## Pflegeversicherung (SGB XI) 2025

```
PFLEGEGELDERHÖHUNG ab 01.01.2025:
  → Pflegegeld erhöht um ca. 4,5% gegenüber 2024

  Pflegegrad 2: 347 € (2024: 332 €)
  Pflegegrad 3: 599 € (2024: 573 €)
  Pflegegrad 4: 800 € (2024: 765 €)
  Pflegegrad 5: 990 € (2024: 947 €)

PFLEGESACHLEISTUNGEN ab 01.01.2025:
  → Ambulante Sachleistungen ebenfalls erhöht
  Pflegegrad 2: 796 € (2024: 761 €)
  Pflegegrad 3: 1.497 € (2024: 1.432 €)
  Pflegegrad 4: 1.859 € (2024: 1.778 €)
  Pflegegrad 5: 2.299 € (2024: 2.200 €)

KURZZEITPFLEGE:
  → 2025: 1.854 €/Jahr (2024: 1.774 €)
  → Durch nicht genutzte Verhinderungspflege: bis zu 3.708 €!

ENTLASTUNGSBETRAG (§ 45b SGB XI):
  → 125 €/Monat (unverändert) — ab Pflegegrad 1!
  → Kann nicht angespart werden — Verfall wenn nicht genutzt!
  → Ausnahme: bis Juni des Folgejahres verwendbar

PFLEGEREFORM 2025 (politisch):
  → Große Reform geplant (Finanzierungslücke der PflegeV)
  → Beitragssatzerhöhung: 3,4% (2025 unverändert von 2024)
  → Weitere Reformen für 2026 erwartet — prüfen!
```

## Asyl- und Ausländerrecht 2025

```
ASYLBEWERBERLEISTUNGSGESETZ:
  → Grundleistungen 2025 (§ 3 AsylbLG):
    Alleinstehend: 460 € (2024: 460 €) — keine Erhöhung
    → Berechnung nach Regelbedarfsstufen (abgesenkt gegenüber SGB II)

SACHLEISTUNGEN statt Geld:
  → Politischer Druck: mehr Sachleistungen statt Bargeld
  → Rechtslage 2025: § 3 AsylbLG erlaubt Sachleistungen
  → Bundesrecht: Länder haben Spielraum
  → Mehrere Bundesländer führten Bezahlkarten ein!

BEZAHLKARTE 2025:
  → Einführung in vielen Bundesländern (Bayern, Niedersachsen etc.)
  → AsylbLG-Empfänger erhalten Karte statt Bargeld
  → Beschränkungen: kein/wenig Bargeld, eingeschränkte Händler
  → Rechtlich umstritten: Verfassungsbeschwerden anhängig

GEFLÜCHTETENRECHT:
  → Rückführungsverbesserungsgesetz 2024/2025: in Kraft
  → Erleichterte Abschiebung + mehr Abschiebehaft
  → Dublin-Verfahren: beschleunigt
```

## SGB VIII — Jugendhilfe 2025

```
KOSTENHERANZIEHUNG (§§ 91–94 SGB VIII):
  → Keine grundlegende Reform 2025
  → Einkommensgrenzen: weiterhin nach KJSG 2021

UNTERHALTVORSCHUSS:
  → Sätze angepasst an Mindestunterhalt (Düsseldorfer Tabelle)
  → Düsseldorfer Tabelle 2025: ab 01.01.2025 neue Sätze
  → Mindestunterhalt Kind 0–5 J.: 482 € (2024: 480 €)
  → Mindestunterhalt Kind 6–11 J.: 554 € (2024: 551 €)
  → Mindestunterhalt Kind 12–17 J.: 649 € (2024: 645 €)

BuT (Bildung und Teilhabe):
  → Schulbedarfspaket: 130 € (01.08.) + 65 € (01.02.) — weiterhin gültig
  → Erhöhung seit 2023, 2025 unverändert
```

## Wohngeld 2025

```
WOHNGELD:
  → Wohngeld-Plus-Reform: seit 01.01.2023 in Kraft
  → 2025: Fortbestand der ausgeweiteten Regelung
  → Erhöhung des Leistungsumfangs bleibt

Wohngeld-Höhenbegrenzung 2025:
  → Leistungshöhe: nach tabellarischen Werten (Haushaltsgröße + Miethöhe + Stufe)
  → Heizkosten-Zuschuss: Teil des Wohngelds (seit 2023)

Verhältnis SGB II/Wohngeld:
  → Wer SGB II oder SGB XII empfängt: KEIN Wohngeld
  → Wohngeld für Haushalte knapp über SGB-II-Grenze
  → Berechnung lohnt sich: ggf. besser Wohngeld als SGB II!
```
