## Категории

- **Gesetze** — новые законы или поправки
- **Urteile** — важные судебные решения (BSG, BVerfG, LSG)
- **Verwaltung** — изменения в практике ведомств, новые Rundschreiben

---

## Как добавить актуальный документ

1. Найди нужный год и месяц: `03_AKTUELLES/2026/Februar/`
2. Создай файл по шаблону: `2026-02-27_Buergergeld-Regelsatz.md`
3. Укажи:
   - Дата вступления в силу
   - Источник (BGBl., Urteilsnummer, Link)
   - Что изменилось
   - Практические последствия для клиентов
