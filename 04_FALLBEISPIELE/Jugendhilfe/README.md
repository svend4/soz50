## Häufige Fallkonstellationen SGB VIII

- **SPFH abgelehnt** — Jugendamt verweigert Hilfe zur Erziehung
- **Inobhutnahme** — Ablauf, Elternrechte, Widerspruch
- **UMA** — unbegleitete minderjährige Ausländer
- **§ 35a abgelehnt** — Eingliederungshilfe für seelisch behinderte Kinder
- **Hilfeplan-Streit** — Eltern nicht einverstanden mit Maßnahme
- **Kostenheranziehung** — Eltern sollen zahlen (§ 92 SGB VIII)
