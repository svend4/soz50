## Häufige Probleme in der Pflege

```
→ Pflegegrad zu niedrig eingestuft (MDK-Gutachten fehlerhaft)
→ Pflegegeld-Einstufung ändert sich bei Krankenhausaufnahme
→ Verhinderungspflege / Kurzzeitpflege: Abrechnung unklar
→ Kombination Pflegegeld + Sachleistungen
→ Heimkostenübernahme: Wann zahlt Sozialamt (§ 61 SGB XII)?
→ Pflegeberatung (§ 7a SGB XI): Anrecht auf Pflegeberater!
```

---

## Tipps für Pflegegrad-Widersprüche

```
1. Pflegetagebuch vor Begutachtung führen (2–4 Wochen)
2. Angehörige bei Begutachtung dabei sein
3. MDK-Gutachten anfordern und prüfen (§ 25 SGB X)
4. Arztbriefe und Atteste sammeln
5. Bei < 47,5 Punkten: Prüfen ob 47,5 möglich → PG 3
6. Frist: 1 Monat ab Bescheid!
```
