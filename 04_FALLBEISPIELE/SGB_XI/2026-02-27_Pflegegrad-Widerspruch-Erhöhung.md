# Fallbeispiel: Pflegegrad-Widerspruch — Begutachtung angefochten

[← SGB XI Fallbeispiele](./README.md) | [← Fallbeispiele](../README.md)

---

## Ausgangssituation

**Person:** Frau G., 78 Jahre, lebt allein in Mietwohnung.

**Vorgeschichte:**
- Diabetes mellitus Typ 2, Polyneuropathie (Taubheitsgefühl Beine/Füße)
- Beginnende Demenz (leichte kognitive Beeinträchtigung)
- Schlaganfall vor 2 Jahren, seither Hemiparese rechts (Schwäche rechte Seite)
- Kann kaum Treppen steigen, Stürze in der Wohnung (2× in 3 Monaten)

**Das Problem:**
Pflegekasse bewilligte nach MDK-Begutachtung **Pflegegrad 2**.
Frau G. (und ihre Tochter) sind der Meinung, dass Pflegegrad 3 angemessen wäre.

Begutachtung fand statt während einer "guten Phase" der Patientin, die Tochter war nicht anwesend.

---

## Rechtliche Einordnung

### Pflegegradsystematik (§ 15 SGB XI)

```
Pflegegrad = Beeinträchtigungsgrad der Selbstständigkeit

Berechnung: Punkte aus 6 Modulen:
  1. Mobilität (10%)
  2. Kognitive/kommunikative Fähigkeiten (15%)
  3. Verhaltensweisen/psych. Problemlagen (15%)
  4. Selbstversorgung (40%)
  5. Umgang mit krankheitsbedingten Anforderungen (20%)
  6. Gestaltung des Alltagslebens (15%)
  [Gewichtung ohne Modul 6: Pflege + Betreuung]

Pflegegrade:
  PG 1: 12,5–26,9 Punkte (gering)
  PG 2: 27–47,4 Punkte (erheblich)  ← wurde bewilligt
  PG 3: 47,5–69,9 Punkte (schwer)    ← angestrebt
  PG 4: 70–89,9 Punkte (schwerst)
  PG 5: 90–100 Punkte (schwerst + besondere Anforderungen)
```

### Relevante Beeinträchtigungen bei Frau G.

```
Modul 1 (Mobilität):
  → Hemiparese rechts → eingeschränkte Fortbewegung
  → Treppensteigen kaum möglich
  → Stürze → Sturzvermeidungsverhalten (zusätzliche Einschränkung)

Modul 2 (Kognition):
  → Beginnende Demenz → Orientierungsprobleme
  → Vergessen von Medikamenten, Terminen

Modul 4 (Selbstversorgung):
  → Körperpflege: Hemiparese erschwert einhändige Tätigkeiten
  → Essen zubereiten: Eingeschränkt durch Neuropathie (kein Greifen)

MDK hat diese Punkte offenbar zu niedrig bewertet.
```

---

## Vorgehensweise

### Schritt 1: Widerspruch einlegen

```
Frist: 1 Monat ab Bescheid (§ 84 SGG für PKV, GKV: § 78 SGG)
→ Hier: Widerspruch am 15. Tag nach Bescheid

Inhalt Widerspruch:
  → "Wir fechten den Bescheid vom [Datum] an und beantragen Pflegegrad 3"
  → Konkrete Begründung: MDK-Gutachten unvollständig
  → Ankündigung Gegengutachten

Wichtig: MDK-Gutachten anfordern!
  → Recht auf Einsicht: § 25 SGB X
  → Pflegekasse muss Gutachten herausgeben
```

### Schritt 2: Gutachten analysieren

```
Nach Erhalt MDK-Gutachten geprüft:

Festgestellt:
  → Modul 1 (Mobilität): 9 Punkte (Gutachter: "kann 50m gehen")
    ABER: Tochter weiß: Frau G. geht kaum noch → 50m überschätzt
  → Modul 4 (Selbstversorgung): 22 Punkte
    ABER: Hemiparese nicht ausreichend gewürdigt (Greifen, Waschen)
  → Modul 2 (Kognition): nur 3 Punkte für Demenz
    ABER: Gedächtnistest-Ergebnisse vom Neurologen: MMS-Test 21/30 → leichtes Demenz-Stadium

Gesamtpunktzahl laut MDK: 44 Punkte → PG 2
Korrekte Gesamtpunktzahl (geschätzt): ca. 52–55 Punkte → PG 3
```

### Schritt 3: Beweise sammeln

```
Eingereichte Dokumente:
  1. Pflegetagebuch (2 Wochen Dokumentation durch Tochter):
     → Morgens: Körperpflege dauert 45 min mit Hilfe
     → Mahlzeiten: Vorbereitung durch Tochter nötig
     → Medikamente: Tochter stellt täglich
     → Einschlafen: Orientierungslosigkeit nachts (2× in 2 Wochen aufgewacht, Wohnung nicht erkannt)

  2. Arztbriefe:
     → Neurologe: MMS-Test 21/30, Diagnose "leichte vaskuläre Demenz"
     → Hausarzt: "erhebliche Einschränkung der Selbstständigkeit"
     → Physiotherapeut: "Hemiparese rechts, Gehhilfe nötig, Treppensteigen unmöglich"

  3. Stellungnahme zum MDK-Gutachten:
     → Punkt für Punkt Widerspruch gegen Bewertung
     → Eigene Punkteberechnung (ca. 52 Punkte)
```

### Schritt 4: Widerspruchsverfahren

```
Ablauf:
  → Pflegekasse holt eigenes neues MDK-Gutachten ein
  → Zweite Begutachtung: diesmal mit Tochter anwesend
  → Neue Punktzahl: 51,5 Punkte → Pflegegrad 3!

→ Abhilfebescheid: Pflegegrad 3 anerkannt
→ Rückwirkend ab Datum des Widerspruchs (oder sogar Erstantrag, § 33 SGB XI)
```

---

## Ergebnis

**Pflegegrad 3 bewilligt** — rückwirkend ab Datum des Widerspruchs.

**Leistungsverbesserung PG 2 → PG 3:**
```
Pflegegeld (häusliche Pflege durch Angehörige):
  PG 2: 332 €/Monat
  PG 3: 573 €/Monat
  → Mehr: 241 €/Monat

Pflegesachleistung (ambulanter Dienst):
  PG 2: 761 €/Monat
  PG 3: 1.432 €/Monat
  → Mehr: 671 €/Monat

Kombinationsleistung möglich!
```

## Lernpunkte

### 1. Pflegetagebuch führen (IMMER!)

```
→ 2–4 Wochen vor Begutachtung dokumentieren
→ Pro Tag: Welche Hilfe, wie lange, bei was?
→ Konkret: "Morgens Körperpflege 45 min mit Hilfe"
   statt "braucht viel Hilfe"
→ Nachts: Orientierungslosigkeit, Stürze dokumentieren
→ Das Tagebuch beim Gutachter VORLEGEN
```

### 2. Bei Begutachtung anwesend sein

```
→ Angehörige MÜSSEN anwesend sein dürfen!
→ Sie können Korrekturen zum Gesundheitszustand machen
→ "Gute Phasen" vs. Alltag unterscheiden
→ Gutachter fragt: "Können Sie alleine Treppen steigen?"
   → Betroffener sagt "ja, wenn ich mich festhalte"
   → Angehöriger ergänzt: "Hat 2 Monate nicht mehr versucht, aus Angst"
```

### 3. MDK-Gutachten immer anfordern und prüfen

```
→ Recht auf Herausgabe (§ 25 SGB X)
→ Jede Bewertung nachvollziehen
→ Fehler: zu optimistische Einschätzung, Diagnosen nicht berücksichtigt
→ Eigene Punkteberechnung erstellen (Punkte-Tabellen sind öffentlich)
```

### 4. Zweites Gutachten einleiten

```
→ Im Widerspruch: Zweite Begutachtung verlangen
→ MDK ist NICHT unabhängig (im Auftrag der Kasse)
→ Alternative: Gutachten von unabhängigem Medizinischen Gutachter einholen
  (Privatgutachter ca. 300–600 €, aber beweisrelevant)
```

### 5. Zeitpunkt der Begutachtung

```
→ "Gute Phasen" vs. "schlechte Phasen" — MDK kommt einmal
→ Falls Termin ungünstig: Verschiebung anfragen!
→ Falls Person nach Begutachtung schlechter geworden: NEUER ANTRAG!
```

## Checkliste Pflegegrad-Widerspruch

```
□ Widerspruch innerhalb 1 Monat eingelegt?
□ MDK-Gutachten angefordert und erhalten?
□ Gutachten Punkt für Punkt geprüft?
□ Pflegetagebuch vorhanden (oder nachträglich erstellt)?
□ Arztbriefe/Atteste die Einschränkungen belegen?
□ Angehörige beim Zweitgutachten anwesend?
□ Rückwirkende Bewilligung beantragt?
```
