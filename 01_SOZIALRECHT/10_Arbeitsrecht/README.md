## Kündigungsrecht — Увольнение

### Kündigungsschutz (KSchG)

```
Gilt wenn:
  ✓ Betrieb > 10 Arbeitnehmer (Vollzeit)
  ✓ Arbeitsverhältnis > 6 Monate (Wartezeit)

Dann: Kündigung nur aus wichtigem Grund:
  → personenbedingt (krankheitsbedingt, fehlende Eignung)
  → verhaltensbedingt (Fehlverhalten — meist Abmahnung zuerst!)
  → betriebsbedingt (Stellenabbau, Umstrukturierung)
```

### Kündigungsfristen (§ 622 BGB)

| Beschäftigungsdauer | Frist |
|--------------------|-------|
| Probezeit (bis 6 Monate) | 2 Wochen, jederzeit |
| bis 2 Jahre | 4 Wochen zum 15. oder Monatsende |
| 2–5 Jahre | 1 Monat zum Monatsende |
| 5–8 Jahre | 2 Monate zum Monatsende |
| 8–10 Jahre | 3 Monate |
| 10–12 Jahre | 4 Monate |
| 12–15 Jahre | 5 Monate |
| 15–20 Jahre | 6 Monate |
| > 20 Jahre | 7 Monate |

### Besonderer Kündigungsschutz

| Gruppe | Schutz |
|--------|--------|
| Schwangere | Kündigung verboten (MuSchG) |
| Elternzeit | Kündigung verboten (BEEG) |
| Schwerbehinderte (GdB ≥ 50) | Zustimmung Integrationsamt nötig (§ 168 SGB IX) |
| Betriebsrat | Kündigung nur mit BR-Anhörung (§ 102 BetrVG) |
| Datenschutzbeauftragte | Sonderkündigungsschutz |

### Was tun bei Kündigung?

```
Frist: 3 WOCHEN nach Erhalt → Klage beim Arbeitsgericht (§ 4 KSchG)
  → Sonst: Kündigung wird wirksam, auch wenn rechtswidrig!
  → Klage kostenlos, kein Anwalt nötig

Sofort:
  [ ] Kündigung schriftlich? (Unterschrift erforderlich!)
  [ ] Datum des Erhalts notieren!
  [ ] Zeugnis verlangen (§ 109 GewO)
  [ ] Arbeitgeber muss Restlohn, Urlaub auszahlen
  [ ] Bei ALG I: sofort Arbeitslosigkeit melden (Agentur für Arbeit)
```

## Mindestlohn (MiLoG)

```
Aktueller gesetzlicher Mindestlohn: 12,82 €/Stunde (2025)
  → Erhöhungen jährlich durch Mindestlohnkommission

Ausnahmen (KEIN Mindestlohn):
  → Auszubildende (eigene Ausbildungsvergütung)
  → Praktikum bis 3 Monate (Pflicht- oder freiwillig)
  → Ehrenamt
  → Selbstständige

Bei Unterschreitung:
  → Anspruch auf Nachzahlung (3 Jahre Verjährung)
  → Klage Arbeitsgericht oder Meldung beim Zoll (Finanzkontrolle Schwarzarbeit)
```

## Arbeitslosengeld I (SGB III) — ALG I

```
Anspruch wenn:
  ✓ Sozialversicherungspflichtig beschäftigt (mind. 12 Monate in 2 Jahren)
  ✓ Arbeitslos gemeldet bei Agentur für Arbeit
  ✓ Verfügbar für Arbeit

Höhe: 60% des pauschalierten Nettolohns (67% mit Kind)
Dauer: abhängig von Beitragsdauer und Alter

| Beitragsdauer | Leistungsdauer |
|--------------|----------------|
| 12 Monate | 6 Monate |
| 16 Monate | 8 Monate |
| 20 Monate | 10 Monate |
| 24 Monate | 12 Monate |
| 30 Monate (ab 50 J.) | 15 Monate |
| 36 Monate (ab 55 J.) | 18 Monate |
| 48 Monate (ab 58 J.) | 24 Monate |

Sperrzeit: 12 Wochen bei eigener Kündigung / Aufhebungsvertrag
  → In dieser Zeit kein ALG I!
  → Ausnahme: wichtiger Grund (Umzug wegen Partner, gesundheitl. Gründe)
```

## Diskriminierung am Arbeitsplatz (AGG)

```
Allgemeines Gleichbehandlungsgesetz (AGG):
  Merkmale: Rasse/Ethnizität, Geschlecht, Religion, Behinderung,
            Alter, sexuelle Identität

Ansprüche bei Diskriminierung:
  → Entschädigung (§ 15 AGG)
  → Frist: 2 Monate nach Kenntnis! (§ 15 Abs. 4 AGG)
  → Klage: Arbeitsgericht

Beratung:
  → Antidiskriminierungsstelle des Bundes (ads.bund.de)
  → Gewerkschaften
```

## Scheinselbstständigkeit — важно для мигрантов

```
Scheinselbstständigkeit liegt vor wenn:
  → Person ist wirtschaftlich abhängig von einem Auftraggeber
  → Keine eigene unternehmerische Freiheit
  → Eingliederung in die Organisation des Auftraggebers

Folge: Sozialversicherungspflicht rückwirkend!
  → Krankenkasse kann Beiträge nachfordern
  → Rentenversicherung prüft

Relevant für:
  → Lieferdienste (Fahrradkuriere)
  → "Freelancer" in der Pflege
  → Reinigungskräfte
```

## Arbeitsgericht — Klage ohne Anwalt

```
Arbeitsgericht = kostenlos in erster Instanz (§ 12a ArbGG)
  → Kein Anwaltszwang in 1. Instanz
  → Güteterm in: schnelle Einigung oft möglich

Klage einreichen:
  → Persönlich beim Arbeitsgericht (Rechtsantragsstelle)
  → Schriftlich (formlos möglich)
  → Wichtig: FRISTEN beachten!
    - Kündigungsschutzklage: 3 WOCHEN
    - Lohnklage: 3 Jahre Verjährung
    - Diskriminierung: 2 MONATE
```
