# Krankenversicherung — Медицинское страхование

[← Sozialrecht](../README.md) | [← Главная](../../README.md)

> В Германии: **Pflicht zur Krankenversicherung** (с 2009).
> Zwei Systeme: **GKV** (gesetzlich) и **PKV** (privat).
> Для людей в социальных ситуациях — преимущественно GKV.

---

## Wer ist wie versichert?

```
Erwerbstätig (Arbeitnehmer)
  → GKV pflichtversichert (bis Jahresarbeitsentgeltgrenze ~69.300 € 2026)
  → Beitrag: ~14,6% + Zusatzbeitrag (je Kasse ca. 1–2%) — je 50% AG/AN

Bürgergeld-Bezieher (SGB II)
  → GKV — Beiträge zahlt Bundesagentur für Arbeit
  → Freie Kassenwahl

Sozialhilfe (SGB XII)
  → GKV — Beiträge zahlt Sozialamt

AsylbLG-Bezieher
  → KEIN GKV-Schutz!
  → Gesundheitsversorgung nach § 4 AsylbLG (nur akut + Schwangerschaft)
  → Krankenschein / Behandlungsschein vom Sozialamt

Rentner
  → Krankenversicherung der Rentner (KVdR) wenn Vorversicherungszeit erfüllt
  → Sonst: freiwillig GKV oder PKV

Familienversicherung (§ 10 SGB V)
  → Mitversicherung Ehepartner + Kinder (kostenfrei)
  → Voraussetzung: kein eigenes Einkommen über 505 €/Monat (2026)
```

## GKV — Leistungen (§§ 11–68 SGB V)

| Leistungsbereich | Inhalt |
|-----------------|--------|
| Ärztliche Behandlung | Hausarzt, Fachärzte, Überweisungen |
| Krankenhausbehandlung | Vollstationär, ambulant |
| Arzneimittel | Rezeptpflichtige Medikamente (Zuzahlung 5–10 € max.) |
| Heilmittel | Physio, Ergo, Logo (nach Verordnung) |
| Zahnbehandlung | Basisversorgung; Zahnersatz = Festzuschuss |
| Vorsorgeuntersuchungen | U1–U9 (Kinder), Krebsvorsorge, Gesundheitscheck |
| Mutterschaftsleistungen | Schwangerschaft, Entbindung, Wochenbett |
| Krankengeld | Ab 7. Krank-Tag: 70% Bruttolohn (max. 78 Wochen) |
| Haushaltshilfe | Bei Krankheit, wenn Kinder unter 12 im Haushalt |

---

## Zuzahlungen (Eigenbeteiligung)

| Leistung | Zuzahlung | Maximum/Jahr |
|---------|-----------|-------------|
| Medikament | 5–10 € je Packung | Belastungsgrenze |
| Krankenhausaufenthalt | 10 €/Tag (max. 28 Tage/Jahr) | — |
| Heilmittel | 10% + 10 € Rezeptgebühr | — |
| Zahnersatz | Festzuschuss (Rest selbst) | — |

**Belastungsgrenze:** 2% Bruttoeinkommen/Jahr (1% bei chronisch Kranken).
→ Über Belastungsgrenze: **Befreiung** beim Krankenkasse beantragen!

## Krankengeld — больничные

```
§ 44 SGB V:
  → Ab dem 4. Krankheitstag Attest (AU-Bescheinigung)
  → Arbeitgeber zahlt 6 Wochen Entgeltfortzahlung (voller Lohn)
  → Ab 7. Woche: Krankengeld von Krankenkasse
     = 70% des Bruttolohns, max. 90% des Nettolohns
  → Höchstdauer: 78 Wochen in 3 Jahren (für dieselbe Krankheit)
  → Danach: Antrag auf Erwerbsminderungsrente prüfen!
```

## Sondersituationen

### Kein Krankenversicherungsschutz

```
Seit 2013: Recht auf Rückkehr in GKV für zuletzt GKV-Versicherte
  → Meldung bei letzter GKV → Aufnahmepflicht
  → Nachzahlung von Beiträgen (max. seit 2013) — aber: Erlass möglich!

Sozialhilfe-Empfänger ohne KV:
  → § 264 SGB V: Sozialamt übernimmt Behandlungskosten direkt
  → Krankenschein = Behandlungsschein vom Sozialamt
```

### Asylsuchende / AsylbLG

```
§ 4 AsylbLG:
  → Akute Erkrankungen und Schmerzzustände: Behandlung
  → Schwangerschaft und Geburt: vollständige Versorgung
  → Impfungen: § 4 Abs. 3

§ 6 AsylbLG (Ermessen):
  → Chronische Erkrankungen, Psychotherapie, Hilfsmittel
  → Ablehnung oft rechtswidrig → Widerspruch!
  → Tipp: ärztliche Verordnung + Attest Notwendigkeit = stärkere Position
```
