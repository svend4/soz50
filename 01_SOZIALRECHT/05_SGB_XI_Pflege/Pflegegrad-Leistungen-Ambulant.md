# Ambulante Pflegeleistungen SGB XI

[← SGB XI Pflege](./README.md) | [← Sozialrecht](../README.md)

> Ambulante Pflege = Pflege zu Hause (nicht im Heim).
> Alle Leistungen setzen einen **Pflegegrad** voraus.
> Pflegegrad 1: eingeschränkte Leistungen; Pflegegrad 2–5: volle Leistungen.
> Kombi-Leistung: Sachleistung + Pflegegeld kombinieren (§ 38 SGB XI)!

---

## Überblick: Ambulante Leistungsarten

```
GELDLEISTUNG:
  → Pflegegeld (§ 37 SGB VIII): für selbst organisierte Pflege (Familie etc.)

SACHLEISTUNG:
  → Pflegesachleistung (§ 36 SGB XI): Pflegedienst auf Kosten der Kasse

KOMBINATION:
  → Kombinationsleistung (§ 38 SGB XI): Geld + Sachleistung kombinieren

ENTLASTUNG:
  → Verhinderungspflege (§ 39 SGB XI): wenn Pflegeperson verhindert
  → Kurzzeitpflege (§ 42 SGB XI): zeitweise ins Heim
  → Tages-/Nachtpflege (§ 41 SGB XI): teilstationär

ERGÄNZEND:
  → Entlastungsbetrag (§ 45b SGB XI): für niedrigschwellige Betreuungsangebote
  → Pflegehilfsmittel (§ 40 SGB XI): Handschuhe, Bettschutz etc.
  → Wohnumfeldverbesserung (§ 40 Abs. 4 SGB XI): Umbau Wohnung
```

## Pflegegeld (§ 37 SGB XI)

```
Voraussetzung:
  → Pflegegrad 2, 3, 4 oder 5
  → Pflege durch eigene Pflegeperson (Familie, Nachbar, Freunde)
  → Pflegeperson = kein professioneller Pflegedienst!

Beträge 2025:
  Pflegegrad 2:  332 € → 347 €/Monat (ab 01.01.2025)
  Pflegegrad 3:  573 € → 599 €/Monat
  Pflegegrad 4:  765 € → 800 €/Monat
  Pflegegrad 5:  947 € → 990 €/Monat

Nachweis der Pflege:
  → Halbjährlicher Beratungsbesuch (§ 37 Abs. 3 SGB XI): PFLICHT!
  → Pflegegrad 2+3: alle 6 Monate (oder bei Bedarf)
  → Pflegegrad 4+5: alle 3 Monate!
  → Kein Beratungsbesuch → Pflegekasse kürzt / setzt aus!
  → Wo: ambulanter Pflegedienst oder Beratungsstelle (Pflegestützpunkt)

Pflegeperson:
  → Ab 30 h/Monat: Rentenversicherungspflicht für Pflegeperson!
    (Pflegekasse zahlt Beiträge → § 44 SGB XI)
  → Arbeitslosenversicherung: möglich (§ 26 SGB III)
  → Unfallversicherung: automatisch (§ 2 Abs. 1 Nr. 17 SGB VII)
```

## Pflegesachleistung (§ 36 SGB XI)

```
Was wird geleistet:
  → Körperpflege: Waschen, Baden, Duschen, Mundpflege
  → Ernährung: Hilfe beim Essen und Trinken
  → Mobilität: Aufstehen, Zubettgehen, Gehen
  → Hauswirtschaft: Reinigung, Kochen (nur wenn Pflegebedarf besteht!)

Wer erbringt es:
  → Zugelassene ambulante Pflegedienste (§ 72 SGB XI)
  → Kasse zahlt direkt an Pflegedienst
  → Klient hat freie Wahl des Pflegedienstes!

Beträge 2025 (monatliches Sachleistungsbudget):
  Pflegegrad 2:  761 € → 796 €/Monat
  Pflegegrad 3: 1.432 € → 1.497 €/Monat
  Pflegegrad 4: 1.778 € → 1.859 €/Monat
  Pflegegrad 5: 2.200 € → 2.299 €/Monat

Wenn Sachleistung nicht voll ausgeschöpft:
  → Nicht genutzter Teil verfällt (kein Übertrag!)
  → ABER: Kombinationsleistung (§ 38) nutzen!
```

## Kombinationsleistung (§ 38 SGB XI)

```
Prinzip:
  → Sachleistung (Pflegedienst) + Pflegegeld kombinierbar!
  → Wenn Sachleistung nicht voll genutzt: Pflegegeld anteilig
  → Formel: Pflegegeld × (1 - genutzter Sachleistungsanteil)

Beispiel Pflegegrad 3:
  Sachleistungsbudget: 1.497 €
  Genutzter Pflegedienst: 800 € = 53,4%
  Nicht genutzter Anteil: 46,6%
  Pflegegeld anteilig: 599 € × 46,6% = 279 €/Monat

Warum Kombinationsleistung?
  → Optimal wenn: Pflegedienst für Körperpflege + Familie hilft zusätzlich
  → Kombileistung ergibt oft mehr als nur Geld oder nur Sachleistung!
  → Antrag: bei Pflegekasse (formlos!)
```

## Verhinderungspflege (§ 39 SGB XI)

```
Was ist das:
  → Wenn die pflegende Person verhindert ist (Urlaub, Krankheit, sonstige Gründe)
  → Ersatzpflege durch andere Person oder professionellen Dienst

Voraussetzungen:
  → Pflegegrad 2–5
  → Pflegeperson hat mind. 6 Monate vor Verhinderung gepflegt
  → Verhinderung: zeitlich begrenzt

Leistungshöhe 2025:
  → Bis 1.612 €/Jahr (2024: 1.612 €)
  → Bis zu 6 Wochen Verhinderung absicherbar
  → TIPP: Nicht genutztes Kurzzeitpflegebudget → 50% = zusätzlich für Verhinderungspflege!
    → Maximal: 1.612 € + 0,5 × 1.854 € = 2.539 €

Wer kann Verhinderungspflege erbringen:
  → Nahestehende Personen (Familie, Freunde): nur bis Pflegegeldhöhe!
    → PG 3: max. 599 €/Monat (= Pflegegeld PG 3)
  → Professioneller Pflegedienst: voller Betrag bis 1.612 €
  → Fernverwandte + nicht-Verwandte: voller Betrag möglich
```

## Kurzzeitpflege (§ 42 SGB XI)

```
Was ist das:
  → Vorübergehend ins Pflegeheim (zeitlich begrenzt)
  → Wenn häusliche Pflege nicht möglich (Krankenhausaufenthalt, Krise)

Voraussetzungen:
  → Pflegegrad 2–5
  → Pflegedürftiger kann nicht zuhause versorgt werden

Leistungshöhe 2025:
  → Bis 1.854 €/Jahr (2024: 1.774 €)
  → Max. 8 Wochen im Jahr
  → TIPP: Nicht genutztes Verhinderungspflegebudget → bis 50% = zusätzlich!
    → Maximal: 1.854 € + 0,5 × 1.612 € = 2.660 €

Wo:
  → Jedes zugelassene Pflegeheim (mit Kurzzeitpflege-Platz)
  → Antrag: bei Pflegekasse (vorher abklären!)
  → Eigenanteil: Heimentgelt minus 1.854 € muss selbst getragen werden
```

## Tages- und Nachtpflege (§ 41 SGB XI)

```
Was ist das:
  → Teilstationäre Pflege (nicht 24h)
  → Tagsüber im Pflegeheim, nachts zu Hause — oder umgekehrt

Beträge 2025:
  Pflegegrad 2:  796 €/Monat
  Pflegegrad 3: 1.497 €/Monat
  Pflegegrad 4: 1.859 €/Monat
  Pflegegrad 5: 2.299 €/Monat

Kombination mit Häuslicher Pflege:
  → Tages-/Nachtpflege ZUSÄTZLICH zu Sachleistung + Pflegegeld!
  → Keine Anrechnung auf Sachleistungsbudget (§ 41 Abs. 4 SGB XI)
  → Sehr wertvolle Ergänzung: Pflegeperson hat tagsüber frei

Vorteil:
  → Pflegeperson entlastet (kann arbeiten gehen)
  → Tagesstruktur für Pflegebedürftigen
  → Soziale Kontakte erhalten
```

## Entlastungsbetrag (§ 45b SGB XI)

```
Wer:
  → ALLE Pflegebedürftigen ab Pflegegrad 1!
  → Auch Pflegegrad 1 (der sonst wenig Leistungen bekommt)

Betrag:
  → 125 €/Monat = 1.500 €/Jahr
  → Kein Übertrag über Jahresende (Verfall am 31.12.!)
    → AUSNAHME: bis 30. Juni des Folgejahres verwendbar (Kulanz-Regelung 2019+)

Wofür verwendbar:
  → Anerkannte niedrigschwellige Betreuungsangebote:
    → Betreuungsgruppen, Nachbarschaftshilfen, Tagespflege
    → Pflegedienste (für Betreuungsleistungen, nicht Körperpflege)
    → Haushaltshilfen (wenn vom Land anerkannt)
  → Nicht: Sachleistungen der eigentlichen Pflege

Wie beantragen:
  → Formlos bei Pflegekasse
  → Rechnungen vom anerkannten Anbieter einreichen
  → Erstattung: Pflegekasse zahlt an Klienten zurück

PRAXIS-TIPP:
  → Viele nutzen Entlastungsbetrag nicht! → Aktiv darauf hinweisen!
  → 125 €/Monat × 12 = 1.500 € / Jahr ungenutzt = verschenkt!
  → Anbietersuche: pflegekasse.de oder Pflegestützpunkt
```

## Pflegehilfsmittel (§ 40 SGB XI)

```
Technische Pflegehilfsmittel:
  → Pflegebett, Rollstuhl, Rollator: auf ärztliche Verordnung
  → GKV und Pflegekasse: Zuständigkeit klären!
  → GKV: Hilfsmittel zur Krankenbehandlung (§ 33 SGB V)
  → Pflegekasse: Hilfsmittel die Pflege erleichtern (§ 40 Abs. 1 SGB XI)

Verbrauchsmittel (Pflegehilfsmittel § 40 Abs. 2):
  → Pauschal 40 €/Monat für:
    → Einmalhandschuhe, Bettschutzunterlagen, Desinfektionsmittel
  → Kein Nachweis über Verwendung nötig!
  → Antrag: formlos bei Pflegekasse

Wohnumfeldverbesserung (§ 40 Abs. 4 SGB XI):
  → Bis 4.000 € je Maßnahme (z.B. Treppenlifter, barrierefreies Bad)
  → Mehrfach je Wohnung möglich!
  → Bei mehreren Pflegebedürftigen in einer Wohnung: bis 16.000 €
  → Antrag VOR der Maßnahme stellen!
  → Pflegekasse muss zustimmen (sonst kein Geld!)
```

## Soziale Sicherung pflegender Angehöriger

```
RENTENVERSICHERUNG (§ 44 SGB XI):
  → Pflegeperson bei mind. 10 h/Woche Pflege + nicht > 30 h/Woche berufstätig:
    → Pflegekasse zahlt RV-Beiträge für Pflegeperson!
  → Berechnungsgrundlage: Pflegegrad × Berechnungsgröße
  → Höhere Pflegegrade = mehr Rentenpunkte für Pflegeperson

ARBEITSLOSENVERSICHERUNG (§ 26 Abs. 2b SGB III):
  → Freiwillige Arbeitslosenversicherung für pflegende Angehörige
  → Beitrag: 35,20 €/Monat (2025 ca.)
  → Sinnvoll wenn: Pflege beendet → ALG I für eigene Übergangsphase

KRANKEN- + PFLEGEVERSICHERUNG:
  → Nicht automatisch gesichert!
  → Wenn Pflege aufgenommen + Beschäftigung aufgegeben:
    → GKV-Familienversicherung prüfen (kostenfrei wenn kein eigenes Einkommen)
    → Freiwillige GKV-Mitgliedschaft wenn kein Anspruch auf Familienvers.

UNFALLVERSICHERUNG:
  → Automatisch (§ 2 Abs. 1 Nr. 17 SGB VII)
  → Gilt für pflegende Angehörige
  → Bei Unfall während Pflege: BG-Leistungen
```

## Beratungsangebote

```
PFLEGEBERATUNG (§ 7a SGB XI):
  → Jeder Pflegebedürftige hat Anspruch auf kostenlose Pflegeberatung!
  → Pflegekasse muss Beratung anbieten (persönlich oder telefonisch)
  → Pflegestützpunkte: regional, meist kostenlos

PFLEGESTÜTZPUNKTE:
  → Gemeinsam von Kranken- und Pflegekasse betrieben
  → Neutrale Beratung (kassenübergreifend!)
  → Auch: Entlastungsgespräch für Angehörige

HÄUSLICHE KRANKENPFLEGE (§ 37 SGB V — GKV!):
  → Ärztlich verordnet: für Behandlungspflege (Verbandwechsel, Medikamentengabe)
  → NICHT identisch mit Pflegesachleistung (SGB XI)!
  → Beide können gleichzeitig laufen: GKV + Pflegekasse!
```
