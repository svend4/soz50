# SGB XI — Soziale Pflegeversicherung

[← Sozialrecht](../README.md) | [← Главная](../../README.md)

> **SGB XI** — Elftes Buch Sozialgesetzbuch.
> Pflegeversicherung как обязательное страхование (Pflichtversicherung).
> Ведомство: **Pflegekasse** (при Krankenkasse).

---

## Pflegegrade — степени ухода

| Pflegegrad | Beschreibung | Punkte NBI |
|------------|-------------|-----------|
| PG 1 | Geringe Beeinträchtigung | 12,5–26,9 |
| PG 2 | Erhebliche Beeinträchtigung | 27–47,5 |
| PG 3 | Schwere Beeinträchtigung | 47,5–69,9 |
| PG 4 | Schwerste Beeinträchtigung | 70–89,9 |
| PG 5 | Schwerste Beeinträchtigung mit besonderen Anforderungen | 90–100 |

> **NBI** = Neues Begutachtungsinstrument (с 2017)

---

## Antrag und Begutachtung

```
1. Antrag bei Pflegekasse stellen
2. Begutachtung durch MDK (Medizinischer Dienst) oder MEDICPROOF
3. Pflegegrad-Feststellung → Bescheid
4. Bei Ablehnung: Widerspruch (1 Monat) → Klage (Sozialgericht)
```
