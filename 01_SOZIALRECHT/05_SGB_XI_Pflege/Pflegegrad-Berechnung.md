# Pflegegrad — Berechnung, Begutachtung, Widerspruch

[← SGB XI Pflege](./README.md)

> Pflegegrad = wie viel Selbstständigkeit ist eingeschränkt?
> Das **NBA-System** (Neues Begutachtungs-Assessment) bewertet 6 Module.
> Wer die Berechnung kennt, kann gezielt Widerspruch einlegen.

---

## Überblick Pflegegrade

| Pflegegrad | Bezeichnung | Punkte gesamt | Pflegegeld 2025 | Sachleistung 2025 |
|-----------|-------------|---------------|-----------------|-------------------|
| PG 1 | geringe Beeinträchtigung | 12,5 – 26,9 | — | — |
| PG 2 | erhebliche Beeinträchtigung | 27 – 47,4 | 347 € | 796 € |
| PG 3 | schwere Beeinträchtigung | 47,5 – 69,9 | 599 € | 1.497 € |
| PG 4 | schwerste Beeinträchtigung | 70 – 89,9 | 800 € | 1.859 € |
| PG 5 | schwerste Beintr. mit besond. Anforderungen | 90 – 100 | 990 € | 2.299 € |

```
PG 1: Leistungen eingeschränkt (nur Beratung + Pflegekassenleistungen)
PG 2–5: Volles Leistungsspektrum
PG 5: Erhöhte Leistungen wenn besondere Bedarfskonstellation
```

## Die 6 Module des NBA

```
Das Neue Begutachtungs-Assessment (NBA) prüft 6 Module:

Modul 1: Mobilität
  → Körperliche Fortbewegung: Treppensteigen, Gehen, Aufstehen
  → Max. Punkte: 10

Modul 2: Kognitive und kommunikative Fähigkeiten
  → Gedächtnis, Orientierung, Entscheidungen, Kommunikation
  → Max. Punkte: 15

Modul 3: Verhaltensweisen und psychische Problemlagen
  → Herausforderndes Verhalten, Angst, Antriebslosigkeit
  → Max. Punkte: 65 (wird aber gewichtet: × 0,15)

Modul 4: Selbstversorgung
  → Körperpflege, Essen, Toilette, Ankleiden
  → Max. Punkte: 40 (höchste Gewichtung!)

Modul 5: Bewältigung und Umgang mit krankheitsbedingten Anforderungen
  → Medikamente, Verbandswechsel, Arzttermine
  → Max. Punkte: 75 (gewichtet: × 0,10)

Modul 6: Gestaltung des Alltagslebens und sozialer Kontakte
  → Tagesstrukturierung, soziale Kontakte, Freizeitgestaltung
  → Max. Punkte: 30
```

## Gewichtung der Module

```
Gewichtung (§ 15 SGB XI + Begutachtungsrichtlinien):

  Modul 1 (Mobilität):              10%  (0,10)
  Modul 2 (Kognition):         )
  Modul 3 (Verhalten):         )  15%  für den HÖHEREN Wert beider Module
  Modul 4 (Selbstversorgung):       40%  (0,40)  ← wichtigster Modul!
  Modul 5 (Krankheitsbewältigung):  20%  (0,20)
  Modul 6 (Alltagsgestaltung):      15%  (0,15)

Berechnung:
  → Für jeden Modul: Punkte × Gewichtungsfaktor = gewichtete Punkte
  → Alle gewichteten Punkte addieren = Gesamtpunktzahl
  → Gesamtpunktzahl → Pflegegrad-Tabelle
```

### Berechnungsbeispiel

```
Herr M., 78 Jahre, nach Schlaganfall:

Modul 1 (Mobilität):    6 Punkte × 0,10 = 0,6
Modul 2 (Kognition):    6 Punkte
Modul 3 (Verhalten):    12 Punkte  → höher = 12 × 0,15 = 1,8
Modul 4 (Selbst.):     22 Punkte × 0,40 = 8,8
Modul 5 (Krankheit):   30 Punkte × 0,20 = 6,0
Modul 6 (Alltag):       8 Punkte × 0,15 = 1,2

Summe: 0,6 + 1,8 + 8,8 + 6,0 + 1,2 = 18,4 → PG 2 (Grenze: 12,5)

Aber: Wenn Modul 4 tatsächlich 28 Punkte:
  28 × 0,40 = 11,2
  Summe: 0,6 + 1,8 + 11,2 + 6,0 + 1,2 = 20,8 → immer noch PG 2

  Wenn Modul 4 bei 35 Punkte: 35 × 0,40 = 14,0 → Summe 24,6 → fast PG 3!
  Grenze PG 3: 27 Punkte Gesamt
```

## Typische Fehler des MD-Gutachtens

```
HÄUFIGE FEHLERQUELLEN:

1. "Gute Phase" während Begutachtung
   → MD kommt an einem "guten Tag"
   → Person zeigt sich von bester Seite (Scham, Stolz)
   → Gutachter beobachtet 1 Stunde — alltagsuntypisch!

   GEGENMASSNAHME:
   → Pflegetagebuch führen! (mind. 2 Wochen vor Begutachtung)
   → Pflegeperson erzählt von typischen Tagen (schlechten!)
   → Fotos / Videos wenn möglich (mit Einverständnis)

2. Beurteilung "was Person theoretisch könnte"
   → MD schreibt: "Patient könnte grundsätzlich..."
   → ABER: Relevant ist was Person TATSÄCHLICH und SICHER kann!
   → Bei Sturzgefahr: Unselbstständigkeit auch wenn technisch möglich

3. Kognitive Einschränkungen unterschätzt
   → Demenzkranke "funktionieren" kurzfristig gut
   → Langfristige Beeinträchtigungen nicht sichtbar in 60-Minuten-Besuch
   → GEGENMASSNAHME: Arztbriefe, Diagnosen, Alltagsschilderungen

4. Psychische Module untergewichtet
   → Depression, Angststörungen → Antriebslosigkeit dokumentieren!
   → Modul 3 (Verhalten): Aggressive Phasen, Weinen, Rückzug

5. Modul 5 unvollständig erhoben
   → Medikamenteneinnahme: Wie viele Medikamente? Selbst steuerbar?
   → Arzttermine: Wie oft? Wer begleitet?
   → Verbandswechsel, Insulininjektionen, Sauerstofftherapie
```

## Widerspruch gegen Pflegegrad — Strategie

```
VORGEHEN:

Schritt 1: Aktuelles Gutachten anfordern
  → Pflegekasse muss Gutachten herausgeben! (§ 18 Abs. 4 SGB XI)
  → Antrag: "Ich beantrage die Übersendung des vollständigen
    Gutachtens des Medizinischen Dienstes"

Schritt 2: Gutachten durcharbeiten
  → Alle 6 Module: Sind die Punktwerte richtig?
  → Wurden alle Einschränkungen erfasst?
  → Waren Angaben der Pflegeperson ausreichend berücksichtigt?

Schritt 3: Widerspruch formulieren
  → Frist: 1 Monat ab Bescheid (§ 84 SGG)
  → Konkrete Punkte benennen:
    "In Modul 4, Kriterium 'Körperwaschung', wurden 1 Punkt vergeben.
    Tatsächlich ist meine Mutter überwiegend unselbstständig (= 2 Punkte),
    da sie [konkrete Begründung]."

Schritt 4: Gegenbeweise sammeln
  → Pflegetagebuch (2–4 Wochen)
  → Attest vom Hausarzt / Facharzt
  → Krankenhausbriefe, Befundberichte
  → Aussage der Pflegeperson (schriftlich)

Schritt 5: Zweitgutachten beantragen
  → Bei Widerspruch: MD führt Zweitbegutachtung durch
  → Oder: Privatgutachter (teuer, aber manchmal nötig)
  → Sozialgericht: Gericht holt oft eigenes Gutachten ein!
```

## Leistungen nach Pflegegrad (2025)

```
Pflegegeld (§ 37 SGB XI) — für private Pflege:
  PG 2: 347 €/Monat
  PG 3: 599 €/Monat
  PG 4: 800 €/Monat
  PG 5: 990 €/Monat

Pflegesachleistung (§ 36 SGB XI) — für ambulanten Dienst:
  PG 2:   796 €/Monat
  PG 3: 1.497 €/Monat
  PG 4: 1.859 €/Monat
  PG 5: 2.299 €/Monat

Kombinationsleistung (§ 38 SGB XI):
  → Teilweise Sachleistung + anteiliges Pflegegeld möglich

Verhinderungspflege (§ 39 SGB XI) ab 07/2025:
  → Einheitlicher Betrag 3.539 €/Jahr (Verhinderung + Kurzzeitpflege zusammen)
  → Einsetzbar für Verhinderungspflege, Kurzzeitpflege oder beides

Vollstationäre Pflege (§ 43 SGB XI):
  PG 2: 770 €/Monat
  PG 3: 1.262 €/Monat
  PG 4: 1.775 €/Monat
  PG 5: 2.005 €/Monat
  → Eigenanteil: je nach Heim und Bundesland 1.500–3.500 €/Monat
  → Bei Überschreitung: Hilfe zur Pflege SGB XII! (§ 61 SGB XII)

Entlastungsbetrag (§ 45b SGB XI):
  → PG 1–5: 125 €/Monat (zweckgebunden für Entlastungsleistungen)
  → Kann angespart werden (max. 12 Monate)
```

## Besonderheiten bei Demenz

```
Demenz und NBA:
  → NBA bevorzugt kognitive Einschränkungen (gut für Demenzkranke!)
  → Modul 2 + 3 spielen große Rolle
  → Schwere Demenz → oft direkt PG 3 oder höher

ABER: Häufige Fehler bei Demenz-Begutachtung:
  → Person "funktioniert" kurz während Besuch
  → Eingeschränkte Eigenauskünfte → Pflegeperson muss sprechen!
  → Tipp: Pflegeperson bereitet Liste typischer Probleme vor

  Beispiele für Modul 3 bei Demenz:
  → Nächtliche Unruhe: wacht auf, irrt umher
  → Weglauftendenzen
  → Aggressivität beim Waschen
  → Verkennen von Personen
  → Ständige Wiederholungen, Fragen
  → Weigerung zu essen/trinken
```
