## Ключевые принципы

- **Subsidiaritätsprinzip** — принцип субсидиарности
- **Bedarfsdeckungsprinzip** — покрытие реальной потребности
- **Nachrangprinzip** — очерёдность (сначала исчерпать другие источники)
- **Individualisierungsprinzip** — индивидуальный подход
