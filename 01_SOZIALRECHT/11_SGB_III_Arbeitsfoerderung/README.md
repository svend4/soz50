# SGB III — Arbeitsförderung (ALG I, Berufsberatung, Weiterbildung)

[← Sozialrecht](../README.md)

> SGB III regelt die **Arbeitsförderung** durch die **Bundesagentur für Arbeit (BA)**.
> Kern: Arbeitslosengeld I (ALG I) — Versicherungsleistung, kein Almosen.
> Wer ausreichend gearbeitet hat, hat ANSPRUCH auf ALG I.

## ALG I — Überblick

```
Arbeitslosengeld I = Versicherungsleistung

Voraussetzungen (§ 137 SGB III):
  1. Arbeitslos (§ 138 SGB III)
  2. Anwartschaftszeit erfüllt (§ 142 SGB III):
     24 Monate beitragspflichtige Beschäftigung in letzten 30 Monaten
     (oder kürzere Variante: 12 Monate in 30 Monaten → 6 Monate ALG I)
  3. Arbeitslosmeldung beim Arbeitsamt (§ 141 SGB III)
  4. Verfügbarkeit (§ 138 Abs. 5 SGB III)
```

## Höhe und Dauer ALG I

### Höhe

```
§ 149 SGB III:
  → 60% des pauschalierten Nettoentgelts (Leistungsentgelt)
  → 67% wenn Kind im Haushalt (Kinderkennzeichen!)

Berechnung:
  Bruttoentgelt (Bemessungsentgelt, § 150 SGB III):
    → Durchschnitt der letzten 12 Monate vor Arbeitslosigkeit
    → Höchstgrenze: Beitragsbemessungsgrenze West 2026: 7.550 €/Monat

  Pauschaliertes Netto:
    → Abzug Pauschalen für Steuern + SV (nach Steuerklasse)
    → = Leistungsentgelt × 60% oder 67%
```

### Dauer (§ 147 SGB III)

| Beschäftigungsdauer | Alter | ALG-I-Dauer |
|--------------------|-------|-------------|
| 12 Monate | beliebig | 6 Monate |
| 16 Monate | beliebig | 8 Monate |
| 20 Monate | beliebig | 10 Monate |
| 24 Monate | beliebig | 12 Monate |
| 30 Monate | ab 50 J. | 15 Monate |
| 36 Monate | ab 55 J. | 18 Monate |
| 48 Monate | ab 58 J. | 24 Monate |

```
→ Maximaldauer: 24 Monate (ab 58 J., 48 Monate Beschäftigung)
→ Anwartschaft: Nur Beschäftigung als Arbeitnehmer zählt (nicht Selbstständigkeit!)
→ Ausnahmen: Erziehungszeit, Wehrpflicht, Krankheit können Rahmenfrist verlängern
```

## Sperrzeiten (§ 159 SGB III)

```
Sperrzeit = keine ALG-I-Zahlung für bestimmte Zeit

Häufige Sperrzeiten:
  1. Eigene Kündigung / Aufhebungsvertrag ohne wichtigen Grund:
     → 12 Wochen (reguläre Sperrzeit)
  2. Ablehnung einer zumutbaren Arbeit:
     → 3 Wochen (1. Mal), 6 Wochen (2. Mal), 12 Wochen (3. Mal)
  3. Nichterscheinen bei Agentur:
     → 1 Woche
  4. Nichtmeldung als arbeitssuchend (§ 38 SGB III):
     → 1 Woche

WICHTIG: Eigene Kündigung mit wichtigem Grund → KEINE Sperrzeit!
  Wichtige Gründe:
  → Umzug wegen Ehe/Lebenspartnerschaft
  → Nachgewiesene gesundheitliche Gründe
  → Mobbing/Belästigung (Nachweis nötig!)
  → Unzumutbare Arbeitsbedingungen
```

### Sperrzeit anfechten

```
Agentur setzt Sperrzeit an → Widerspruch!
Frist: 1 Monat

Argumentation:
  → Kündigung durch AG provoziert (Mobbingkündigung)
  → Aufhebungsvertrag war notwendig (drohende betriebsbedingte Kündigung)
  → Gesundheitliche Gründe: ärztliches Attest!
  → Familiäre Gründe: Pflege Angehöriger

Beweislast: Agentur muss Sperrzeit begründen → Widerspruch oft erfolgreich!
```

## Weiterbildungsförderung (§§ 81–87 SGB III)

```
Bildungsgutschein (BGS):
  → Agentur stellt Bildungsgutschein aus
  → Person wählt zugelassenen Bildungsträger (AZAV-Zertifizierung)
  → Kosten werden übernommen

Voraussetzungen (§ 81 SGB III):
  → Notwendigkeit für (Wieder-)eingliederung in Arbeitsmarkt
  → Arbeitslosen- oder Kurzarbeitsgeldbezug ODER Beschäftigt mit Weiterbildungsbedarf

Während Weiterbildung:
  → ALG I läuft weiter (§ 144 SGB III verlängert Bezugsdauer!)
  → Weiterbildungsbonus möglich (§ 87a SGB III)
  → Unterhaltsbeihilfe bei nicht-ALG-Bezug

Anspruch erzwingen?
  → § 81 SGB III gibt Anspruch auf FÖRDERUNG — nicht auf konkreten Lehrgang
  → Ablehnung ohne Begründung: Widerspruch!
  → Wenn Maßnahme für Eingliederung notwendig: Anspruch kann gerichtlich durchgesetzt werden
```

## Nahtlosigkeit — § 145 SGB III

```
§ 145 SGB III — Nahtlosigkeitsregelung:
  Wenn Vermittlung eingeschränkt, aber Erwerbsfähigkeit unklar:
  → Agentur zahlt ALG I weiter bis Klärung
  → Jobcenter / Rentenversicherung prüft Erwerbsfähigkeit
  → Kein "Vakuum" ohne Leistung

Wichtig für Praxis:
  → Person ist krank, Jobcenter lehnt ab (nicht erwerbsfähig?)
  → Agentur für Arbeit zahlt nach § 145 SGB III bis Klärung
  → So vermeiden: keinen Monat ohne Einkommen
```

## Berührungs- und Überschneidungspunkte mit SGB II

```
SGB III → SGB II:
  → ALG I läuft aus → ALG II wenn Bedürftigkeit
  → ALG I zu niedrig für Bedarf → Aufstockung durch SGB II möglich!
    (ALG I + ALG II = "Aufstocker")

Aufstocker-Berechnung:
  ALG I = 900 €
  Bedarf (Regelbedarf + KdU) = 1.100 €
  → ALG II = 1.100 − 900 = 200 € (+ Freibetrag nach § 11b SGB II)

Wichtig:
  → ALG I wird als Einkommen in SGB II angerechnet (nach Abzügen)
  → § 141 SGB III: Arbeitssuchendmeldung auch für ALG II nötig
  → Aufstocker: Bei Agentur UND Jobcenter Antrag stellen
```

## Kurzarbeitergeld (§§ 95–111 SGB III)

```
KUG = Leistung wenn Betrieb vorübergehend Stunden reduziert

Voraussetzungen:
  → Erheblicher Arbeitsausfall (mind. 10% der Belegschaft betroffen, > 10% Entgeltverlust)
  → Betriebliche und persönliche Voraussetzungen
  → Anzeige beim Arbeitsamt

Höhe:
  → 60% des pauschalierten Nettolohn-Ausfalls
  → 67% mit Kind

Bezugsdauer: max. 12 Monate (in Krisenzeiten verlängerbar)

Sozialversicherung:
  → AG zahlt halbe SV-Beiträge für ausgefallene Stunden
  → Rentenversicherungszeiten bleiben erhalten
```

---

## Ansprechpartner und Rechtsbehelfe

```
Zuständig: Agentur für Arbeit (nicht Jobcenter!)
  → Jobcenter = SGB II (ALG II)
  → Agentur = SGB III (ALG I, Weiterbildung, Beratung)

Rechtsbehelf bei Ablehnung:
  → Widerspruch: 1 Monat (§ 84 SGG)
  → Klage: Sozialgericht (nach Widerspruchsbescheid)
  → Zuständig: Sozialgericht am Wohnort

Häufige Streitpunkte:
  → Sperrzeit zu Unrecht verhängt
  → Anwartschaftszeit falsch berechnet
  → Höhe des Bemessungsentgelts
  → Ablehnung Bildungsgutschein
```
