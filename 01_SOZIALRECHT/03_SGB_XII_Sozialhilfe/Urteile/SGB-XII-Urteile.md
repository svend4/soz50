# Wichtige Urteile im SGB XII / Sozialhilferecht

[← SGB XII](../README.md) | [← Sozialrecht](../../README.md)

> Übersicht der praxisrelevantesten Urteile zu SGB XII, Sozialhilfe und angrenzenden Bereichen.
> Schwerpunkt: Grundsicherung, Regelsatz, Ausländer in SGB XII, Heimkosten.

---

## BVerfG — Regelsätze und Grundsicherung

```
BVerfG 1 BvL 1/09, 3/09, 4/09 — 09.02.2010 (Hartz IV I):
  Grundsatzentscheidung zum Grundrecht auf Existenzsicherung

  Leitsatz:
  → Das Grundrecht auf Gewährleistung eines menschenwürdigen Existenzminimums
    ergibt sich aus Art. 1 Abs. 1 GG iVm. Art. 20 Abs. 1 GG
  → Der Gesetzgeber muss dieses Recht konkretisieren
  → Regelsätze müssen transparent und nachvollziehbar ermittelt werden!

  Relevanz für SGB XII:
  → Gilt gleichermaßen für Sozialhilfe-Regelsätze
  → Grundsicherung muss Existenzminimum sichern
  → Härtefall-Regelungen müssen existieren (§ 27a Abs. 4 SGB XII)
```

```
BVerfG 1 BvL 7/16 — 05.11.2019 (Sanktionen SGB II):
  → Sanktionen über 30% verfassungswidrig
  → Für SGB XII: keine Sanktionen vergleichbar, aber:
  → Analogieschluss: Leistungskürzungen müssen verhältnismäßig sein
```

## BSG — Grundsicherung im Alter (§ 41 SGB XII)

```
BSG B 8 SO 21/14 R — 23.03.2016:
  Leistungsausschluss EU-Bürger in SGB XII

  Sachverhalt:
  → Rumänische Staatsangehörige ohne Arbeit beantragt § 41 SGB XII
  → Sozialamt lehnt wegen § 23 Abs. 3 SGB XII ab

  Entscheidung:
  → BSG sieht Unionsrechtswidrigkeit des Ausschlusses
  → EuGH-Vorlage folgte (C-568/16)

  Relevanz 2026:
  → § 23 SGB XII mehrfach geändert
  → Grundregel: EU-Bürger ohne verfestigten Aufenthalt kein Anspruch
  → Einzelfallprüfung + humanitäre Klausel beachten
```

```
BSG B 8 SO 14/19 R — 26.08.2020:
  Elternunterhalt und § 94 SGB XII (vor BTHG-Reform)

  Relevanz:
  → Entscheidungen VOR 01.01.2020 betreffen altes Recht
  → Seit 2020: § 94 Abs. 1a SGB XII: Kinder mit Einkommen < 100.000 € nicht herangezogen
  → Jetzt: neue Rechtsprechung zur Grenze 100.000 €
```

## BSG — Unterkunftskosten (§ 35 SGB XII)

```
BSG B 8 SO 14/17 R — 2019:
  Unterkunftskosten im Pflegeheim

  Sachverhalt:
  → Pflegebedürftiger im Heim; Sozialhilfe zahlt Heimkosten
  → Streit um "angemessenen" Unterkunftsanteil

  Entscheidung:
  → § 35 SGB XII: Angemessenheit auch bei Heimunterbringung
  → Nicht jeder Heimkostenanteil ist unbegrenzt zu übernehmen
  → Heimvertrag muss wirtschaftlich angemessen sein
```

```
BSG B 8 SO 7/16 R:
  Unterkunftskosten bei vorübergehendem Aufenthalt

  Relevanz:
  → Wenn Person im Krankenhaus: Unterkunftskosten für bisherige Wohnung?
  → BSG: ja, für angemessenen Zeitraum (bis Rückkehr absehbar)
  → Praxis: max. 3–6 Monate überbrückbar
```

## BSG — Eingliederungshilfe (bis BTHG 2020)

```
BSG B 8 SO 20/10 R — 02.02.2012:
  WfbM und Eingliederungshilfe

  Leitsatz:
  → WfbM-Leistungen sind Eingliederungshilfe
  → Kein vorrangiges Verhältnis zu anderen Leistungen (RV, GKV)
  → Träger sind verpflichtet, geeigneten Platz zu finanzieren

BSG B 8 SO 9/06 R — Schulbegleitung:
  → § 54 Abs. 1 Nr. 1 SGB XII a.F. (jetzt § 75 SGB IX)
  → Schulbegleitung ist Aufgabe der Eingliederungshilfe
  → WENN seelische Behinderung: § 35a SGB VIII (Jugendamt)
  → WENN körperlich/geistig: EGH-Träger
  → BSG: keine Zuständigkeitslücke zulässig!
```

## BSG — Mehrbedarf und Einmalleistungen

```
BSG B 8 SO 26/13 R:
  Mehrbedarf kostenaufwändige Ernährung (§ 30 Abs. 5 SGB XII)

  Sachverhalt:
  → Dialysepatientin beantragt Mehrbedarf für spezielle Kost

  Entscheidung:
  → Ärztliches Attest + Begründung nötig
  → Pauschal erhöhter Bedarf: ärztlich begründet
  → Höhe: nicht nach Tabelle, sondern im Einzelfall!
  → Praxis: Diätprotokoll + Verordnung vom Arzt als Nachweis
```

```
BSG B 8 SO 8/13 R:
  Erstausstattung Wohnung (§ 31 SGB XII)

  Leitsatz:
  → Einmalleistungen sind kein Ermessen!
  → Bei Vorliegen der Voraussetzungen: Anspruch!
  → Auch wenn Person in der Vergangenheit Wohnmöbel hatte und verloren hat
```

## BVerwG — Sozialhilfe und Ausländer

```
BVerwG 5 C 30.15 — 26.01.2017:
  Sozialhilfe für EU-Bürger ohne Aufenthaltsrecht

  Leitsatz:
  → § 23 Abs. 3 SGB XII (a.F.): Ausschluss bei Einreise zum Sozialhilfebezug
  → Muss humanitär einschränkend ausgelegt werden
  → Vollständiger Ausschluss bei langer Aufenthaltsdauer: unverhältnismäßig

  Relevanz:
  → Grundlage für spätere Gesetzesänderungen 2019 (§ 23 SGB XII Neufassung)
```

## BVerfG — Asylbewerber und Existenzminimum

```
BVerfG 1 BvL 10/10 — 18.07.2012:
  AsylbLG-Grundleistungen verfassungswidrig

  Sachverhalt:
  → AsylbLG-Leistungen seit 1993 nicht erhöht
  → Realwert der Leistungen war drastisch gesunken

  Entscheidung:
  → Verstößt gegen das Grundrecht auf menschenwürdiges Existenzminimum
  → Keine gesonderten "Mindest-Existenzminima" für Ausländer!
  → AsylbLG musste sofort reformiert werden

  Relevanz:
  → Grundlegendes Urteil für Beratung AsylbLG
  → Auch Asylsuchende haben Recht auf menschenwürdiges Existenzminimum
  → § 6 AsylbLG: Ermessensleistungen müssen Existenzminimum sichern
```

## Praxistipps zur Urteilsrecherche

```
Datenbanken (kostenlos):
  → sozialgerichtsbarkeit.de: BSG, LSG, SG — alle Instanzen
  → bsg.bund.de: BSG-Pressemitteilungen (aktuell + wichtig)
  → bundesverfassungsgericht.de: BVerfG-Volltext

Suchstrategie:
  → Nach Aktenzeichen: eindeutig
  → Volltextsuche: § 27a SGB XII + "Regelsatz" + "Bedarf"
  → Zeitfilter: nur letzte 5 Jahre für aktuelle Rechtslage
  → Immer: gibt es neuere Entscheidungen die das Urteil relativieren?

ACHTUNG:
  → BSG-Urteile vor BTHG-Reform (vor 01.01.2020): teilweise überholt!
  → § 53ff. SGB XII (alt) → jetzt SGB IX Teil 2
  → Immer auf geltende Rechtsgrundlage prüfen
```
