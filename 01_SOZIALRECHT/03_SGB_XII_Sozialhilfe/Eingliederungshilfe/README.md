# Eingliederungshilfe — SGB IX (ab 2020)

[← SGB XII](../README.md) | [← Sozialrecht](../../README.md)

> Seit **01.01.2020** ist die Eingliederungshilfe aus SGB XII herausgelöst
> und im **SGB IX Teil 2 (§§ 99–150)** geregelt (BTHG-Reform).
> Ведомство: **Eingliederungshilfeträger** (meist Landschaftsverband, z.B. LVR, LWL in NRW).

---

## Wer hat Anspruch? (§ 99 SGB IX)

```
Leistungsberechtigt ist, wer:
  1. Eine Behinderung im Sinne von § 2 Abs. 1 SGB IX hat
     (körperlich, geistig, seelisch, Sinnesbeeinträchtigung)

  2. Wesentliche Beeinträchtigung der Teilhabe (§ 99 Abs. 1)
     → Maßgeblich: Aktivitäten und Teilhabe (ICF-Klassifikation)

  3. Voraussichtlich länger als 6 Monate betroffen
```

## Wichtige Leistungen im Detail

### Persönliches Budget (§ 29 SGB IX)

```
Statt Sachleistungen → Geld an betroffene Person
Person kauft selbst Unterstützung ein (mehr Selbstbestimmung)

Vorteil: Flexibel, selbst organisiert
Nachteil: Organisation liegt beim Betroffenen
Antrag beim zuständigen Träger
```

### Assistenzleistungen (§ 78 SGB IX)

- **Alltagsassistenz:** Unterstützung im täglichen Leben (essen, anziehen, Mobilität)
- **Assistenz bei Freizeitaktivitäten**
- **Familienassistenz** — Unterstützung bei der Kindererziehung

### Wohnen mit Unterstützung

```
Früher: stationäre Einrichtung (Heim — Gesamtpaket)
Heute (BTHG): Trennung von Wohnen und Assistenz
  → Wohnen = eigene Wohnung (Mietrecht gilt!)
  → Assistenz = separate Leistung (EGH-Träger)
  → Ziel: Inklusion, Selbstbestimmung
```

### Werkstatt für Menschen mit Behinderung (WfbM)

```
§§ 56–63 SGB IX
→ Für Menschen die (noch) nicht auf dem Arbeitsmarkt tätig sein können
→ Arbeitstraining + Beschäftigung
→ Mindestarbeitsentgelt: ca. 119 € + Grundbetrag
→ Alternative: Budget für Arbeit (§ 61 SGB IX) — auf normalem Arbeitsmarkt
```

## Verfahren — Gesamtplan (§ 121 SGB IX)

```
Antrag beim zuständigen EGH-Träger (Landschaftsverband)
        │
Bedarfsermittlung (ICF-basiert, § 118 SGB IX)
  → Gespräch, Gutachten, Selbstauskunft
        │
Gesamtplankonferenz (§ 119 SGB IX)
  → Betroffener + Träger + ggf. weitere Träger
  → Gemeinsam: Ziele + Leistungen festlegen
        │
Gesamtplan (schriftlich) → Leistungsbescheid
        │
Umsetzung + jährliche Überprüfung
```

## Abgrenzung: § 35a SGB VIII vs. SGB IX

| | § 35a SGB VIII | SGB IX |
|--|---------------|--------|
| Alter | Kinder/Jugendliche | alle Alter |
| Art | seelische Behinderung | alle Behinderungsarten |
| Träger | Jugendamt | Landschaftsverband / EGH-Träger |
| Volljährig → | Übergang zu SGB IX! (§ 41 SGB VIII nur bis 27) | |
