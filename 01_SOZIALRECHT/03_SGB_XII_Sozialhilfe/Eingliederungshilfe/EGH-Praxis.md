# Eingliederungshilfe — Praxis und Antragstellung

[← Eingliederungshilfe](./README.md) | [← SGB XII](../README.md)

> Seit 01.01.2020 ist die EGH aus dem SGB XII herausgelöst (BTHG-Reform).
> Das Ziel ist Inklusion und Selbstbestimmung — nicht mehr Versorgung.
> Wichtigste Änderung: Wohnen und Assistenz sind getrennte Leistungen.

---

## Wer ist zuständig? (§ 94 SGB IX)

```
Eingliederungshilfeträger:

Je nach Bundesland unterschiedlich:
  → Nordrhein-Westfalen: LVR (Rheinland) oder LWL (Westfalen)
  → Bayern: Bezirke (Bezirk Oberbayern etc.)
  → Baden-Württemberg: Landeswohlfahrtsverbände
  → Berlin, Hamburg: Senatsverwaltung
  → Sachsen: Kommunen (Kreise + kreisfreie Städte)

Nicht das Sozialamt! Nicht das Jobcenter!
Zuständigkeitsprüfung → immer zuerst klären
```

## Leistungsvoraussetzungen (§ 99 SGB IX)

```
Drei Voraussetzungen müssen ALLE erfüllt sein:

1. Behinderung (§ 2 Abs. 1 SGB IX):
   → Körperliche, geistige, seelische oder Sinnesbeeinträchtigung
   → Voraussichtlich länger als 6 Monate
   → Abweichung von alterstypischer Entwicklung

2. Wesentliche Beeinträchtigung der Teilhabe:
   → Wesentlich = erhebliche Einschränkung in Aktivitäten + Teilhabe
   → Maßstab: ICF (Internationale Klassifikation der Funktionsfähigkeit)
   → Entscheidend: nicht nur Diagnose, sondern Funktionsbeeinträchtigung!

3. Geeignete Maßnahmen sind möglich:
   → EGH kann helfen, die Teilhabe zu verbessern
```

---

## ICF-basierte Bedarfsermittlung

```
ICF = Internationale Klassifikation der Funktionsfähigkeit
  (Behinderung und Gesundheit — WHO)

Zwei Hauptkomponenten:
  1. Körperfunktionen und -strukturen (was ist beeinträchtigt)
  2. Aktivitäten und Teilhabe (was kann Person nicht tun)
  + Kontextfaktoren: Umwelt (Wohnung, Arbeit) + Person (Motivation)

Bedarfsermittlungsinstrumente (BEI) je nach Bundesland:
  → BEI_BW (Baden-Württemberg)
  → BEI_NRW (bei LVR/LWL)
  → Metzler-Verfahren
  → ITP (Individueller Teilhabeplan)

Wichtig für die Beratung:
  → Instrument vor Gesprächstermin kennen!
  → Klient auf Gesamtplankonferenz vorbereiten
  → Eigene Ziele + Wünsche formulieren lassen
```

## Antragstellung — Schritt für Schritt

```
Schritt 1: Antrag stellen
  → An zuständigen EGH-Träger
  → Schriftlich + formlos möglich (Brief, E-Mail)
  → Sofortige Wirkung: ab Antragsdatum!

Schritt 2: Zuständigkeitsprüfung
  → EGH-Träger prüft eigene Zuständigkeit
  → Ggf. Weiterleitung an anderen Träger (§ 14 SGB IX)
    WICHTIG: Weiterleitung muss innerhalb 2 Wochen erfolgen!
    Wenn nicht → erstangegangener Träger bleibt zuständig!

Schritt 3: Bedarfsermittlung (§ 118 SGB IX)
  → Termin beim EGH-Träger
  → Gespräch mit ICF-Instrument
  → Ggf. ärztliche/psychologische Gutachten

Schritt 4: Gesamtplankonferenz (§ 119 SGB IX)
  → Gemeinsam: Klient + EGH-Träger + ggf. weitere Träger
  → Ziele vereinbaren, Leistungsumfang festlegen
  → Klient hat Recht, Vertrauensperson mitzubringen!

Schritt 5: Gesamtplan + Leistungsbescheid
  → Schriftlicher Gesamtplan
  → Bescheid über bewilligte Leistungen
  → Widerspruch möglich (4 Wochen!)

Schritt 6: Umsetzung
  → Beauftragung Leistungserbringer (Anbieter)
  → Jährliche Überprüfung (§ 121 Abs. 4 SGB IX)
```

## Häufige Leistungsarten in der Praxis

```
Assistenzleistungen (§ 78 SGB IX):
  → Alltagsassistenz: essen, anziehen, Körperpflege
  → Kommunikationsassistenz: Dolmetscher (Gebärdensprache)
  → Schulassistenz / Studienassistenz
  → Freizeitassistenz

Wohnassistenz / Unterstütztes Wohnen:
  → Person wohnt in eigener Wohnung (Mieter!)
  → EGH zahlt Assistenz (stündlich)
  → Keine stationäre Einrichtung nötig
  → Vorteil: mehr Selbstbestimmung

Beförderungsleistungen:
  → Wenn Person nicht selbst fahren kann
  → EGH kann Fahrdienst oder Fahrkostenerstattung leisten

Werkstatt (WfbM) oder Budget für Arbeit:
  → WfbM (§§ 56–63 SGB IX): für Menschen mit erheblicher Behinderung
  → Budget für Arbeit (§ 61 SGB IX): Alternative auf normalem Arbeitsmarkt
    → Lohnkostenzuschuss (bis 75% des Arbeitsentgelts)
    → Unterstützung durch Jobcoach

Hilfsmittel / Wohnraumanpassung:
  → EGH zahlt Hilfsmittel die GKV/DRV nicht übernehmen
  → Wohnraumanpassung: barrierefreier Umbau
```

## Typische Probleme und Widerspruchsgründe

```
FEHLER 1: Ablehnung wegen "keine wesentliche Beeinträchtigung"
  → Gegenargument: Gutachten zum Funktionsstatus besorgen
  → ICF-Perspektive: Was kann Person NICHT tun?
  → BSG-Rechtsprechung: wesentlich = erheblich (nicht: vollständig)

FEHLER 2: Falscher Träger behauptet Unzuständigkeit
  → § 14 SGB IX: erstangegangener Träger bleibt zuständig!
  → Kein "Schwarzer Peter"-Spiel zwischen Trägern dulden
  → Bei Streit: Sozialverwaltung → Sozialgericht (einstw. Verfügung)

FEHLER 3: Zu geringe Stundenzahl bewilligt
  → Tagesprotokolle führen über tatsächlichen Unterstützungsbedarf
  → Arztzeugnis / Pflegegutachten als Nachweis
  → Widerspruch: detaillierte Begründung + eigene Zeitdokumentation

FEHLER 4: Verweis auf ambulant statt stationär (oder umgekehrt)
  → Ambulant vor stationär gilt — ABER Eignung muss gegeben sein!
  → BSG: Träger muss nachweisen dass ambulant ausreicht

FEHLER 5: Ablehnung Persönliches Budget
  → § 29 SGB IX: Recht auf Persönliches Budget besteht!
  → Träger darf nicht ohne sachlichen Grund ablehnen
  → Widerspruch + Begründung: Selbstbestimmung nach § 1 SGB IX
```

## Übergang von § 35a SGB VIII zu SGB IX

```
Beim Volljährigwerden:
  → § 35a SGB VIII endet mit 18 / ggf. 21 (§ 41 SGB VIII)
  → Dann: SGB IX (EGH-Träger) zuständig

Problem: Nahtlosigkeit!
  → Antrag beim EGH-Träger VOR dem 18. Geburtstag stellen!
  → Übergabe zwischen JA und EGH-Träger koordinieren
  → Gesamtplan muss nahtlos fortgeführt werden

Praktisch:
  → Mind. 6 Monate vor 18. Geburtstag mit EGH-Träger Kontakt aufnehmen
  → Hilfeplan SGB VIII auf Übergang abstimmen (§ 36 SGB VIII)
  → "Große Lösung" ab 2028: dann JA bis 18 auch für körperlich/geistig behinderte Kinder
```

## Zusammenspiel mit anderen Leistungen

```
EGH + GKV (Krankenversicherung):
  → GKV zahlt medizinische Reha
  → EGH zahlt soziale Teilhabe
  → Grenze fließend: Abgrenzungsabkommen beachten

EGH + Pflegekasse (SGB XI):
  → Pflegekasse: häusliche Pflege (Körperpflege, Hauswirtschaft)
  → EGH: darüber hinausgehende Assistenz (Freizeitgestaltung, Arbeit)
  → EGH geht Pflegekasse vor in bestimmten Bereichen!

EGH + SGB II (Bürgergeld):
  → Person mit Behinderung kann EGH + SGB II gleichzeitig beziehen
  → Einkommensanrechnung bei EGH: Freibeträge nach § 135 SGB IX!
    → Höherer Freibetrag als bei SGB II!

EGH + Wohngeld / KdU:
  → EGH zahlt keine Unterkunftskosten (Trennung von Wohnen und Assistenz!)
  → Unterkunft: eigene Wohnung → Miete aus eigenen Mitteln (ggf. SGB II/XII)
```
