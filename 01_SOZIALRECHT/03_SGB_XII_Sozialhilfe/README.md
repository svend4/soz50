# SGB XII — Sozialhilfe

[← Sozialrecht](../README.md) | [← Главная](../../README.md)

> **SGB XII** — Zwölftes Buch Sozialgesetzbuch.
> Ведомство: **Sozialamt** (не Jobcenter — важное отличие от SGB II).
> Применяется для людей, которые **не erwerbsfähig** (нетрудоспособны).

## Отличие SGB XII от SGB II

| | SGB II (Bürgergeld) | SGB XII (Sozialhilfe) |
|--|--------------------|-----------------------|
| Ведомство | Jobcenter | Sozialamt |
| Кто получает | Erwerbsfähige (15–65 лет) | Nicht erwerbsfähige, Rentner |
| Основание | § 7 SGB II | § 19, 41 SGB XII |
| Arbeitslosengeld II | ja | nein |

## Subsidiarität — очерёдность

```
SGB XII применяется только если:
1. Нет права на SGB II (не erwerbsfähig)
2. Нет других источников (Rente, Unterhalt, Vermögen)
3. Нет обязанных родственников (Unterhaltspflicht — только Eltern↔Kinder ab 100.000 € Jahreseinkommen)
```
