## Wohngeld vs. KdU — что выбрать?

```
KdU (§ 22 SGB II / § 35 SGB XII):
  → только если уже получаешь Bürgergeld / Sozialhilfe
  → входит в общий расчёт выплат

Wohngeld (WoGG):
  → для тех, кто НЕ получает SGB II/XII
  → можно получать дополнительно к низкому доходу
  → подаётся в Wohngeldstelle (Bezirksamt)

WICHTIG: SGB II und Wohngeld schließen sich gegenseitig aus!
```

## Angemessene Kosten der Unterkunft (§ 22 SGB II)

Ключевая концепция: Jobcenter оплачивает только **angemessene** (приемлемые) расходы.

Как определяется «приемлемость»:
- **Schlüssiges Konzept** — ведомство должно иметь обоснованную систему расчёта
- Без schlüssiges Konzept → применяется **Wohngeldtabelle + 10%** (BSG-Rechtsprechung)
- Нормы индивидуальны для каждого города / Landkreis

```
Если Jobcenter считает жильё "zu teuer":
1. Aufforderung zur Kostensenkung (Aufforderungsschreiben)
2. Frist: 6 Monate zur Kostensenkung
3. Danach: nur angemessene Kosten übernommen
→ Widerspruch ist oft erfolgreich bei fehlendem schlüssigen Konzept!
```
