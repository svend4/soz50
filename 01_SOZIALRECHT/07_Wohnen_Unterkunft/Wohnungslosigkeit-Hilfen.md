# Wohnungslosigkeit — Hilfen, Rechte, Prävention

[← Wohnen und Unterkunft](./README.md)

> In Deutschland sind 600.000–800.000 Menschen wohnungslos.
> Entscheidend: **Wohnungslosigkeit ist kein Schicksal — es gibt Rechte!**
> Früh handeln verhindert Obdachlosigkeit. Das Sozialsystem hat mehrere Sicherheitsnetze.

---

## Grundbegriffe

```
Definitionen:

Wohnungslos (im sozialrechtlichen Sinn):
  → Keine eigene Wohnung (Mietvertrag) mehr
  → Aber: noch nicht obdachlos
  → Übergangsunterbringung, Notunterkunft, bei Freunden/Bekannten

Obdachlos (ordnungsrechtlich):
  → Kein Dach über dem Kopf
  → Sofortiger Handlungsbedarf der Gemeinde!

Verdeckte Wohnungslosigkeit:
  → Menschen bei Familie/Freunden (ohne eigene Wohnung)
  → In dieser Kategorie besonders viele Frauen!

Von Wohnungslosigkeit bedroht:
  → Mietschulden vorhanden
  → Kündigung wegen Mietschulden
  → Räumungsklage läuft
```

---

## § 67 SGB XII — Hilfen zur Überwindung besonderer sozialer Schwierigkeiten

```
§§ 67–69 SGB XII:
  → Spezifische Leistung für Menschen in besonderen sozialen Schwierigkeiten
  → Gilt für Wohnungslose, aber AUCH für andere Lebenslagen
    (Haftentlassene, Menschen mit Suchtproblemen, etc.)

Leistungsinhalt (§ 68 SGB XII):
  1. Beratung und persönliche Betreuung
  2. Hilfe bei der Wohnungssuche
  3. Hilfe bei Behördenkontakten
  4. Hilfe zur Erhaltung und Beschaffung von Wohnraum
  5. Soziale Eingliederung

Zuständigkeit:
  → Sozialamt (Sozialhilfeträger)
  → Oft delegiert an freie Träger (Caritas, AWO, Diakonie, Bahnhofsmission)
  → Fachberatungsstellen für Wohnungslose (in jeder größeren Stadt)

Anspruch:
  → Rechtsanspruch! (kein reines Ermessen)
  → Sobald Person obdachlos oder von Obdachlosigkeit bedroht ist
```

## Prävention — Wohnung erhalten

### Schritt 1: Bei drohender Kündigung wegen Mietschulden

```
§ 22 Abs. 8 SGB II / § 36 Abs. 1 SGB XII:
  → Jobcenter / Sozialamt MUSS Mietschulden übernehmen wenn:
    1. Wohnungserhalt sonst nicht möglich
    2. Wohnung ist angemessen (§ 22 Abs. 1 SGB II)
    3. Oder: keine angemessene Alternativwohnung verfügbar

  Form: Als Darlehen (§ 22 Abs. 8 S. 2 SGB II)
  → Rückzahlung durch monatliche Aufrechnung bis zu 10% des Regelbedarfs
  → In besonderen Fällen: als Zuschuss (Ermessen)

Ablauf:
  1. Sofort beim JC/Sozialamt melden bei Kündigung!
  2. Kündigung + Schulden vorlegen
  3. Schriftlicher Antrag auf Übernahme der Mietschulden
  4. JC hat Pflicht zu prüfen — Ablehnung muss begründet werden

WICHTIG: JC muss VOR Wohnungsverlust aktiv werden!
  → Nicht warten bis Räumungsurteil → dann zu spät
  → Schon bei erster Mahnung / Abmahnung handeln
```

### Schritt 2: Bei Räumungsklage

```
Räumungsklage läuft:

1. Anwalt / Mieterverein einschalten!
   → Widerspruchsfrist im Räumungsverfahren: kurz!
   → Prozesskostenhilfe beantragen

2. Sozialamt informieren (§ 22 Abs. 9 SGB II):
   → Gericht MUSS Sozialamt über Räumungsklage informieren
   → Sozialamt hat dann Möglichkeit, Schulden zu übernehmen

3. Härteklagsel / Vollstreckungsschutz:
   → Wenn Räumungsurteil: Vollstreckungsschutz beantragen
   → § 765a ZPO: Aufschub der Zwangsräumung bei besonderer Härte
   → Besondere Härte: schwere Erkrankung, Kinder, drohende Obdachlosigkeit

4. Wohnungssuche sofort beginnen!
   → Parallel zur Klage: neue Wohnung suchen
   → JC / Sozialamt muss bei Suche unterstützen (§ 67 SGB XII)
```

## Akute Wohnungslosigkeit — Sofortmaßnahmen

### Öffentlich-rechtliche Unterbringung (Ordnungsrecht)

```
Wer auf der Straße steht: Ordnungsrechtliche Unterbringung!

Rechtsgrundlage: Landespolizeigesetze, Gemeindeordnungen
  → Gemeinde ist VERPFLICHTET, Notunterkunft zu stellen
  → Keine Bedürftigkeitsprüfung! (kein SGB II-Antrag nötig)
  → Sofort, kostenlos, auch nachts

Wo melden:
  → Ordnungsamt der Gemeinde (auch nachts: Notruf-Nummer!)
  → Polizei verweist weiter
  → In Großstädten: Kältehilfe-Hotlines, Notunterkünfte

Unterkunft:
  → Notunterkunft (Turnhalle, Hotel, Containerunterkünfte)
  → NICHT optimal — aber sofortiger Schutz vor Kälte/Witterung
  → Kostenpflichtig für die Gemeinde (nicht für Betroffenen)

Kosten:
  → Ordnungsrechtliche Unterbringung: Gemeinde zahlt zunächst
  → Erstattung: Gemeinde kann von Person zurückfordern wenn zahlungsfähig
  → SGB II/XII-Bezieher: kein Eigenanteil
```

### SGB II / KdU in Notunterkunft

```
§ 22 SGB II gilt auch für Notunterkünfte:
  → Kosten der Notunterkunft = KdU wenn nicht anderweitig gedeckt
  → JC übernimmt angemessene Kosten
  → Angemessenheit: oft höher als reguläre Wohnung (vertretbar)

Antrag SGB II bei Wohnungslosigkeit:
  → Antrag sofort stellen!
  → Postadresse: Anlaufstellen, Beratungsstellen, Behörde erlaubt
  → Keine feste Adresse = kein Hinderungsgrund für Antrag!
  → "Gewöhnlicher Aufenthalt" reicht (§ 30 SGB I)
```

## Soziale Wohnhilfe und Fachberatung

### Einrichtungen der Wohnungslosenhilfe

```
Typen von Einrichtungen:

1. Beratungsstellen (ambulant):
   → Erste Anlaufstelle ohne Anmeldung
   → Hilfe bei Anträgen, Behördenkontakten, Schulden
   → Kostenlos, oft anonym möglich

2. Tagesstätten / Wärmstuben:
   → Tagsüber aufwärmen, Essen, Dusche
   → Soziale Kontakte, Post-Adresse möglich

3. Notunterkünfte (stationär, kurzfristig):
   → Übernachtungsstätten
   → Meist: Männer und Frauen getrennt!

4. Übergangswohnheime (stationär, längerfristig):
   → Mehrere Wochen/Monate möglich
   → Begleitetes Wohnen mit sozialpädagogischer Unterstützung
   → Ziel: Eigenständige Wohnung danach

5. Soziales Wohnen (betreutes Einzelwohnen):
   → Eigener Mietvertrag + ambulante Betreuung
   → § 67 SGB XII financiert die Betreuung
   → Ideal für Übergangsphase

Träger:
  → Caritas, Diakonie, AWO, Rotes Kreuz
  → Lokale Obdachlosenverbände, Bahnhofsmission
  → Stadtmissionen (Berlin, Hamburg, München etc.)
```

### Besondere Gruppen in der Wohnungslosigkeit

```
FRAUEN:
  → Verdeckte Wohnungslosigkeit besonders häufig
  → Frauenwohnheime / Frauenspezifische Beratung wichtig!
  → Oft von Wohnungslosigkeit betroffen durch Trennung / Gewalt

SUCHT:
  → Aktiver Drogenkonsum = kein Hinderungsgrund für Unterkunft!
  → "Akzeptierende" Einrichtungen ("Wet shelter" = Alkohol erlaubt)
  → Unterstützung nur wenn Abstinenz = diskriminierend in manchen Kontexten

PSYCHISCHE ERKRANKUNG:
  → Psychiatrische Versorgung + Unterkunft kombinieren
  → SPZ (Sozialpsychiatrische Zentren) als Brücke
  → Kriseninterventionsteams (in Großstädten)

EU-BÜRGER:
  → Ordnungsrechtliche Unterbringung: auch für EU-Bürger!
  → SGB II: nur wenn Freizügigkeitsrecht besteht (§ 7 SGB II)
  → § 23 Abs. 3 SGB XII: Ermessensleistung für EU-Bürger ohne SGB-II-Anspruch
  → Repatriierungsbeihilfe: Heimreise kann bezahlt werden

HAFTENTLASSENE:
  → § 67 SGB XII sofort nach Entlassung!
  → Übergangsmanagement: Sozialarbeiter im Gefängnis → nach Entlassung
  → Sofort: SGB II / SGB XII beantragen (ab Entlassungstag!)
```

## Mietrecht und Kündigung — Rechte der Mieter

```
Außerordentliche Kündigung wegen Mietschulden:
  → § 543 Abs. 2 Nr. 3 BGB: sofortige Kündigung wenn ≥ 2 Monatsmieten rückständig
  → ABER: Schonfristzahlung möglich (§ 569 Abs. 3 BGB)!
    → Nachzahlung der Schulden innerhalb von 2 Monaten nach Klage
    → → Kündigung wird unwirksam!
    → Nur 1× in 2 Jahren möglich (§ 569 Abs. 3 S. 3 BGB)

Ordentliche Kündigung:
  → § 573 BGB: berechtigtes Interesse nötig
  → Kündigung wegen Mietschulden als ordentliche Kündigung auch möglich
  → Kündigungsfrist: 3–9 Monate (je nach Mietdauer)

Widerspruch gegen Kündigung:
  → § 574 BGB: Mieter kann Widerspruch einlegen bei "Härte"
  → Härte: Erkrankung, hohes Alter, keine Alternativwohnung in der Gemeinde
  → → Gericht kann Räumung auf bestimmte Zeit aufschieben!
```

## Prävention: Mietschulden vermeiden

```
Checkliste für Klienten:
  □ Bei finanziellen Schwierigkeiten: SOFORT Jobcenter informieren!
  □ Mietkosten immer priorisieren (Strom, Gas kann nachgezahlt werden)
  □ Laufende KdU beantragen wenn bisher kein SGB II
  □ Bei Kündigung: Mieterverein / Rechtsberatung sofort aufsuchen
  □ Schonfristzahlung kennen! (2 Monate nach Kündigung)
  □ Bei Räumungsklage: § 765a ZPO (Vollstreckungsschutz) beantragen

JC-Pflichten kennen:
  → JC muss über drohende Wohnungslosigkeit informiert werden
  → JC MUSS Handlungsoptionen prüfen (Darlehen, Mietschulden)
  → Ablehnung durch JC → sofort Widerspruch + Eilantrag Sozialgericht!
```
