# Angemessenheit der KdU — Уместность расходов на жильё

[← Leistungen](./README.md) | [← KdU Grundlagen](./KdU-Grundlagen.md)

> **Ключевая проблема:** Jobcenter ежегодно ограничивает тысячи выплат, ссылаясь на «неуместность» жилья. Но: многие эти решения незаконны — либо потому что у Jobcenter нет корректного «schlüssiges Konzept», либо потому что анализ был сделан некорректно. Знание этой темы критически важно для Widerspruch.

---

## Что значит «angemessen»?

По §22 Abs. 1 SGB II — «уместный» (angemessen) размер KdU означает:

> Такая квартира, которую man среднего достатка при ограниченных средствах выбрал бы с учётом Mietmarkt данного населённого пункта.

Jobcenter сам определяет этот предел — но по строгим правилам BSG (так называемый **schlüssiges Konzept**).

---

## Schlüssiges Konzept — что это и зачем

### Обязанность Jobcenter (BSG-Rechtsprechung)

BSG с 2009 года (B 14 AS 55/08 R) требует, чтобы каждый Jobcenter имел:

**Schlüssiges Konzept** = последовательная, методически обоснованная концепция определения местного рынка аренды (lokaler Mietmarkt) для конкретного «Vergleichsraum» (территории сравнения).

### Обязательные элементы (BSG B 14 AS 55/08 R и след.)

| Элемент | Требование |
|---------|-----------|
| **Aktualität** | Данные не старше ~4-5 лет |
| **Repräsentativität** | Охватывает весь релевантный рынок аренды (не только Sozialwohnungen!) |
| **Vergleichsraum** | Чётко определённая территория (не слишком мала, не слишком велика) |
| **Wohnungsgrößen** | Учитывает реальные размеры для разных составов семей |
| **Einfaches Segment** | Нижний сегмент рынка (не роскошь, но пригодное жильё) |
| **Nachvollziehbarkeit** | Воспроизводимая методология (не «потолочная цифра») |

### Если у Jobcenter нет schlüssiges Konzept — что это значит?

**→ Jobcenter обязан оплачивать реальные расходы** (tatsächliche Kosten), пока не разработает корректную концепцию.

BSG B 4 AS 87/13 R: «Fehlt ein schlüssiges Konzept, sind die tatsächlichen KdU in voller Höhe zu übernehmen.»

## Как проверить: законно ли ограничение моего Jobcenter?

### Шаг 1: Запроси schlüssiges Konzept

**Письмо:** Antrag auf Akteneinsicht (§25 SGB X) + Herausgabe des schlüssigen Konzepts

```
Ich beantrage gemäß § 25 SGB X Einsicht in meine Akten sowie
die Übersendung des schlüssigen Konzepts zur Bestimmung der
angemessenen Unterkunftskosten im Landkreis/der Stadt [X].
```

**Jobcenter обязан предоставить:**
- Название исследования / концепции
- Дату актуальности данных
- Методологию определения Vergleichsraum
- Источники данных (Mietspiegel, eigene Erhebung, Gutachten)

### Шаг 2: Проверь Vergleichsraum

Vergleichsraum должен охватывать территорию, где человек реально может найти жильё с учётом соцсвязей (работа, школа, врач).

❌ **Незаконно:** установить слишком маленький Vergleichsraum (только центр города), чтобы занизить лимит.
❌ **Незаконно:** объединить несравнимые территории (центр Мюнхена + деревня в 50 км).

### Шаг 3: Проверь актуальность данных

- Если данные старше **5 лет** → концепция устарела → спорь (BSG B 14 AS 174/11 R)
- Если данные из **Sozialwohnungen only** → не репрезентативно → спорь

### Шаг 4: Проверь учёт твоей семьи / Wohnungsgröße

| Размер семьи | Обычный норматив площади |
|-------------|------------------------|
| 1 человек | bis 50 m² |
| 2 человека | bis 60 m² |
| 3 человека | bis 75 m² |
| 4 человека | bis 85–90 m² |
| каждый доп. | +10–15 m² |

⚠️ **Норматив площади — НЕ закон**, это ориентир BSG. Индивидуальные потребности (инвалидность, медицинские показания, уход) могут увеличивать норму.

## Особые случаи (Ausnahmen)

| Ситуация | Последствие |
|---------|------------|
| Behinderung / barrierefreie Wohnung | Может обосновать более дорогую квартиру |
| Pflegebedürftigkeit (домашний уход) | Дополнительная комната для ухаживающего |
| Minderjährige Kinder | Отдельная комната на ребёнка |
| Schutzbefohlene (дети по решению суда) | Учитывается даже при непостоянном проживании |
| Eigenheim | Другие критерии — отдельный анализ |
| Erst-6-Monate-Regel | При первом обращении за Bürgergeld: 6 мес. не трогают KdU |

## Rechte bei Umzug (права при переезде)

### Zusicherung vor dem Umzug (§ 22 Abs. 4)

Перед переездом нужно получить **Zusicherung** (письменное согласие) что новая квартира будет оплачена.

**Jobcenter обязан** дать Zusicherung, если:
1. Переезд «erforderlich» (необходим) — например, угроза выселения, медицинские причины, смена работы
2. Новая квартира «angemessen»

**Если откажет:** → Widerspruch + einstweiliger Rechtsschutz (§86b SGG).

### При переезде в другой Bezirk

- Zusicherung даёт новый (принимающий) Jobcenter
- Старый Jobcenter не вправе блокировать

## Прямые аргументы для Widerspruch

Если Jobcenter урезает KdU — используй один или несколько из этих аргументов:

```
1. KEIN SCHLÜSSIGES KONZEPT
   Johcenter hat kein nachvollziehbares schlüssiges Konzept
   vorgelegt. BSG B 4 AS 87/13 R: Ohne schlüssiges Konzept
   sind tatsächliche Kosten zu übernehmen.

2. VERALTETE DATEN
   Das Konzept basiert auf Daten aus [Jahr], also älter als
   5 Jahre. Nach BSG B 14 AS 174/11 R nicht mehr aktuell.

3. FALSCHER VERGLEICHSRAUM
   Der zugrunde gelegte Vergleichsraum entspricht nicht dem
   tatsächlichen Wohnungsmarkt. Eine eingeschränkte Fläche
   senkt künstlich den Richtwert.

4. BESONDERE UMSTÄNDE
   Die besonderen Umstände meiner Situation wurden nicht
   berücksichtigt: [Behinderung / Pflegebedarf / Kinder / ...]

5. KEINE WOHNUNG VERFÜGBAR
   Es ist mir trotz intensiver Suche nicht gelungen, eine
   angemessene Wohnung zu den genannten Konditionen zu finden.
   Nachweis: [Absagen, Suchanzeigen, ...]
```

## Чеклист при получении Kürzungs-Bescheid

- [ ] Прочитан §22 Abs. 1 S. 3 (есть ли ещё 6-месячный срок?)
- [ ] Запрошен schlüssiges Konzept (Akteneinsicht §25 SGB X)
- [ ] Проверена актуальность данных концепции
- [ ] Проверен Vergleichsraum
- [ ] Учтены особые обстоятельства семьи
- [ ] Проверено: есть ли реально доступные квартиры по указанному пределу?
- [ ] Widerspruch подан в течение 1 месяца
- [ ] При острой нужде: einstweiliger Rechtsschutz заявлен

## Ключевые решения BSG

| Дело | Суть |
|------|------|
| BSG B 7b AS 18/06 R (2006) | Первое определение: «einfacher, im unteren Marktsegment liegender Standard» |
| BSG B 14 AS 55/08 R (2009) | Обязанность schlüssiges Konzept |
| BSG B 14 AS 33/10 R (2012) | Требования к Vergleichsraum |
| BSG B 14 AS 174/11 R (2013) | Устаревшие данные → концепция недействительна |
| BSG B 4 AS 87/13 R (2014) | Без schlüssiges Konzept → реальные расходы |
| BSG B 14 AS 153/11 R (2014) | Eigentumswohnung — аналогичные принципы |
| BSG B 14 AS 21/17 R (2018) | Aktualitätsanforderungen конкретизированы |
