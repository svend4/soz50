# KdU — Kosten der Unterkunft und Heizung (§ 22 SGB II)

[← Leistungen](./README.md) | [← SGB II](../README.md)

> **KdU** ist einer der häufigsten Streitpunkte im Sozialrecht.
> Die Behörde kürzt — der Klient wehrt sich. Meist zu Recht!
> Das Instrument: **Schlüssiges Konzept** des Jobcenters.
> Fehlt es → Tabellenwert (Wohngeldtabelle + 10%) gilt!

---

## Grundregel § 22 SGB II

```
§ 22 Abs. 1 SGB II:
  "Bedarfe für Unterkunft und Heizung werden in Höhe der tatsächlichen
  Aufwendungen anerkannt, soweit diese angemessen sind."

→ Tatsächliche Kosten zuerst!
→ Angemessenheit ist die Ausnahme, nicht die Regel
→ Beweislast: Jobcenter muss Unangemessenheit beweisen
```

---

## Was gehört zu KdU?

```
KdU = Kosten der Unterkunft:
  ✓ Kaltmiete
  ✓ Betriebskosten (Nebenkosten ohne Heizung)
  ✓ Mietkaution (als Darlehen, § 22 Abs. 6 SGB II)
  ✓ Garagenmiete (wenn ortsüblich und nicht verzichtbar)
  ✓ Genossenschaftsanteile (als Darlehen)

KdU = Kosten der Heizung:
  ✓ Tatsächliche Heizkosten (Gas, Öl, Fernwärme, Strom für Heizung)
  ✓ Warmwasserkosten (bei zentraler Warmwasserversorgung)
  ✓ Wartungskosten Heizungsanlage

NICHT zu KdU:
  ✗ Haushaltsstrom (gehört zum Regelbedarf)
  ✗ Möblierungszuschlag (in der Regel)
  ✗ Kosten für 2. Wohnung (Ausnahme: doppelte Haushaltsführung)
```

## Angemessenheit — Die Produkttheorie

```
BSG, Urt. v. 07.11.2006, B 7b AS 18/06 R — "Produkttheorie":

Angemessen = Angemessene Wohnfläche × Angemessener Quadratmeterpreis

Angemessene Wohnfläche (Richtwerte aus sozialen Wohnungsbau):
  1 Person:   45–50 m²
  2 Personen: 60 m²
  3 Personen: 75 m²
  4 Personen: 85–90 m²
  + 10–15 m² je weitere Person

ABER: Produkt entscheidet, nicht einzelne Faktoren!
→ Kleine Wohnung + hoher Preis/m² kann angemessen sein
→ Große Wohnung + billiger Preis/m² kann angemessen sein
```

## Das Schlüssige Konzept

### Was ist das?

```
BSG, Urt. v. 22.09.2009, B 4 AS 18/09 R:
  → Jobcenter muss Angemessenheitsgrenze mit "schlüssigem Konzept" belegen
  → Kein Konzept → Tabellenwerte gelten!

Anforderungen an schlüssiges Konzept:
  1. Gesamter Wohnungsmarkt muss abgebildet sein (nicht nur billiges Segment)
  2. Aktuelle Daten (nicht älter als 2 Jahre)
  3. Differenzierung nach Wohnungsgrößen
  4. Repräsentative Datenbasis (Mietdatenbank, Mietspiegel oder Erhebung)
  5. Schlüssiger Zusammenhang zwischen Daten und Grenzwert
```

### Häufige Fehler der Behörde

```
→ Mietspiegel verwendet der nur qualifizierte Wohnungen erfasst
  (nicht Bestandsmieten → zu teuer/zu billig)
→ Daten älter als 2 Jahre
→ Vergleichsraumabgrenzung zu eng (nur Stadtteile statt Stadt)
→ Kein Nachweis dass Wohnungen zu diesem Preis tatsächlich verfügbar
→ Konzept nicht öffentlich zugänglich gemacht
```

### Wenn kein schlüssiges Konzept vorliegt

```
BSG, Urt. v. 30.01.2019, B 14 AS 24/18 R:
  → Tabellenwert nach § 12 WoGG + 10% Zuschlag

Tabelle 2026 (Beispiel Großstädte, 1 Person, Mietenstufe VI):
  WoGG-Wert: ca. 580 € + 10% = ca. 638 €
  → Das ist die Angemessenheitsgrenze wenn kein Konzept!
```

## Kostensenkungsverfahren

### Ablauf

```
Schritt 1: Jobcenter schickt "Kostensenkungsaufforderung"
  → Frist zur Kostensenkung: mindestens 6 Monate (BSG)
  → Inhalt: Konkrete Angemessenheitsgrenze mitteilen!
  → Hinweis auf Konsequenzen

Schritt 2: Klient sucht günstiger — oder Unmöglichkeit dokumentieren

Schritt 3: Wenn kein Umzug möglich:
  → "Unmöglichkeit" nachweisen:
    ✓ Absagen auf Wohnungsangebote sammeln
    ✓ Eigene Suche dokumentieren (Datum, Angebot, Absage)
    ✓ Ggf. Attest (Krankheit macht Umzug unzumutbar)

Schritt 4: Wenn nach Frist weiter zu teuer:
  → Nur noch angemessene Kosten werden übernommen
  → ABER: Nur wenn Jobcenter Konzept hat + Umzug möglich war!
```

### Formelle Fehler der Kostensenkungsaufforderung

```
Häufige Fehler:
  → Keine konkrete Grenze genannt (nur "Sie müssen Kosten senken")
  → Frist zu kurz (unter 6 Monate)
  → Kein Hinweis auf zumutbare Wohnungen im Vergleichsraum
  → Nicht schriftlich

→ Formfehler = Kostensenkungsaufforderung unwirksam!
→ Weitere Übernahme zu tatsächlichen Kosten!
```

## Heizkosten — Besonderheiten

```
Heizkosten werden tatsächlich übernommen — ABER:
  → "Unwirtschaftliches Heizverhalten" kann Kürzung begründen
  → Bundesweite Heizkostenspiegel (co2online) als Maßstab

Heizkostenspiegel 2025 (Beispielwerte, bundesweit):
  Gas: ca. 10–15 €/m²/Jahr
  Öl:  ca. 15–20 €/m²/Jahr
  Fernwärme: 15–25 €/m²/Jahr

Bei Überschreitung:
  → Erst Hinweis, Möglichkeit zur Erklärung!
  → Schlechte Isolation → kein Verschulden des Klienten!
  → Nebenkostenabrechnung kann rückwirkend Probleme zeigen
```

## Umzug — Wann zahlt das Jobcenter?

```
§ 22 Abs. 4 SGB II — Zusicherung vor Umzug erforderlich!

Jobcenter muss Umzug vorab genehmigen (Zusicherung):
  → Sonst riskiert Klient dass neue KdU nicht anerkannt wird

Jobcenter muss Zusicherung erteilen wenn:
  1. Umzug zur Eingliederung in Arbeit erforderlich (§ 22 Abs. 6 S.3 SGB II)
  2. Umzug aus anderen Gründen notwendig (gesundheitliche Gründe, zu klein)
  3. Neue Wohnung ist angemessen

Umzugskosten (§ 22 Abs. 6 SGB II):
  → Als Darlehen oder Zuschuss möglich
  → Jobcenter hat Ermessen

Keine Zusicherung nötig wenn:
  → Umzug innerhalb der Bedarfsgemeinschaft (gleiche Stadt, günstiger)
  → Notfallumzug (Wohnungsverlust, Gewalt)
```

## Widerspruch gegen KdU-Kürzung

```
Prüfschema für Widerspruch:

1. Hat Jobcenter schlüssiges Konzept?
   → Nein: Tabellenwert + 10% gilt → Widerspruch!

2. Kostensenkungsaufforderung formell korrekt?
   → Fehlerhaft: Widerspruch!

3. Frist eingehalten (6 Monate)?
   → Nein: Widerspruch!

4. War günstigere Wohnung wirklich verfügbar?
   → Dokumentiert gesucht und keine gefunden → Widerspruch!

5. Liegen persönliche Gründe vor (Krankheit, Kind in Schule)?
   → Unzumutbarkeit → Widerspruch!

Frist: 1 Monat ab Bescheid (§ 84 SGG)
Muster: s. Widerspruch-Musterbrief.md
```
