[← SGB II](../README.md) | [← Sozialrecht](../../README.md)

## Виды заявлений

| Antrag | Wann | Formblatt |
|--------|------|----------|
| **Erstantrag Bürgergeld** | При первом обращении | BA-Formblatt (Antrag auf ALG II / Bürgergeld) |
| **Weiterbewilligungsantrag** | За 1–2 месяца до конца Bewilligungszeitraum | BA-Formblatt |
| **Änderungsantrag** | При изменении ситуации (доход, жильё, семья) | Schriftlich formlos |
| **Antrag auf Mehrbedarf** | Беременность, диета, одинокое родительство | Schriftlich + Nachweise |
| **Antrag KdU-Erhöhung** | При повышении аренды | Schriftlich + Mieterhöhungsschreiben |
| **Antrag Einmalleistung** | Erstausstattung, Schulbedarf | Schriftlich vor Kauf! |
| **Antrag Darlehen** | Reparaturen, unerwartete Ausgaben | § 24 Abs. 1 SGB II |
| **Antrag auf Akteneinsicht** | При любом Widerspruch | § 25 SGB X — immer! |

---

## Процедура подачи первого заявления

```
Schritt 1: Termin beim Jobcenter
    → Online oder telefonisch (Nummer auf Website Jobcenter)
    → Alternativ: Antrag online über jobcenter-portal.de

Schritt 2: Unterlagen zusammenstellen (см. чек-лист ниже)

Schritt 3: Antrag abgeben
    → Persönlich (Datum + Unterschrift vom Sachbearbeiter lassen!)
    → Per Post (Einschreiben!)
    → Online über jobcenter-digital.de

Schritt 4: Antragsdatum sichern
    → Der Anspruch beginnt ab Antragsdatum — nicht ab Bewilligungsdatum!
    → § 37 SGB II: Leistungen werden ab dem Tag des Antrags gewährt

Schritt 5: Auf Bescheid warten (ca. 2–4 Wochen)
    → Bei Verzögerung: Untätigkeitsklage möglich nach 6 Monaten
    → Bei akuter Not: Darlehen nach § 24 SGB II beantragen
```

## Checkliste: Unterlagen Erstantrag

### Immer erforderlich

```
Personalien / Identität:
  [ ] Personalausweis oder Reisepass (alle BG-Mitglieder)
  [ ] Meldebestätigung (aktuell, nicht älter als 3 Monate)
  [ ] Mietvertrag + letzte Nebenkostenabrechnung
  [ ] Letzte 3 Monatsmietzahlungsbelege (Kontoauszüge)

Finanzen:
  [ ] Kontoauszüge der letzten 3 Monate (alle Konten!)
  [ ] Sparbücher, Depot-Auszüge (Vermögen!)
  [ ] Kfz-Schein (wenn Auto vorhanden — Vermögen prüfen)

Einkommen:
  [ ] Lohnabrechnungen letzte 3 Monate (wenn erwerbstätig)
  [ ] Rentenbescheid (wenn Rentner)
  [ ] Unterhaltsnachweise
  [ ] Kindergeldbescheid
```

### Дополнительно по ситуации

```
Kinder:
  [ ] Geburtsurkunden der Kinder
  [ ] Schulbescheinigungen
  [ ] Kindergeldbescheid (Familienkasse)
  [ ] Unterhaltsbescheid / Unterhaltsvorschusstitel

Gesundheit / Mehrbedarf:
  [ ] Schwerbehindertenausweis (GdB ≥ 50)
  [ ] Ärztliches Attest (Ernährungsmehrbedarf, Schwangerschaft)

Ausländer:
  [ ] Aufenthaltstitel (Vorderseite + Rückseite!)
  [ ] ggf. Anerkennungsbescheid BAMF
```

## Wichtige Fristen

| Situation | Frist | Folge bei Versäumnis |
|-----------|-------|---------------------|
| Weiterbewilligungsantrag | Vor Ende Bewilligungszeitraum | Lücke im Leistungsbezug |
| Widerspruch gegen Bescheid | 1 Monat nach Bekanntgabe | Bestandskraft (Bescheid wird bindend) |
| Änderung mitteilen | Unverzüglich (§ 60 SGB I) | Überzahlung → Rückforderung |
| Einmalleistung (Erstausstattung) | Vor Anschaffung | Sonst: Ablehnung möglich |

---

## Häufige Fehler

- **Antrag zu spät stellen** → Anspruch gilt erst ab Antragsdatum, kein rückwirkend
- **Vermögen verschweigen** → Rückforderung + evtl. Strafanzeige § 263 StGB
- **Änderung nicht melden** → Rückforderung (Überzahlung)
- **Einmalleistung nach Kauf beantragen** → wird abgelehnt
- **Weiterbewilligungsantrag vergessen** → Unterbrechung der Leistungen
