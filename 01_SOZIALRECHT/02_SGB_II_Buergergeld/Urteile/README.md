## Как читать BSG-Urteil

```
BSG B 14 AS 60/12 R
     │  │      │  │
     │  │      │  └─ R = Revision (Urteil), B = Beschluss
     │  │      └──── Aktenzeichen: lfd. Nr. / Jahr
     │  └─────────── AS = Grundsicherung für Arbeitsuchende
     └────────────── B = Bundessozialgericht, 14. Senat
```

Senat-Zuständigkeit:
- **4. Senat** — SGB II allgemein
- **14. Senat** — SGB II (2. Kammer)
- **8. Senat** — AsylbLG, SGB XII
- **12. Senat** — SGB XI Pflege
