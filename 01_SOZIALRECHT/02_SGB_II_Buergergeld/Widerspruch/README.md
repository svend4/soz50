# Widerspruch & Klage — Оспаривание решений Jobcenter

[← SGB II](../README.md) | [← Sozialrecht](../../README.md)

---

## Схема оспаривания

```
Bescheid (решение)
    │
    ├─ Widerspruch (в течение 1 месяца)
    │       │
    │       ├─ Abhilfe (отмена решения) ✓
    │       └─ Widerspruchsbescheid (отказ)
    │               │
    │               └─ Klage beim Sozialgericht (в течение 1 месяца)
    │                       │
    │                       ├─ Urteil SG
    │                       └─ Berufung LSG → Revision BSG
    │
    └─ Antrag auf einstweiligen Rechtsschutz (срочная защита)
           (§ 86b SGG — при острой нужде)
```

---

## Сроки

| Шаг | Срок |
|-----|------|
| Widerspruch | **1 Monat** после получения Bescheid |
| Klage | **1 Monat** после Widerspruchsbescheid |
| Antrag einstweiliger Rechtsschutz | без срока (при острой нужде) |

## Важно

- Widerspruch обязательно подавать **письменно** (per Post mit Einschreiben или persönlich mit Empfangsbestätigung)
- При подаче Widerspruch запросить **Akteneinsicht** (доступ к делу)
- При срочной нужде — параллельно подавать **Antrag auf einstweiligen Rechtsschutz** в Sozialgericht
