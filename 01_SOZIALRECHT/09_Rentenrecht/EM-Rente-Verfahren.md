# Erwerbsminderungsrente (EM-Rente) — Verfahren und Beratung

[← Rentenrecht](./README.md) | [← Sozialrecht](../README.md)

> EM-Rente = Rente bei Invalidität/dauerhafter Erkrankung.
> Zuständig: Deutsche Rentenversicherung (DRV).
> ACHTUNG: Ablehnung häufig! Widerspruchsquote: fast 50% werden aufgehoben.
> Sofort nach Ablehnung: Widerspruch + Klage in Betracht ziehen!

---

## Voraussetzungen EM-Rente (§ 43 SGB VI)

```
DREI VORAUSSETZUNGEN (alle müssen erfüllt sein):

1. WARTEZEIT (§ 50 SGB VI):
   → Mind. 5 Jahre Versicherungszeit (Mindestwartezeit)
   → Zählen: Pflichtbeitragszeiten, freiwillige Zeiten, Ersatzzeiten
   → AUCH: Kindererziehungszeiten, Pflegezeiten!

2. MINDESTBEITRAGSZEITEN in den letzten 5 Jahren:
   → Mindestens 3 Jahre Pflichtbeitragszeiten in den letzten 5 Jahren
   → "Dreijahreszeitraum" vor Eintritt der Erwerbsminderung
   → AUSNAHME: Wenn Wartezeit von 20 Jahren erfüllt → kein Dreijahreszeitraum nötig

3. ERWERBSMINDERUNG (§ 43 Abs. 1 + 2 SGB VI):
   → Volle EM: < 3 Stunden/Tag arbeitsfähig (auf dem allgemeinen Arbeitsmarkt)
   → Teilweise EM: 3–6 Stunden/Tag arbeitsfähig
   → "Allgemeiner Arbeitsmarkt" = alle Tätigkeiten weltweit, nicht nur erlernter Beruf!
```

---

## Leistungsarten und Leistungshöhe

```
VOLLSTÄNDIGE ERWERBSMINDERUNGSRENTE (§ 43 Abs. 2 SGB VI):
  → Weniger als 3 Stunden täglich arbeitsfähig
  → Anspruch auf volle EM-Rente

TEILWEISE ERWERBSMINDERUNGSRENTE (§ 43 Abs. 1 SGB VI):
  → 3–6 Stunden täglich arbeitsfähig
  → Anspruch auf halbe EM-Rente (ca. 50% der vollen)
  → Ausnahme: Wenn kein Teilzeitjob zumutbar erreichbar → gilt als voll erwerbsgemindert!

RENTE FÜR BERGBAULEUTE (§ 45 SGB VI):
  → Für Personen, die im Bergbau tätig waren

Rentenhöhe (vereinfacht):
  → Grundlage: Entgeltpunkte aus Versicherungsbiographie
  → "Zugangsfaktor": Abzüge bei frühzeitigem Renteneintritt
  → "Zurechnungszeit": DRV rechnet Versicherungszeiten bis Regelrentenalter hinzu!
    (wichtige Besonderheit: EM-Rente nicht so schlecht wie befürchtet)
  → Durchschnittliche EM-Rente 2025: ca. 900–1.100 € (West)

Hinzuverdienstgrenzen (§ 96a SGB VI):
  → 2023 liberalisiert: flexible Hinzuverdienstgrenzen
  → Maximal 3/8 der Beitragsbemessungsgrenze bei voller EM-Rente
  → Prüfen: DRV-Merkblatt Hinzuverdienst (aktuell!)
```

## Das Antragsverfahren

```
SCHRITT 1: ANTRAGSTELLUNG
  → Antrag bei: DRV (Regionalstelle oder Bund)
  → Formular: R0100 (Rentenantrag wegen verminderter Erwerbsfähigkeit)
  → Online: meine-drv.de
  → Kostenlose Beratung: DRV-Beratungsstellen überall

  Was mitbringen:
  → Personalausweis
  → Krankenkassennachweis
  → Rentenversicherungsnummer
  → Ärztliche Atteste + Facharztberichte
  → Aufstellung aller Ärzte (DRV fragt selbst an, aber hilfreich)

SCHRITT 2: DRV KLÄRT MEDIZINISCH AB
  → DRV beauftragt eigenen medizinischen Dienst (Gutachter)
  → Gutachten: Aktengutachten oder persönliche Untersuchung
  → Frist: DRV hat 3 Monate Zeit (§ 17 Abs. 1 SGB I)

SCHRITT 3: BESCHEID
  → Bewilligung: EM-Rente wird gezahlt
  → Ablehnung: häufig! → sofort Widerspruch einlegen!
```

## Häufige Ablehnungsgründe und Gegenargumente

```
ABLEHNUNGSGRUND 1: "Nicht vollständig erwerbsgemindert"
  → DRV-Gutachten: noch 3–6 h/Tag arbeitsfähig
  → Gegenargument: eigenes Gegengutachten + Facharztberichte
  → BSG: DRV-Gutachter ≠ letzte Instanz, Gericht würdigt alle Gutachten

ABLEHNUNGSGRUND 2: "Kein Anspruch auf dem allgemeinen Arbeitsmarkt"
  → DRV benennt "Verweisungsberufe" (theoretische Jobs)
  → BSG-Rechtsprechung: Verweisungsberufe müssen realistisch sein
  → Wenn keine realistischen Stellen: faktische volle EM!
  → BSG B 13/5 R 123/03 R: "Katalogberufe" können nicht beliebig benannt werden

ABLEHNUNGSGRUND 3: "Wartezeit nicht erfüllt"
  → Prüfen: alle Versicherungszeiten berücksichtigt?
  → Schulzeiten, Ausbildung, Mutterschutz, Pflegezeiten, KiEZ?
  → Auslandszeiten (EU/Abkommensstaaten)?

ABLEHNUNGSGRUND 4: "Dreijahreszeitraum nicht erfüllt"
  → Prüfen: tatsächliche Pflichtbeitragszeiten der letzten 5 Jahre
  → Krankheitzeiten mit Krankengeld: zählen als Pflichtbeiträge!
  → Kindererziehungszeiten: zählen!

ABLEHNUNGSGRUND 5: "Rente endet / keine Weitergewährung"
  → Befristete EM-Rente: nach 3 Jahren Prüfung
  → Weiterbewilligungsantrag: rechtzeitig stellen!
```

## Widerspruch und Klage

```
WIDERSPRUCH (§ 83 SGG):
  → Frist: 1 Monat ab Bescheid
  → Einlegen bei: DRV (schriftlich)
  → Mindestinhalt: "Ich lege Widerspruch ein gegen Bescheid vom [Datum]"
  → Begründung kann nachgereicht werden!

STRATEGIE:
  → Eigenes fachärztliches Gutachten beauftragen:
    → Internist/Psychiater/Neuropsychiater je nach Erkrankung
    → Kosten: ca. 300–800 € — VKH / Prozesskostenhilfe möglich!
  → Alle Befundberichte einreichen
  → Psychische Erkrankungen: oft unterschätzt → genau dokumentieren

KLAGE SOZIALGERICHT (§ 54 SGG):
  → Frist: 1 Monat nach Widerspruchsbescheid
  → Kostenlos: keine Gerichtskosten im SGG!
  → PKH (§§ 73a SGG, 114 ZPO): Prozesskostenhilfe möglich
  → Im Verfahren: Gericht holt eigenes Gutachten ein!
  → Gutachter des Gerichts: unabhängig, oft anders als DRV-Gutachter

STATISTIK:
  → Ca. 40–50% der Klagen gegen EM-Renten-Ablehnung: erfolgreich!
  → Widerspruch lohnt sich fast immer!
```

## Nahtlosigkeit (§ 145 SGB III)

```
Problem nach Krankengeld-Ende:
  → 78 Wochen Krankengeld (§ 44 SGB V) sind ausgeschöpft
  → EM-Rente noch nicht bewilligt
  → Wer zahlt jetzt?

§ 145 SGB III — Nahtlosigkeitsregelung:
  → Wenn Person sich bei BA meldet (trotz Krankheit):
    → BA zahlt ALG I "überbrückend" bis EM-Rente entschieden
  → Kostenerstattung durch DRV wenn EM-Rente rückwirkend bewilligt

Voraussetzungen:
  1. Person meldet sich bei BA als arbeitssuchend
  2. Nahtlosigkeitsbescheinigung (behandelnder Arzt)
  3. BA leitet Verfahren ein

Alternative wenn § 145 nicht greift:
  → JC: Bürgergeld (SGB II) als Auffangleistung
  → Sozialamt: HzL § 27 SGB XII
  → Rückzahlung wenn EM-Rente rückwirkend: JC hat Erstattungsanspruch!
```

## Befristete vs. Unbefristete EM-Rente

```
BEFRISTETE EM-RENTE (§ 102 SGB VI):
  → Standard: Rente wird auf 3 Jahre befristet!
  → Begründung: Möglichkeit der Besserung
  → Nach 3 Jahren: Weiterbewilligungsantrag stellen!

UNBEFRISTETE EM-RENTE:
  → Wenn nach 3+3+3=9 Jahren Befristung: Rente wird unbegrenzt
  → ODER: wenn klar keine Verbesserung möglich
  → Praxis: DRV oft sehr zögerlich bei Entfristung

WEITERBEWILLIGUNGSANTRAG:
  → 3 Monate vor Ablauf der Befristung stellen!
  → Neues Gutachten: DRV prüft neu
  → Einreichen: aktualisierte Arztberichte + Nachweise
  → Bei Ablehnung: sofort Widerspruch!

ÄNDERUNG DES LEISTUNGSUMFANGS:
  → Wenn Krankheit schlimmer: Antrag auf Höherstufung (Teilweise → Volle EM)
  → Wenn besser: DRV kann selbst Rente entziehen (Überprüfungsverfahren)
```

## Zusammentreffen EM-Rente mit anderen Leistungen

```
EM-RENTE + BÜRGERGELD (SGB II):
  → EM-Rente < Bedarfsdeckung → SGB II ergänzend möglich
  → EM-Rente als Einkommen anrechnen (§ 11 SGB II)
  → Freibetrag: nur "Erwerbstätigen-Freibetrag" (§ 11b) NICHT für Rente!
  → Praxis: EM-Rente oft < Bürgergeld-Bedarf → JC ergänzt

EM-RENTE + SGB XII (Grundsicherung im Alter):
  → Volle dauerhaft EM + Wartezeit: Grundsicherung möglich (§ 41 SGB XII)
  → Gleichzeitig: kein SGB II mehr wenn Grundsicherung bewilligt
  → TIPP: Bei dauerhafter voller EM → direkt Grundsicherung prüfen!

EM-RENTE + SCHWERBEHINDERTENAUSWEIS:
  → EM-Rente ≠ automatisch GdB 50+
  → Separater Antrag beim Versorgungsamt nötig!
  → ABER: bei GdB 50+ → Frühverrentung schon ab 62 möglich (§ 37 SGB VI)

EM-RENTE + PFLEGELEISTUNGEN:
  → EM-Rente + Pflegegeld: möglich (kumulativ)
  → EM-Rente zählt als Einkommen bei SGB XII-Pflegeleistungen

EM-RENTE + UNTERHALT:
  → Bei Scheidung: EM-Rente kann Unterhaltspflicht mindern
  → Versorgungsausgleich: EM-Rentenpunkte werden geteilt!
```

## Beratungshinweise

```
WO BERATEN?
  → DRV-Beratungsstellen (kostenlos!): Pflicht zur Rentenberatung
  → VdK / SoVD: kostenpflichtige Mitgliedschaft, umfassende Beratung + Vertretung
  → Rentenberater (§ 10 RDG): kostenpflichtig, spezialisiert
  → Sozialrechtsanwalt: wenn Klage nötig

WAS BESORGEN?
  → Rentenauskunft anfordern (kostenlos bei DRV)!
  → Versicherungsverlauf: prüfen ob alle Zeiten erfasst
  → Fehlende Zeiten: Klärungsantrag bei DRV

TYPISCHE FALLSTRICKE:
  → Zu späte Antragstellung: Rente nur max. 1 Monat rückwirkend
    (aber Krankengeld überbrückt die Zeit!)
  → Weiterbewilligungsantrag vergessen → Rente endet!
  → Hinzuverdienst nicht gemeldet → Rente muss zurückgezahlt werden!
  → Bei Pflegeleistungen: EM-Rente melden!
```
