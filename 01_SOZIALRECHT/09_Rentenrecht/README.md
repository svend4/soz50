# Rentenrecht — Пенсионное право

[← Sozialrecht](../README.md) | [← Главная](../../README.md)

> Rentenversicherung = SGB VI. Träger: **Deutsche Rentenversicherung (DRV)**.
> Für Sozialarbeit besonders relevant: Erwerbsminderungsrente, Regelaltersrente,
> Rehabilitation vor Rente, Schnittstellen zu SGB II und SGB XII.

---

## Rentenarten — виды пенсии

| Rente | Voraussetzung | Höhe |
|-------|--------------|------|
| **Regelaltersrente** | 67 Jahre + Wartezeit 5 Jahre | Entgeltpunkte × Rentenwert |
| **Altersrente für langjährig Versicherte** | 65 J. + 35 Beitragsjahre | dto. |
| **Altersrente für schwerbehinderte Menschen** | 63 J. + GdB ≥ 50 + 35 Jahre | dto. (Abschlag möglich) |
| **Erwerbsminderungsrente (EM-Rente)** | < 3h oder < 6h arbeitsfähig + 5 J. Beiträge | Hochrechnung |
| **Hinterbliebenenrente** | Tod des Versicherten | % der Versichertenrente |

---

## Erwerbsminderungsrente — самое важное для Sozialarbeit

```
Volle EM-Rente (§ 43 Abs. 2 SGB VI):
  → weniger als 3 Stunden täglich arbeitsfähig
  → auf dem allgemeinen Arbeitsmarkt

Teilweise EM-Rente (§ 43 Abs. 1 SGB VI):
  → 3 bis unter 6 Stunden täglich arbeitsfähig

Voraussetzungen:
  ✓ 5 Jahre Wartezeit (Mindestversicherungszeit)
  ✓ In den letzten 5 Jahren: mind. 3 Jahre Pflichtbeiträge
  ✓ Ärztliches Gutachten der DRV
```

### Rentenhöhe EM-Rente

```
Berechnung: Entgeltpunkte × aktueller Rentenwert × Zugangsfaktor

Besonderheit: Zurechnungszeit
  → Als ob der Versicherte bis 67 weitergearbeitet hätte
  → Deutlich höher als reine Beitragsrente!

Abschlag: Rentenbeginn vor 65 → 0,3% pro Monat (max. 10,8%)
```

---

## Reha vor Rente (§ 9 SGB VI)

```
Grundsatz: "Reha vor Rente"
→ DRV muss zuerst Rehabilitation versuchen, bevor EM-Rente bewilligt wird

Rentenantrag stellt automatisch Reha-Antrag!
  → DRV prüft: kann Arbeitsfähigkeit durch Reha wiederhergestellt werden?
  → Medizinische Reha (z.B. Sucht, Orthopädie, Psyche)
  → Berufliche Reha (Umschulung, Qualifizierung)

Wenn Reha nicht hilft oder möglich → EM-Rente
```

## Rentenantrag — практика

```
Antrag bei DRV (Deutsche Rentenversicherung):
  Online: drv.de
  Persönlich: Auskunfts- und Beratungsstellen DRV
  Formulare: Rentenantrag V0050

Unterlagen:
  [ ] Personalausweis
  [ ] Sozialversicherungsausweis (falls vorhanden)
  [ ] Ärztliche Unterlagen (alle Diagnosen, Atteste)
  [ ] Bescheide Pflegekasse, Schwerbehindertenausweis (falls vorhanden)
  [ ] Lückennachweise (Zeiten ohne Beiträge erklären: Kinder, Pflege, etc.)

Dauer: DRV hat 3 Monate Bearbeitungszeit
Bei Ablehnung: Widerspruch → Klage Sozialgericht
```

## Rentenauskunft — что проверить для клиента

```
Kostenlose Rentenauskunft: drv.de oder Auskunftsstelle DRV
→ Renteninformation (jährlich automatisch ab 27 Jahren)
→ Rentenauskunft (individuell auf Antrag)

Wichtige Fragen:
  ✓ Sind alle Beitragszeiten erfasst? (Lücken?)
  ✓ Kindererziehungszeiten eingetragen? (§§ 56, 249 SGB VI)
  ✓ Pflegezeiten? (§§ 3 S.1 Nr.1a, 177 SGB VI)
  ✓ Schul-/Ausbildungszeiten? (Anrechnungszeiten § 58 SGB VI)
```

## Schnittstellen zu anderen Leistungen

| Situation | Konsequenz |
|-----------|-----------|
| EM-Rente < Grundsicherungsbedarf | Aufstockung durch SGB XII § 41 (Sozialamt) |
| Rentenantrag läuft, noch kein Bescheid | Überbrückung durch SGB XII § 19 Abs. 2 (Darlehen) |
| Ablehnung EM-Rente, SGB II-Bezug | Jobcenter kann nicht als "nicht erwerbsgemindert" behandeln → Nahtlosigkeitsregelung § 145 SGB III |
| Rente + Bürgergeld? | Rente wird als Einkommen angerechnet (§ 11 SGB II) |

## Kindererziehungszeiten — важно для одиноких матерей

```
§ 56 SGB VI:
  → Pro Kind: 3 Jahre Kindererziehungszeit (nach 1992)
  → Pro Kind: 1 Jahr (vor 1992 — "Mütterrente")
  → Zählen als Beitragszeiten!
  → Sehr wichtig für Frauen mit Erwerbslücken

Beantragen: beim DRV (VBEV-Antrag)
→ Oft vergessen! Unbedingt nachprüfen!
```
