## Rechtsweg-Übersicht Ausländerrecht

```
Asylentscheidung (BAMF):
  VG → Klage innerhalb 2 Wochen (einfache Ablehnung)
        oder 1 Woche (offensichtlich unbegründet / Dublin)
  OVG → Berufung (Zulassung nötig)
  BVerwG → Revision

Aufenthaltstitel (Ausländerbehörde):
  VG → Klage + Eilantrag § 80 Abs. 5 VwGO
  OVG → Berufung
  BVerwG → Revision

AsylbLG-Leistungen:
  SG → Klage + Eilantrag § 86b SGG
  LSG → Berufung
  BSG → Revision
```

---

## Praktischer Hinweis

```
Bei abgelehnten AsylbLG-Leistungen (§ 6, § 4 chronisch):
  → Immer Widerspruch einlegen (kostenlos)
  → Bei Dringlichkeit: einstweiliger Rechtsschutz SG (§ 86b SGG)
  → Prozesskostenhilfe beantragen!
  → Beratung: Flüchtlingsrat, PRO ASYL, Rechtsanwalt (Fachgebiet AsylR)
```
