## Ключевой вопрос: какой закон применяется?

```
Статус пребывания → какие выплаты?

Aufenthaltserlaubnis (§ 7 AufenthG)
  └─ erwerbsfähig? → SGB II (Jobcenter)
  └─ nicht erwerbsfähig? → SGB XII (Sozialamt)

Gestattung / Duldung (первые 36 мес.) → AsylbLG (Grundleistungen)
Gestattung / Duldung (после 36 мес.) → AsylbLG § 2 (analog SGB XII)

Anerkannt: Flüchtling / subsidiär Schutz → SGB II oder SGB XII
```
