## Arten der Aufenthaltstitel

```
Aufenthaltstitel (§ 4 AufenthG)
    │
    ├─ Visum (§ 6) — краткосрочное (Schengen / nationales D-Visum)
    │
    ├─ Aufenthaltserlaubnis (§ 7) — временный ВНЖ
    │       ├─ zu Ausbildungszwecken (§§ 16a–17a)
    │       ├─ zu Erwerbszwecken (§§ 18ff)
    │       ├─ aus familiären Gründen (§§ 27–36a)
    │       └─ aus humanitären Gründen (§§ 22–26)
    │
    ├─ Niederlassungserlaubnis (§ 9) — постоянный ВНЖ
    │
    └─ Erlaubnis zum Daueraufenthalt-EU (§ 9a)
```

## Freizügigkeit — граждане ЕС

Граждане ЕС имеют право свободного передвижения (FreizügG/EU).

```
EU-Bürger + erwerbsfähig → SGB II
EU-Bürger + arbeitsuchend → SGB II (erste 3 Monate fraglich)
EU-Bürger, kein Aufenthaltsrecht → kein SGB II (BSG-Rspr.)
```

> Важно: BSG B 14 AS 15/17 R — системное отстранение EU-Bürger без Aufenthaltsrecht.
