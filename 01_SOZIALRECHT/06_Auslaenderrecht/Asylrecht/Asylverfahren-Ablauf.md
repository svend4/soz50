# Asylverfahren — Ablauf von Ankunft bis Bescheid

[← Asylrecht](./README.md) | [← Ausländerrecht](../README.md)

> Das Asylverfahren in Deutschland ist komplex und entscheidend.
> Die **Anhörung beim BAMF ist der wichtigste Termin** — Fehler sind
> kaum korrigierbar. Vorbereitung und Begleitung sind essenziell.

---

## Überblick: Phasen des Asylverfahrens

```
Phase 1: Einreise und Registrierung
    ↓
Phase 2: Asylantragstellung (BAMF)
    ↓
Phase 3: Dublin-Prüfung (ggf. Überstellung)
    ↓
Phase 4: Anhörung (BAMF)
    ↓
Phase 5: Entscheidung des BAMF
    ↓
Phase 6: Klage (wenn Ablehnung)
    ↓
Phase 7: Aufenthaltserlaubnis / Abschiebung
```

---

## Phase 1: Einreise und Erstregistrierung

```
Wer ins Land kommt und Asyl will:
  → Asylgesuch äußern (gegenüber Polizei, Ausländerbehörde, Behörde)
  → Keine Form nötig — mündlich reicht ("Ich beantrage Asyl")
  → Person darf nicht zurückgewiesen werden (Non-Refoulement, Art. 33 GFK)

Erstregistrierung:
  → Ankunftsnachweis (§ 63a AsylG)
  → Biometrische Daten (Fingerabdrücke, Foto)
  → Eurodac-Abgleich (EU-weite Fingerabdruckdatenbank)
  → Verteilung: nach EASY-System (Erstverteilung) auf Bundesländer

Aufnahmeeinrichtung (AE):
  → Aufenthaltsgestattung (§ 55 AsylG) — kein Titel, nur Duldung
  → Residenzpflicht: oft nur im Landkreis / Bundesland (§ 56 AsylG)
  → Leistungen: AsylbLG § 3 (Grundleistungen)

IMPORTANT: Asylantrag stellt BAMF, nicht die Polizei!
  → Polizei kann nur Erstregistrierung vornehmen
  → Formeller Antrag: beim BAMF stellen (§ 13 AsylG)
```

## Phase 2: Förmliche Asylantragstellung (§ 14 AsylG)

```
Wo: Zuständige BAMF-Außenstelle (je nach Aufnahmeeinrichtung)
Frist: Keine starre Frist — aber: je früher desto besser!
  → Wer früher antrag stellt, hat früher Verfahren

Beim Antrag:
  → Persönliches Erscheinen (§ 25 AsylG)
  → Reisedokumente abgeben (wenn vorhanden)
  → Personalfragebogen ausfüllen
  → Weitere Befragung durch BAMF-Mitarbeiter

Aufenthaltsgestattung wird ausgestellt:
  → Gilt für gesamtes Bundesgebiet (nach § 60 AsylG Abmeldung bei Umzug!)
  → Verlängerung bis Entscheidung
```

## Phase 3: Dublin-Prüfung

```
Dublin-III-Verordnung (VO 604/2013):
  → Welcher EU-Staat ist für Asylverfahren zuständig?
  → Grundregel: Staat der ERSTEN Einreise in EU (§ 29 AsylG)

Ablauf:
  1. BAMF prüft: Eurodac-Treffer? Visum eines anderen EU-Staates?
  2. Wenn anderer Staat zuständig: Überstellungsverfahren
     → "Dublin-Bescheid" = Ablehnung + Überstellung
     → Frist: 6 Monate für Überstellung (§ 29 Abs. 1 Nr. 1 AsylG)
  3. Frist abgelaufen → Deutschland wird zuständig!
     → Selbsteintrittsrecht: Deutschland kann Verfahren übernehmen

WANN kein Dublin (Deutschland bleibt zuständig):
  ✓ Überstellungsfrist abgelaufen (6 Monate, 12/18 M. bei Untertauchen)
  ✓ Systemische Mängel im anderen EU-Staat
    (BVerwG/EuGH: Griechenland, Bulgarien, Ungarn oft mangelhaft!)
  ✓ Familiäre Bindungen in Deutschland (§ 36 Dublin-VO)
  ✓ Unbegleitete Minderjährige (fast nie Überstellung!)

Rechtsmittel gegen Dublin-Bescheid:
  → Klage beim VG (1 Woche Frist! § 36 Abs. 3 S. 1 AsylG)
  → Eilantrag gleichzeitig (§ 80 Abs. 5 VwGO)
  → Sofortiger Anwaltskontakt nötig!
```

## Phase 4: Anhörung (§ 25 AsylG) — WICHTIGSTE PHASE

```
§ 25 AsylG: Anhörung durch BAMF-Entscheider

Inhalt:
  → Person schildert Fluchtgründe
  → Alle Erlebnisse, Verfolgungshandlungen, Bedrohungen
  → Warum Rückkehr nicht möglich

Vorbereitung (SEHR WICHTIG):
  1. Anwalt/Beratungsstelle rechtzeitig aufsuchen
  2. Fluchtgeschichte chronologisch aufschreiben
  3. Beweise sammeln: Fotos, Zeugen, Dokumente
  4. Dolmetscher: Recht auf verständliche Übersetzung!
     → Bei Unklarheiten: nachfragen!
     → Protokoll durchlesen und korrigieren!

Häufige Fehler bei Anhörung:
  ✗ Fluchtgründe nicht vollständig genannt (spätere Ergänzung schwer!)
  ✗ Widersprüche zum vorherigen Gespräch
  ✗ Wichtige Details nicht erwähnt (Familienangehörige, Vorstrafen)
  ✗ Falsche Übersetzung nicht korrigiert
  ✗ Protokoll unterschrieben ohne Kontrolle

RECHT AUF PROTOKOLLKORREKTUR:
  → § 25 Abs. 7 AsylG: Protokoll muss vorgelesen/übersetzt werden
  → Person kann Fehler korrigieren BEVOR sie unterschreibt!
  → Nur nach Unterschrift gilt Protokoll!
```

### Geschlechtsspezifische Verfolgung

```
§ 3b AsylG: Verfolgungshandlungen wegen Geschlecht

  → Weibliche Genitalverstümmelung (FGM): Verfolgung!
  → Zwangsehe: Verfolgung!
  → Häusliche Gewalt wenn Staat nicht schützt: Verfolgung!
  → LGBTIQ+-Verfolgung: anerkannte Verfolgung!

Praktisch:
  → Frauen haben Recht auf weiblichen Anhörer (§ 24 Abs. 3 AsylG)
  → Dolmetscher desselben Geschlechts auf Wunsch
  → Bei Traumatisierung: psychologischer Bericht kann hilfreich sein
```

## Phase 5: BAMF-Entscheidung

### Mögliche Ergebnisse

```
1. Flüchtlingsschutz (§ 3 AsylG) — "Anerkennung"
   → AE § 25 Abs. 1 AufenthG (3 Jahre)
   → SGB II sofort, vollständige Integration

2. Subsidiärer Schutz (§ 4 AsylG)
   → AE § 25 Abs. 2 AufenthG (1 Jahr, verlängerbar)
   → SGB II sofort

3. Nationales Abschiebungsverbot (§ 60 Abs. 5 oder 7 AufenthG)
   → AE § 25 Abs. 3 AufenthG (1 Jahr)
   → AsylbLG, kein SGB II!

4. Ablehnung als "offensichtlich unbegründet" (§ 30 AsylG)
   → Klagefrist: 1 WOCHE (§ 36 Abs. 3 AsylG)!
   → Härtere Abschiebungskonsequenzen

5. Einfache Ablehnung (§ 31 Abs. 2 AsylG)
   → Klagefrist: 2 Wochen

6. Unbeachtlich / Nicht eingegangen
   → Sehr selten, wenn Person nicht erscheint
```

---

## Phase 6: Klage vor dem Verwaltungsgericht

```
Klage nach Ablehnung:
  → Klagefrist: 2 Wochen (einfache Ablehnung) / 1 Woche (offensichtlich unbegründet)
  → Klage beim zuständigen VG (Wohnort)
  → Sofortige Beauftragung Anwalt erforderlich!
  → PKH (Prozesskostenhilfe) möglich

Während des Klageverfahrens:
  → Aufenthaltsgestattung verlängert sich (§ 67 Abs. 1 S. 2 AsylG)
  → KEINE Abschiebung bis VG entschieden hat (aufschiebende Wirkung)
  → AUSNAHME: offensichtlich unbegründete Ablehnung
    → VG muss aufschiebende Wirkung gesondert anordnen

Eilantrag (§ 80 Abs. 5 VwGO):
  → Gleichzeitig mit Klage stellen wenn aufschiebende Wirkung fehlt
  → VG entscheidet innerhalb von Tagen (Notfall: Stunden!)
  → Ohne Eilantrag: Abschiebung möglich!

Aufenthaltsgestattung während Klage:
  → Bleibt erhalten
  → AsylbLG gilt weiterhin
  → Arbeitserlaubnis möglich (nach 3 Monaten + Genehmigung)
```

## Besondere Verfahrensformen

### Beschleunigtes Verfahren (§ 30a AsylG)

```
Für Herkunftsstaaten auf "sicherer Herkunftsländer"-Liste:
  → Albanien, Bosnien, Kosovo, Montenegro, Nord-Mazedonien, Serbien,
    Georgien (Stand 2026)
  → Ghana, Senegal, Marokko, Algerien, Tunesien

Konsequenzen:
  → Verfahren in Aufnahmeeinrichtung (keine Verteilung)
  → Sehr kurze Entscheidungsfristen (< 1 Woche!)
  → Keine Beratung vor Anhörung oft möglich
  → Ablehnung fast immer als "offensichtlich unbegründet"!

WICHTIG:
  → Auch bei sicherem Herkunftsland: individuelle Verfolgung prüfen!
  → LGBTIQ+, politische Verfolgung kann trotzdem bestehen
  → Immer Anwalt sofort einschalten!
```

### Folgeantragsverfahren

```
§ 71 AsylG: Folgeantrag nach rechtskräftig abgelehntem Erstverfahren

Voraussetzungen (sehr eng!):
  → Neue Sachverhalte NACH Abschluss des Erstverfahrens
  → Oder: neue Erkenntnisse die vorher nicht erreichbar waren

Praxis:
  → Nur selten erfolgreich
  → Neue Erkrankung: in besonderen Fällen (§ 60 Abs. 7 AufenthG)
  → Kirchenasyl: besondern Härtefall-Bescheid möglich

Duldung nach Ablehnung:
  → § 60a AufenthG: Duldung wenn Abschiebung nicht möglich
    (kein Pass, Lagebericht, gesundheitliche Gründe)
```

## Aktuelles 2025/2026

```
Syrische Flüchtlinge (ab 12/2024 nach Assad-Sturz):
  → BAMF eröffnet Widerrufsverfahren für anerkannte Syrer!
  → Flüchtlingsschutz kann widerrufen werden wenn Gefährdung weggefallen
  → ABER: Individuelle Prüfung — Pauschalhalt unzulässig!
  → Widerrufsbescheid → sofort Klage einlegen (3 Wochen Frist!)
  → AE bleibt bis Klage-Entscheidung (§ 84 AufenthG)

Beschleunigung der Verfahren:
  → BAMF hat 2024/2025 Entscheidungsrückstand abgebaut
  → Neue Verfahren: im Schnitt 6–12 Monate
  → Aber: komplizierte Fälle (Klagen, Dublin) deutlich länger
```
