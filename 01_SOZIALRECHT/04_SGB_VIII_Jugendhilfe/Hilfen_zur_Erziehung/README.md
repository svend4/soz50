# Hilfen zur Erziehung — §§ 27–35 SGB VIII

[← SGB VIII](../README.md) | [← Sozialrecht](../../README.md)

> **§ 27 SGB VIII:** Eltern haben Anspruch auf Hilfe, wenn
> eine dem Wohl des Kindes entsprechende Erziehung nicht gewährleistet ist
> und die Hilfe für seine Entwicklung geeignet und notwendig ist.

---

## Anspruchsvoraussetzungen (§ 27 Abs. 1 SGB VIII)

```
1. Personensorgeberechtigte (Eltern / Sorgeberechtigte) stellen Antrag
2. Erziehung nicht gewährleistet  ←─ Defizit in der Erziehungssituation
3. Hilfe für Entwicklung notwendig  ←─ Kausalität + Eignung der Hilfe
4. Anspruch: SUBJEKTIVES RECHT der Eltern (einklagbar!)
```

**Jugendamt KANN nicht einfach ablehnen, wenn Voraussetzungen vorliegen.**
→ Ablehnung: Widerspruch + ggf. einstweiliger Rechtsschutz (VG)

## Sozialpädagogische Familienhilfe (SPFH) — § 31 SGB VIII

Die häufigste ambulante HzE:

```
Inhalt:
  → Fachkraft kommt regelmäßig in die Familie (mehrmals/Woche)
  → Alltagsbegleitung: Haushalt, Behörden, Erziehung, Beziehung
  → Stärken aktivieren, Selbsthilfekräfte fördern
  → Krisen abwenden

Dauer: meist 1–2 Jahre mit Verlängerungsmöglichkeit
Umfang: 6–12 Stunden/Woche (variiert nach Träger)

Geeignet wenn:
  ✓ Familie motiviert
  ✓ Gefährdung noch nicht akut
  ✓ Erziehungsschwierigkeiten ohne Strukturversagen
```

## Hilfeplanverfahren (§ 36 SGB VIII) — обязательно!

```
Schritt 1: Antrag / Meldung beim Jugendamt

Schritt 2: Jugendamt klärt:
  → Situation, Ressourcen, Gefährdung
  → Gespräche mit Eltern, Kind, Fachkräften

Schritt 3: Hilfeplankonferenz (HPK)
  → Beteiligt: Eltern + Kind (!) + ASD + Fachkraft des Trägers
  → Gemeinsam: Ziele, Maßnahme, Dauer, Träger
  → Hilfeplan wird schriftlich festgehalten (§ 36 Abs. 2)

Schritt 4: Umsetzung der HzE

Schritt 5: Fortschreibung des Hilfeplans
  → Spätestens alle 6 Monate Überprüfung

Schritt 6: Abschluss oder Weiterführung
```

**Wichtig:** Kind und Eltern müssen am Hilfeplan beteiligt werden!

## Heimerziehung (§ 34 SGB VIII) — плюсы/минусы

```
Indikationen:
  + Elternhaus nicht geeignet (akute Gefährdung, psychische Erkrankung)
  + Kind braucht strukturierten Rahmen, Therapie, Schule
  + Eltern können vorübergehend nicht für Kind sorgen

Kostentragung:
  → Jugendamt trägt Kosten (oft hohe Tagessätze: 150–300 €/Tag!)
  → Eltern beteiligt nach Einkommen (§ 92 SGB VIII)
```

---

## § 35a — Eingliederungshilfe für seelische Behinderung

Besonderer Anspruch neben HzE:

```
Voraussetzungen:
  1. Seelische Gesundheit erheblich beeinträchtigt (ärztliche Diagnose)
  2. Oder: Beeinträchtigung droht
  3. Teilhabe am gesellschaftlichen Leben beeinträchtigt / bedroht

Abgrenzung:
  Körperliche/geistige Behinderung → SGB IX (Eingliederungshilfe)
  Seelische Behinderung Kind → § 35a SGB VIII (Jugendamt!)
```
