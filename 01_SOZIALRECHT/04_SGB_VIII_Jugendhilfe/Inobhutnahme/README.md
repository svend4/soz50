# Inobhutnahme — § 42 SGB VIII

[← SGB VIII](../README.md) | [← Sozialrecht](../../README.md)

> **§ 42 SGB VIII** — Inobhutnahme von Kindern und Jugendlichen.
> Das Jugendamt ist **verpflichtet**, ein Kind in Obhut zu nehmen, wenn es dringend geboten ist.
> Это полномочие и обязанность — Jugendamt может действовать без согласия родителей.

---

## Основания для Inobhutnahme

### § 42 Abs. 1 SGB VIII — три ситуации

```
1. Eigener Wunsch des Kindes / Jugendlichen
   → Kind bittet um Schutz (auch gegen elterlichen Willen)

2. Dringende Gefahr für das Wohl des Kindes
   → Körperliche / seelische Misshandlung
   → Vernachlässigung
   → Sexueller Missbrauch
   → Wenn keine Zeit für Familiengericht

3. Unbegleiteter ausländischer Minderjähriger (UMA)
   → § 42a SGB VIII — vorläufige Inobhutnahme
   → Sofort bei Einreise / Auffinden
```

---

## Ablauf der Inobhutnahme

```
Gefährdungssituation / Meldung
        │
        ↓
Jugendamt / ASD (Allgemeiner Sozialer Dienst) prüft
        │
        ├─ Gefahr nicht dringend → Hilfeplanung, HzE, § 8a-Verfahren
        │
        └─ Gefahr dringend → INOBHUTNAHME (§ 42)
                │
                ├─ Unterbringung in:
                │     Bereitschaftspflegefamilie
                │     Notaufnahme / Jugendschutzhaus
                │     Jugendheim / stationäre Einrichtung
                │
                ├─ Eltern informieren (§ 42 Abs. 3) — unverzüglich
                │     Widersprechen Eltern → Familienrichter anrufen (§ 42 Abs. 3 S. 4)
                │     Familienrichter entscheidet über Verbleib
                │
                └─ Hilfeplan (§ 36 SGB VIII) erstellen
                      Rückkehr zur Familie? Fremdunterbringung?
```

---

## Kindeswohlgefährdung — § 8a SGB VIII

Der **Schutzauftrag** gilt für **alle** Einrichtungen (nicht nur Jugendamt):

```
Beobachtung / Meldung von Gefährdungsanzeichen
        │
Risikoeinschätzung im Team (§ 8a Abs. 1)
        │
Hinzuziehung erfahrener Fachkraft
        │
Eltern einbeziehen (wenn ohne Gefährdung möglich)
        │
        ├─ Gefährdung abgewendet → Dokumentation + Begleitung
        └─ Gefährdung nicht abgewendet → Jugendamt informieren (§ 8a Abs. 2)
```

**Anzeichen für Kindeswohlgefährdung:**
- Unerklärliche Verletzungen, Hämatome
- Deutliche Unterernährung, mangelhafte Hygiene
- Kind äußert Angst vor Zuhause
- Fehlende Schulbesuche
- Sexualisiertes Verhalten (bei jüngeren Kindern)

## Unbegleitete ausländische Minderjährige (UMA) — § 42a SGB VIII

```
UMA trifft ein (Grenze, Bahnhof, gemeldet)
        │
Vorläufige Inobhutnahme durch Jugendamt am Ankunftsort
        │
Erstversorgung + Alterseinschätzung (wenn nötig)
        │
Bundesweite Verteilung (Königsteiner Schlüssel / EASY-Verfahren)
        │
Inobhutnahme durch zuständiges Jugendamt (§ 42 SGB VIII)
        │
Hilfeplanung: Heimunterbringung, Pflegefamilie, betreutes Wohnen
        │
Asylantrag (BAMF) + Vormund / Ergänzungspfleger bestellen
```

---

## Rechte des Kindes während Inobhutnahme

- Recht auf **Begleitung** durch Vertrauensperson
- Recht auf **Informationen** (altersgerecht)
- Recht auf **Kontakt** zu Eltern (außer bei Gefährdung durch Kontakt)
- Recht auf **Rückkehr** zu Eltern wenn Gefährdung beseitigt
- Recht auf **Anhörung** beim Familiengericht (ab ca. 14 Jahren)

---

## Beteiligte Stellen

| Stelle | Aufgabe |
|--------|---------|
| Jugendamt / ASD | Gefährdungseinschätzung, Inobhutnahme |
| Familiengericht | Entscheidung über Verbleib, Sorgerechtsentzug |
| Bereitschaftspflege | Sofortunterbringung (48h–Wochen) |
| Ergänzungspfleger | Vertretung UMA |
| Verfahrensbeistand | Anwalt des Kindes im Gerichtsverfahren |
| Polizei | Bei akuter Gefahr gemeinsam mit Jugendamt |
