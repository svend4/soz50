## Как добавить документ

1. Найди нужную папку (от общего к частному)
2. Создай файл по шаблону: `YYYY-MM-DD_Thema.md`
3. Заполни метаданные в начале файла (тема, дата, источник)
4. Добавь ссылку в `README.md` папки

Подробнее: [00_METHODIK/anleitungen/wie-dokument-hinzufuegen.md](./00_METHODIK/anleitungen/wie-dokument-hinzufuegen.md)
