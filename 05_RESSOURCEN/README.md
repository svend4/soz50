## Онлайн-базы данных

| Ресурс | Что содержит |
|--------|-------------|
| [gesetze-im-internet.de](https://www.gesetze-im-internet.de) | Все федеральные законы (актуальные) |
| [sozialgerichtsbarkeit.de](https://www.sozialgerichtsbarkeit.de) | Решения социальных судов |
| [bsg.bund.de](https://www.bsg.bund.de) | Bundessozialgericht |
| [bundesverfassungsgericht.de](https://www.bundesverfassungsgericht.de) | BVerfG |
| [dejure.org](https://dejure.org) | Законы + судебная практика (перекрёстные ссылки) |
| [haufe.de](https://www.haufe.de) | Kommentare (частично платно) |
| [arbeitsagentur.de](https://www.arbeitsagentur.de) | Formblätter BA |
| [bmas.de](https://www.bmas.de) | BMAS — Ministerium für Arbeit und Soziales |
