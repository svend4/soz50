## Suchhilfe: wie suchen?

### BSG-Urteil nach Aktenzeichen

```
Beispiel: "BSG B 14 AS 60/12 R"

1. bsg.bund.de → Entscheidungssuche → Aktenzeichen eingeben
2. Alternativ: dejure.org → Suche → Aktenzeichen

Für neue Urteile: bsg.bund.de → Pressemitteilungen
```

### Paragraf → relevante Urteile

```
dejure.org → Paragraph aufrufen → Rechtsprechung-Tab
Beispiel: § 22 SGB II → Entscheidungen
```

### Stichwortsuche Sozialrecht

```
Google: "BSG schlüssiges Konzept § 22 SGB II"
Google Scholar: scholar.google.de → Rechtsprechung
```

## Qualitätsprüfung von Quellen

```
Vertrauenswürdig:
  ✓ Offizielle Gerichtsseiten (bsg.bund.de etc.)
  ✓ gesetze-im-internet.de
  ✓ Peer-reviewed Fachzeitschriften

Prüfen/kritisch lesen:
  ⚠ Vereinsseiten (tacheles, gegen-hartz) — gut, aber Perspektive beachten
  ⚠ Blogs, Ratgeberseiten — Datum prüfen! Recht ändert sich

Nicht verwenden:
  ✗ Wikipedia als Rechtsquelle
  ✗ Veraltete Seiten (Datum prüfen!)
  ✗ KI-Ausgaben ohne Quellenprüfung
```
