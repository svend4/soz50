# Online-Ressourcen — Rechtsdatenbanken und Fachportale

[← Online Datenbanken](./README.md) | [← Ressourcen](../README.md)

> Gute Recherche braucht die richtigen Quellen.
> Diese Sammlung gibt einen Überblick über kostenfreie und kostenpflichtige
> Datenbanken für Sozialrecht und Sozialarbeit.

---

## Gesetzestexte — kostenlos

```
gesetze-im-internet.de (Bundesjustizministerium):
  → Alle Bundesgesetze im Volltext, kostenlos
  → Immer aktuelle Fassung mit Änderungshistorie
  → Ideal: SGB I–XIV, AsylG, AufenthG, BGB, ZPO...
  → Direkte Suche nach Paragraphen möglich

bundesanzeiger.de:
  → Offizieller Bundesanzeiger
  → Verkündete Gesetze und Verordnungen
  → Jahresberichte, amtliche Bekanntmachungen

EUR-Lex (eur-lex.europa.eu):
  → EU-Recht im Volltext
  → Verordnungen, Richtlinien, EuGH-Urteile
  → Dublin-VO, VO 492/2011, etc.
```

---

## Gerichtsurteile — kostenlos

```
sozialgerichtsbarkeit.de:
  → Entscheidungssuche der deutschen Sozialgerichtsbarkeit
  → BSG, LSG, SG: alle Instanzen
  → Freitext- und Aktenzeichen-Suche
  → Direktlink: sozialgerichtsbarkeit.de/sgb/esgb/...

bsg.bund.de:
  → Bundessozialgericht direkt
  → Pressemitteilungen zu aktuellen Urteilen
  → Termine + Vorlagen beim EuGH

bundesverfassungsgericht.de:
  → BVerfG-Entscheidungen im Volltext
  → Pressemitteilungen zu wichtigen Entscheidungen
  → Wichtig: BVerfG 2019 Sanktionen, BVerfG Regelsätze...

bundesverwaltungsgericht.de:
  → BVerwG-Entscheidungen (Verwaltungsrecht, Asylrecht)
  → Relevant für Asyl und Jugendhilfe

curia.europa.eu:
  → EuGH-Urteile auf Deutsch
  → Dublin-Rechtsprechung, Freizügigkeit, etc.
```

## Fachportale Sozialrecht — kostenlos

```
tacheles-sozialhilfe.de:
  → Aktuelle SGB-II/XII-Rechtsprechung in einfacher Sprache
  → Regelmäßige Newsletter
  → Besonders für: KdU, Mehrbedarf, Sanktionen

gegen-hartz.de:
  → SGB-II-Nachrichten aus Betroffenenperspektive
  → Widerspruchshilfen, aktuelle Urteile

anwalt.de / anwaltauskunft.de:
  → Anwaltssuche (Fachanwalt Sozialrecht, Ausländerrecht)

proasyl.de:
  → Asylrecht: Länderdossiers, Gerichtsurteile, Handlungsleitfäden
  → PDF-Leitfäden zum Download
  → Besonders gut: asylrechtliche Rechtsprechung

BAMF-Entscheidungsstatistiken:
  → bamf.de → "Aktuelle Zahlen Asyl"
  → Schutzquoten nach Nationalität (monatlich aktualisiert)
  → Grundlage für Beratung zur Erfolgsaussicht

Grundsicherungs-Wiki:
  → Aktuelle SGB-II-Gesetzgebung und Durchführungshinweise (BA)
  → Auf sozialrechtsexperte.de / hartz4.org
```

## Kostenpflichtige Datenbanken (für Fachkräfte)

```
juris.de:
  → Vollständigste deutsche Rechtsdatenbank
  → Alle Gerichtsinstanzen, Gesetze, Kommentare
  → Preis: ab ca. 80 €/Monat (Einzelplatz)
  → Lohnt sich für: intensiv arbeitende Beratungsstellen

beck-online.de:
  → Juristischer Kommentar + Rechtsprechung
  → Umfangreich kommentierte SGB-Texte
  → Preis: ähnlich juris
  → Kommentare Hauck/Noftz SGB II, LPK-SGB II etc.

NWB Datenbank:
  → Steuerrecht + Sozialrecht
  → Gut für Überschneidungen (Elterngeld, Rente und Steuern)
```

## Sozialarbeit-Fachressourcen

```
socialnet.de:
  → Fachinformationen Sozialarbeit, Sozialrecht, Sozialpolitik
  → Rezensionen von Fachbüchern
  → Stellenangebote

dbsh.de (Deutscher Berufsverband Soziale Arbeit):
  → Berufsethische Prinzipien
  → Fortbildung, Netzwerk

bagfw.de (Bundesarbeitsgemeinschaft der freien Wohlfahrtspflege):
  → Positionen der Wohlfahrtsverbände
  → Stellungnahmen zu Gesetzgebungsvorhaben

bmas.de (Bundesministerium für Arbeit und Soziales):
  → Aktuelle Gesetzgebung, Statistiken
  → Durchführungshinweise SGB II (für Jobcenter — auch für Beratung!)
  → Mindestlohn, Rentendaten

bmfsfj.de (Bundesministerium für Familien):
  → Familienpolitik, Jugendhilfe, Kinder
  → Kinder- und Jugendbericht

destatis.de:
  → Statistisches Bundesamt
  → Armutsquoten, Sozialleistungsstatistiken
  → Grundlage für Berichte und Gutachten
```

## Berechnung und Formulare

```
BuT-Antrag:
  → Direkt beim JC (verschiedene Formulare je Bundesland)
  → bmas.de: Bundesformulare SGB II

Pflegegrad-Formular:
  → pflegekasse-antrag.de (Muster)
  → Direkt bei der eigenen Pflegekasse

ALG-I-Antrag:
  → arbeitsagentur.de/arbeitslosigkeit/arbeitslosengeld
  → Online-Antrag möglich!

Rentenantrag:
  → meine-drv.de (nach Registrierung)
  → Oder: DRV-Beratungsstelle

Widerspruchs-Muster:
  → tacheles-sozialhilfe.de: Musterschreiben
  → gegen-hartz.de: Musterwidersprüche
  → PARITÄTISCHER: mustervorlagen.sozialrecht.de

Berechnung KdU-Angemessenheit:
  → Schlüssige-Konzepte: von Jobcentern zu erfragen
  → Tabellengrenze (Fallback): BSG-Tabelle WoGG + 10%
    → Abrufbar bei BSG-Urteil B 14 AS 24/18 R
```
