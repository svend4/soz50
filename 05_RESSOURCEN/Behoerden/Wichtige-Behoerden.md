# Wichtige Behörden und Anlaufstellen — Übersicht

[← Ressourcen](./README.md) | [← Hauptseite](../../README.md)

> Wer ist für was zuständig? Diese Übersicht hilft dabei,

## Übersicht: Träger und Zuständigkeiten

| Behörde | Zuständig für | Rechtsgrundlage |
|---------|--------------|-----------------|
| **Jobcenter** | SGB II (Bürgergeld), KdU, Eingliederung | SGB II |
| **Agentur für Arbeit** | SGB III (ALG I), Weiterbildung, Beratung | SGB III |
| **Sozialamt** | SGB XII (Sozialhilfe), AsylbLG, § 67 | SGB XII, AsylbLG |
| **Jugendamt** | SGB VIII (Jugendhilfe), HzE, Inobhutnahme | SGB VIII |
| **EGH-Träger** (Bezirk/LWV/LVR) | Eingliederungshilfe SGB IX | SGB IX |
| **Pflegekasse** | SGB XI (Pflegegrade, Leistungen) | SGB XI |
| **Krankenkasse (GKV)** | SGB V (Krankenversicherung) | SGB V |
| **Deutsche Rentenversicherung** | SGB VI (Rente, EM-Rente) | SGB VI |
| **Ausländerbehörde** | Aufenthaltstitel, Verlängerung | AufenthG |

## Jobcenter

```
Zuständigkeit: SGB II — Bürgergeld
  → Regelbedarf + KdU für erwerbsfähige Hilfebedürftige
  → Eingliederungsvereinbarung, Maßnahmen
  → Sanktionen (§§ 31–32 SGB II)

Ansprechpartner finden:
  → bundesagentur.de/jobcenter → Suche nach PLZ
  → Persönlich: Wohnortgemeinde

Wichtige Nummern:
  → Bürgertelefon Jobcenter: 0800 4 5555 00 (kostenfrei Mo–Fr 8–18 Uhr)
  → Online-Antrag: jobcenter.digital

Rechtsbehelfe gegen JC:
  → Widerspruch → Widerspruchsbescheid → Klage Sozialgericht
  → Ombudsmann BA: schlichten.arbeitsagentur.de
```

## Agentur für Arbeit

```
Zuständigkeit: SGB III — ALG I, Weiterbildung, Beratung

Abgrenzung zum Jobcenter:
  → Agentur = SGB III (ALG I, Vermittlung, Bildung)
  → Jobcenter = SGB II (ALG II/Bürgergeld)
  → Wichtig: richtige Stelle aufsuchen!

Kontakt:
  → arbeitsagentur.de → Standortsuche
  → Bürgertelefon: 0800 4 5555 00 (kostenfrei, Mo–Fr 8–18 Uhr)
  → Jobbörse: arbeitsagentur.de/jobboerse

Serviceangebote:
  → Berufsberatung (auch für Schüler, Studienabbrecher)
  → Bildungsgutschein (Weiterbildungsförderung)
  → Förderung zur Selbstständigkeit (Gründungszuschuss)
  → Teilhabe am Arbeitsmarkt (für Langzeitarbeitslose)
```

## Sozialamt

```
Zuständigkeit: SGB XII, AsylbLG, § 67 SGB XII
  → Grundsicherung im Alter (§§ 41–46b SGB XII)
  → Hilfe zum Lebensunterhalt (§§ 27–40 SGB XII)
  → AsylbLG-Leistungen
  → Wohnungslosenhilfe (§§ 67–69 SGB XII)
  → Hilfe zur Pflege (§§ 61–66 SGB XII)

Örtliche Zuständigkeit:
  → Wohnortgemeinde / Kreis
  → Bei Heimunterbringung: Sonderregelungen (§ 98 SGB XII)

Kontakt:
  → Gemeindeverwaltung → "Sozialamt" / "Fachdienst Soziales"
  → In Großstädten: oft Bezirksämter mit Sozialbürgerhaus

Rechtsbehelfe:
  → Widerspruch → Widerspruchsbescheid → Klage Sozialgericht
```

## Jugendamt

```
Zuständigkeit: SGB VIII — Kinder- und Jugendhilfe
  → HzE (§§ 27–35 SGB VIII)
  → Hilfeplan (§ 36 SGB VIII)
  → Inobhutnahme (§ 42 SGB VIII)
  → UMA-Betreuung (§ 42a SGB VIII)
  → Kinderschutz (§ 8a SGB VIII)
  → Unterhaltsvorschuss

Örtliche Zuständigkeit:
  → Wohnortgemeinde (bei Eltern)
  → Besonderheiten bei getrenntlebenden Eltern

Kontakt:
  → Gemeindeverwaltung → "Jugendamt" / "Jugend- und Familienamt"
  → Notfall-Rufbereitschaft (auch nachts/Wochenende!):
    → § 8a SGB VIII: JA muss bei Kindeswohlgefährdung rund um die Uhr erreichbar sein
    → Nummer beim lokalen JA erfragen!

Rechtsbehelfe:
  → Widerspruch → Widerspruchsbescheid → Klage Verwaltungsgericht
    (NICHT Sozialgericht! Jugendhilfe = VG)
```

## Pflegekasse

```
Zuständigkeit: SGB XI — Pflegeleistungen
  → Pflegegradantrag und -begutachtung
  → Pflegegeld, Sachleistungen, Verhinderungs-/Kurzzeitpflege
  → Entlastungsbetrag (§ 45b SGB XI)

Wo:
  → Gleiche Stelle wie Krankenkasse (GKV)
  → Pflegekasse = Abteilung der jeweiligen KK

Antrag:
  → Schriftlich an eigene Pflegekasse
  → Bürgertelefon der jeweiligen KK nutzen

Rechtsbehelfe:
  → Widerspruch → Widerspruchsbescheid → Klage Sozialgericht
  → Gutachten anfordern (§ 18 Abs. 4 SGB XI — Recht auf Akteneinsicht)
```

## Deutsche Rentenversicherung (DRV)

```
Zuständigkeit: SGB VI — Renten
  → Altersrenten, EM-Rente, Witwenrente
  → Reha-Maßnahmen (§§ 9 ff. SGB VI)
  → Rentenauskunft, Rentenbescheid

Kontakt:
  → drv.de — Online-Rentenantrag, Auskunft
  → Beratungsstellen: deutschlandweit (kostenlos)
  → Bürgertelefon DRV: 0800 1000 4800 (Mo–Do 7:30–19:30, Fr 7:30–15:30)

Auskunft:
  → Renteninformation: jährlich automatisch per Post
  → Online-Dienste: meine-drv.de (nach Registrierung)
  → Rentenberechnung: drv.de/rentenrechner

Beratung:
  → VdK, SOVD: kostenlose Rentenberatung für Mitglieder
  → Steuerberater: für komplizierte Rentenbesteuerung
```

## BAMF — Bundesamt für Migration und Flüchtlinge

```
Zuständigkeit: Asylverfahren, Integrationskurse, Niederlassungserlaubnis (bestimmte)
  → Asylentscheidungen
  → Integrations- und Berufssprachkurse
  → Widerruf von Schutzstatus

Kontakt:
  → bamf.de — Informationen auf Deutsch und vielen Sprachen
  → Zuständige Außenstelle: je nach Aufnahmeeinrichtung
  → Bürgertelefon: 0911 943-0

Asylentscheidung:
  → Auskunft: bamf.de → "Behördenanfragen"
  → Verfahrensberatung: vor der Anhörung!

WICHTIG:
  → BAMF ist KEINE Beratungsstelle!
  → Beratung: freie Träger, Flüchtlingsräte, Anwälte
```

## Sozialgericht / Verwaltungsgericht

```
Sozialgericht (SGG):
  → Zuständig für: SGB II, SGB III, SGB XI, SGB XII (Sozialhilfe), SGB VI, GKV
  → Klage nach Widerspruchsbescheid (1-Monats-Frist)
  → Eilantrag: § 86b SGG (sofortige Entscheidung möglich)
  → Prozesskostenhilfe: § 73a SGG iVm §§ 114 ff. ZPO

Verwaltungsgericht (VwGO):
  → Zuständig für: Asylrecht, Jugendhilfe (SGB VIII), Ausländerrecht
  → Klage nach Ablehnung durch BAMF / JA
  → Eilantrag: § 80 Abs. 5 VwGO

Standorte:
  → Sozialgericht: in jedem Oberlandesgerichtsbezirk
  → Verwaltungsgericht: in jedem Bundesland mehrere Standorte
  → Zuständig: Wohnort der klagenden Person

Kein Anwaltszwang (SG):
  → Vor Sozialgericht: kein Anwaltszwang
  → Rechtsberatung trotzdem empfehlenswert!
  → VdK, Sozialverbände: kostenlose Rechtsvertretung (für Mitglieder)
```

## Wichtige Beratungsverbände und -vereine

```
VdK (Sozialverband VdK Deutschland):
  → vdk.de
  → Mitgliederberatung: Rentenrecht, SGB XII, Pflegerecht
  → Rechtsvertretung vor Sozialgericht (für Mitglieder)

SOVD (Sozialverband Deutschland):
  → sovd.de
  → Ähnlich wie VdK

AWO (Arbeiterwohlfahrt):
  → awo.org
  → Beratungsstellen für alle Lebensbereiche
  → MBE (Migrationsberatung für Erwachsene)

Caritas:
  → caritas.de
  → Schuldnerberatung, Migrationsberatung, Familienhilfe

Diakonie:
  → diakonie.de
  → Evangelische Wohlfahrt — breites Beratungsangebot

DRK (Deutsches Rotes Kreuz):
  → drk.de
  → Suchdienst, Katastrophenhilfe, Sozialberatung

PRO ASYL:
  → proasyl.de
  → Rechtsberatung Asylrecht (bundesweit)

Mieterverein / Mieterbund:
  → mieterbund.de → Ortsverbände
  → Mietrecht, Kündigung, Nebenkosten (Mitglieder)

Schuldnerberatung:
  → schuldnerberatung.de (BSFG)
  → Insolvenzberatung, Schuldenregulierung
```
