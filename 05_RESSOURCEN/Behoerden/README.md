## Kommunalebene — nach Aufgabe

| Aufgabe | Behörde | Bemerkung |
|---------|---------|-----------|
| Bürgergeld / SGB II | **Jobcenter** | Gemeinsam BA + Kommune |
| Sozialhilfe / SGB XII | **Sozialamt** | Kommunal |
| AsylbLG-Leistungen | **Sozialamt** oder spez. Stelle | Kommunal |
| Jugendhilfe / SGB VIII | **Jugendamt** | Kommunal |
| Aufenthaltstitel | **Ausländerbehörde** | Kommunal |
| Wohngeld | **Wohnungsamt / Bezirksamt** | Kommunal |
| GdB-Feststellung | **Versorgungsamt** (beim Sozialamt/Landesversorgungsamt) | |
| Betreuung § 1814 BGB | **Betreuungsgericht** (Amtsgericht) + Betreuungsstelle | |
| Pflegegrad | **Pflegekasse** (bei Krankenkasse) | |
| Kindergeld | **Familienkasse** (bei Agentur für Arbeit) | |
| Führerschein/KFZ | **Straßenverkehrsamt** | |
| Meldewesen | **Einwohnermeldeamt** | |
