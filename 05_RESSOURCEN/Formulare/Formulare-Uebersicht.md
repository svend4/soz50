# Formulare und Antragsvordrucke — Praxisübersicht

[← Formulare](./README.md) | [← Ressourcen](../README.md)

> Anträge müssen gestellt werden — wer nicht stellt, bekommt nicht.
> **Formlosigkeit** ist oft möglich und unterschätzt: viele Anträge sind formlos möglich!
> Bei Unklarheit: formloser Brief + persönliches Erscheinen beim Amt.

---

## Grundregel: Formlos vor Formular

```
§ 16 SGB I — Antragstellung:
  → Antrag kann bei JEDER Sozialleistungsbehörde gestellt werden
  → Falsch gestellter Antrag: Behörde MUSS weiterleiten (unverzüglich)
  → Datum des Eingangs beim ersten Amt gilt!

Formlos bedeutet:
  → Brief, E-Mail, persönlich mündlich
  → Kein amtliches Formular nötig (außer ausdrücklich vorgeschrieben)
  → Im Zweifel: kurzer Brief "Ich beantrage hiermit..."

Formular-Pflicht nur wenn:
  → Gesetz oder Rechtsverordnung es ausdrücklich vorschreibt
  → In der Praxis: JC + BA verlangen i.d.R. ihre Formulare
  → Aber: auch ohne Formular → Datum gilt!

TIPP:
  → Immer: Datum notieren, Eingangsbestätigung verlangen
  → Wenn Eingang unklar: Einschreiben!
```

## SGB II — Bürgergeld (Jobcenter)

```
Hauptantrag / Erstantrag:
  → Formular: jobcenter-digital.de oder beim JC persönlich
  → Inhalt: Stammdaten, Einkommens-, Vermögensverhältnisse
  → Anlagen: je nach Situation

Wichtige Anlagen:
  Anlage VM (Vermögen und Wohnverhältnisse):
    → Immobilien, Bankkonten, Fahrzeuge, Lebensversicherungen

  Anlage EK (Einkommen):
    → Alle Einnahmen (Lohn, Unterhalt, Rente, Kindergeld...)

  Anlage KDU (Kosten der Unterkunft):
    → Mietvertrag-Daten, Heizkosten, Nebenkosten

  Anlage Kind:
    → Je Kind: Personaldaten, Kindergeldnachweis

  Anlage SV:
    → Sozialversicherungsnachweise

Weiterbewilligungsantrag (WBA):
  → Alle 6 oder 12 Monate (je nach JC)
  → Frühzeitig stellen (mindestens 4 Wochen vorher!)
  → JC schickt i.d.R. Formular zu — wenn nicht: nachfragen!

Online-Portal:
  → jobcenter-digital.de
  → Vollständig digital möglich + Upload von Belegen
  → ABER: Barrierefreiheit nicht überall gewährleistet
```

## Einmalige Beihilfen (SGB II)

```
BuT — Bildung und Teilhabe (§ 28 SGB II):
  → Schulbedarfspaket: Antrag beim JC
    → 130 € zum 1.8. + 65 € zum 1.2. (automatisch oder auf Antrag)
  → Lernförderung: Antrag + Schulbescheinigung + Angebotspreis
  → Mittagessen: Antrag + Nachweis
  → Schulausflüge: oft direkt beim JC/Schule

Erstausstattung (§ 24 Abs. 3 SGB II):
  → Formloser Antrag beim JC: "Ich beantrage Erstausstattung für..."
  → Bei Erstbezug Wohnung nach Obdachlosigkeit/Haft
  → Schwangerschaft: gesonderte Erstausstattung

Darlehen (§ 24 Abs. 1 SGB II):
  → Unabwendbarer Bedarf (z.B. Waschmaschinen-Reparatur)
  → Formlos: "Ich beantrage ein Darlehen für..."
  → JC kann Sachleistung statt Geldleistung geben
```

## SGB XII — Sozialhilfe (Sozialamt)

```
Grundsicherung im Alter (§ 41 SGB XII):
  → Formular beim Sozialamt (nicht bundeseinheitlich!)
  → Inhalt: Renten, Wohnen, Vermögen, Verwandtschaftsverhältnisse
  → Rückseitig: Vollmacht für Sozialamt (Unterhaltsermittlung)
  → TIPP: Vollmacht ggf. eingeschränkt erteilen

Hilfe zum Lebensunterhalt (§ 27 SGB XII):
  → Sozialamt, formlos möglich
  → Dieselben Unterlagen wie SGB II

AsylbLG-Leistungen:
  → Leistungsstelle beim Sozialamt oder spezieller Anlaufstelle
  → Unterschiedlich je Bundesland / Kommune
  → Personalausweis / Aufenthaltstitel + Aufnahmebescheid

§ 67 SGB XII (besondere soziale Schwierigkeiten):
  → Formlos beim Sozialamt
  → Bescheinigung vom Fachdienst (Wohnungslosenhilfe)
```

## SGB VIII — Jugendhilfe (Jugendamt)

```
HzE — Hilfen zur Erziehung (§ 27 SGB VIII):
  → FORMLOS! Auch mündlich möglich
  → JA muss reagieren!
  → Schriftlicher Antrag empfohlen: Datum beweisbar
  → Inhalt: "Ich/Wir beantragen Hilfen zur Erziehung für [Kind]"

§ 35a SGB VIII (seelische Behinderung):
  → JA, formlos möglich
  → Ärztliche/psychologische Stellungnahme muss vorgelegt werden (§ 35a Abs. 1a)
  → Schulbescheinigung, Diagnose

Unterhaltsvorschuss (UhVG):
  → JA (Unterhaltsvorschussstelle)
  → Formular + Unterlagen (→ siehe Unterhaltsvorschuss-Dokument)
  → Vollständige Unterlagen: schnellere Bearbeitung!
```

## SGB XI — Pflegeleistungen (Pflegekasse)

```
Pflegeleistungen Erstantrag:
  → FORMLOS bei der Pflegekasse des Versicherten
  → Brief, Telefon, E-Mail — alles möglich
  → Text: "Ich beantrage Leistungen aus der Pflegeversicherung"
  → Datum des Eingangs = maßgeblich für Leistungsbeginn!

Widerspruch Pflegegrad:
  → An Pflegekasse (nicht an MDK/MDS!)
  → Frist: 1 Monat
  → Inhalt: "Ich widerspreche dem Bescheid vom [Datum]"
  → Begründung: Gutachten-Fehler benennen + eigene Dokumentation

Entlastungsbetrag (§ 45b SGB XI):
  → Formlos bei Pflegekasse
  → 125 €/Monat für anerkannte Betreuungsangebote
  → Nachweise: Rechnungen des Anbieters

Verhinderungspflege (§ 39 SGB XI):
  → Formlos (Antrag + Rechnung) bei Pflegekasse
  → Aufwendungsersatz bis 1.612 €/Jahr
```

## Weitere wichtige Anträge

```
Kindergeld (KG1 — Familienkasse):
  → familienkasse.de → Formular KG1
  → Online-Antrag bevorzugt!
  → Unterlagen: Geburtsurkunde Kind, Steuer-ID Kind + Eltern

Kinderzuschlag (KiZ — Familienkasse):
  → familienkasse.de/kiz
  → Online-Antrag!
  → Einfacher Prozess, aber Einkommensnachweise nötig

BAföG (Studium — Studentenwerk):
  → bafög-digital.de
  → Vollständig online möglich
  → Einkommensnachweis der Eltern!

BAB (Berufsausbildungsbeihilfe — BA):
  → arbeitsagentur.de → Formulare
  → Für Auszubildende außerhalb des Elternhauses

Rentenantrag (DRV):
  → meine-drv.de nach Registrierung
  → Oder: Beratungsstellen der DRV (kostenlos!)
  → Frühzeitig stellen (3 Monate vor Rentenbeginn)

Schwerbehindertenausweis (GdB-Antrag):
  → Versorgungsamt (im Sozialamt / Landesbehörde)
  → Antragsformular + ärztliche Befundberichte
  → Formular: zuständiges Versorgungsamt oder online
```

## Widersprüche — Muster und Fristen

```
Allgemeine Widerspruchsfrist (§ 84 SGG):
  → 1 Monat nach Bekanntgabe des Bescheids
  → Frist läuft ab Zustellung (nicht ab Erstellungsdatum!)
  → Wenn kein Datum: ab Kenntnisnahme

Widerspruch — Mindestinhalt:
  "Gegen den Bescheid vom [Datum], Az. [...], erhebe ich Widerspruch.
   Eine Begründung reiche ich nach."
  → Sofort einsenden — Begründung kann später folgen!

Muster-Quellen:
  → tacheles-sozialhilfe.de: SGB-II-Musterwidersprüche
  → gegen-hartz.de: kommentierte Muster
  → Wissensbasis: [Sanktionswiderspruch](../../01_SOZIALRECHT/02_SGB_II_Buergergeld/Sanktionen/Sanktionswiderspruch-Musterbrief.md)
  → PARITÄTISCHER: mustervorlagen.sozialrecht.de
  → VdK / SoVD: kostenlose Rechtsberatung + Muster für Mitglieder
```

## Vollmachten und Datenschutz

```
Vollmacht für Beratungsstelle:
  → Schriftlich (formlos möglich)
  → Inhalt: was darf Bevollmächtigter? Alle Angelegenheiten oder nur bestimmte?
  → Welcher Zeitraum? (nicht unbegrenzt!)
  → Kopie beim Klienten, Original beim Amt

Einwilligungserklärung für Datenweitergabe:
  → Art. 7 DSGVO: muss freiwillig sein!
  → Spezifisch: für welche Stelle, welche Daten, welchen Zweck?
  → Muster: beim eigenen Träger (eigene Einwilligungsformulare)

Post- und Zustellungsvollmacht:
  → Wenn Klient keine Post empfangen kann (Obdachlos etc.)
  → Beratungsstelle als Postanschrift: rechtlich möglich
  → Zustellungsbevollmächtigung gegenüber Behörden erklären
```
